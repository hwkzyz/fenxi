# 20250527间隙-振动辨识V1

本目录是独立于`20250527_low_speed_gap_prior_decoupling`的新正式程序包，原目录保持不动。

## 正式辨识约束

- 目标叶片B1，传感器CH1、CH3、CH6；
- 20圈输入、3圈窗口、1圈步长，共18个独立窗口；
- 频率搜索范围为`[300,1000] Hz`；
- VP Top-K只负责产生候选，不固定EO；
- 每个Top-K候选分别优化`f=EO*f_r+Delta f`，`Delta f`默认为正负2 Hz；
- 不使用参考阶次，不使用固定EO；
- 理论静态偏置固定为`eta=0`；
- 不使用上一窗口的EO、相位、频率或位移参考；
- 最终候选排序使用普通不加权电压RMSE；
- 正式间隙模型为`gap_only`。

## OPR六槽角度映射

正式程序不再把一圈内六个OPR槽视为严格等间隔。低速数据标定得到的六个相邻槽角为：

```text
[59.923500, 60.581694, 59.167795, 60.098993, 59.942518, 60.285500] deg
```

高速与低速OPR槽指纹的循环匹配偏移为`-1`槽（等价写法为`circshift(high,+5)`），匹配残差为`0.021572 deg`。`Main09`使用同一套物理槽映射同时计算空间坐标和EO相位；低速模板固定使用共同的第2-21圈。正式标定文件为：

```text
inputs/calibration/OPR6_SlotCalibration_20250527.mat
```

## 运行顺序

首先检查程序和冻结参数：

```matlab
Check_Program_20250527('all')
```

只做正式振动辨识和两方法对比时运行：

```matlab
Main09_Foundation_FixedGap_Identification_20250527
Main10_GapAware_FullWave_Identification_20250527
Main11_Compare_FixedGap_GapAware_20250527
```

首次建立应变验证证据时，必须先运行`Main01`至`Main04`。其中`Main04`把应变时间统一换算到BTT时钟；随后运行：

```matlab
Main12_Validate_Identification_With_Strain_20250527
Main13_Visualize_Strain_BTT_Waveforms_20250527
```

需要从原始数据重新建立全部标定和辨识结果时，按`Main01`至`Main13`顺序运行。
