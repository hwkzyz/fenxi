# 20250527 V1 OPR六槽角度映射分析与正式更新

## 结论

20250527 V1确实存在“一圈六次OPR按等效整圈角速度处理、未显式使用六个物理槽不等角度及低高速槽号循环对齐”的问题。该问题不是OPR漏检或事件跳槽，而是坐标模型不完整。

独立诊断确认改进有效后，正式V1已统一改为：

1. 低速模板使用共同的第2-21圈；
2. 六个相邻OPR槽使用各自标定角度；
3. 高速OPR事件按低高速指纹进行循环槽号对齐；
4. 空间坐标与EO相位使用同一套物理槽映射；
5. Step06间隙库基于新模板重新标定；
6. Main09保存完整正式波形束，Main10不再使用6000点预览替代全波形。

## 槽角标定

六个相邻槽角为：

```text
[59.923500, 60.581694, 59.167795, 60.098993, 59.942518, 60.285500] deg
```

高速到低速的物理槽号偏移为`-1`槽，等价于`circshift(high,+5)`。匹配残差为`0.021572 deg`，次优方案间隔为`0.476862 deg`。0-50 s分段检查得到相同偏移。

仅改成相邻等60度没有稳定收益；真正有效的是“不等槽角+物理槽号对齐”。
