# 20241106 gap-prior projection flow

This folder now follows a calibration-first route.

## Core idea

Build calibration banks once, then identify any target blade by selecting the target blade, sensor set, and time window.

- Low-speed single-template library: all blades B1-B6, sensors S2/S3/S5/S7, generated by `20241106_low_speed_rotating_calibration`.
- Local low-speed template bank: an index/cache assembled from those single blade-sensor template files.
- Gap calibration bank: all blades B1-B6, capacitive sensors S5/S7 only.
- S2/S3 are direct-only vibration sensors. They can be used in dynamic identification, but they are never added to the gap library.
- S5/S7 are capacitive sensors. They use the low-speed template and can also use `dg`, `dmu`, and `dtau` gap correction terms.

## Canonical files

- `ProjectionFlow_Config_20241106.m`: central defaults for calibration and identification.
- `Step00_CheckCase_20241106.m`: dry-run checker for the active case, paths, window count, and stale environment overrides.
- `Step00_Run_ProjectionFlow_20241106.m`: recommended runner.
- `Step06A_BuildLowSpeedTemplateBank_20241106.m`: reads `20241106_low_speed_rotating_calibration/output/new_flow/template_library/Template_20241106_Bx_Sy.mat` and builds `outputs/LowSpeedTemplateBank_20241106_B1toB6_S2357.mat`.
- `Step06I_Calibrate_AllBladeGapLibrary_20241106.m`: builds `outputs/GapCalibrationBank_20241106_B1toB6_S57.mat`.
- `Step06_BuildGapAwareDynamicMap_20241106.m`: selects one target blade and builds high-speed sliding windows.
- `Step07J_NestedStaticWarp_VPFullWave_20241106.m`: identifies direct/fixed/gap models on the selected windows.
- `Step07K_Compare_NestedStaticWarp_20241106.m`: compares methods from a comparison-mode Step07J result.

Older single-case gap-route scripts are under `_archive_candidates_20260701/`.
The bank route above should be used for new 20241106 runs.
Step07J does not silently fall back to DynamicMap bundle reconstruction in
normal use. Generate the matching direct/compact upstream files, or enable
`STEP07J_ALLOW_DYNAMIC_MAP_FALLBACK=1` only for debugging.

## Typical runs

Build all calibration banks:

```matlab
Step00_CheckCase_20241106;
setenv('FLOW_RUN_MODE','calibration');  % optional; defaults can live in ProjectionFlow_Config_20241106
run('Step00_Run_ProjectionFlow_20241106.m');
```

Generate/refresh the upstream single low-speed templates first:

```matlab
cd('../20241106_low_speed_rotating_calibration');
run('Step05_BuildLowSpeedTemplateLibrary_20241106.m');
```

Run B4 with S2/S5/S7, where only S5/S7 use the gap bank:

```matlab
% Prefer editing ProjectionFlow_Config_20241106.m for persistent settings.
Step00_CheckCase_20241106;
setenv('FLOW_RUN_MODE','compare');
setenv('BLADE_CASE_BLADE_ID','4');
setenv('BLADE_CASE_SENSOR_IDS','2 5 7');
setenv('STEP06G_ANALYSIS_SENSORS','2 5 7');
setenv('STEP07J_ANALYSIS_SENSORS','2 5 7');
setenv('STEP06G_GAP_SENSORS','5 7');
setenv('STEP07J_GAP_SENSORS','5 7');
setenv('STEP07J_RESULT_SUFFIX','_hybrid_s2_bank_compare');
run('Step00_Run_ProjectionFlow_20241106.m');
```
