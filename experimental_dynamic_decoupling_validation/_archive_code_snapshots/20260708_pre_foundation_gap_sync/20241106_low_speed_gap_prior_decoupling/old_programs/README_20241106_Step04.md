# Step04：先用应变信号做三维 FFT 找共振区间

这个步骤先不碰 OPR 和 probe，只看 `20241106_2` 里面的应变信号：

- `AI1-01_20241106170148.mat`
- `AI1-02_20241106170148.mat`
- `AI1-03_20241106170148.mat`
- `AI1-04_20241106170148.mat`

程序文件：

```matlab
Step04_3DFFT_Strain_ResonanceScan_20241106
```

## 程序做什么

程序对每一路应变信号做滑动窗口 FFT：

1. 横轴是时间。
2. 纵轴是频率。
3. 幅值用三维曲面和二维热图显示。
4. 自动在指定频带里找幅值最大的几个时间窗口。

默认设置为：

```matlab
windowSec = 2.0;
stepSec = 0.25;
displayFreqBandHz = [0 1000];
resonanceBandHz = [500 750];
```

其中 `displayFreqBandHz` 用来看整体频谱，`resonanceBandHz` 用来自动挑选候选共振窗口。现在先聚焦 `500-750 Hz`，是因为这组数据里最明显的叶片响应集中在约 `629-631 Hz`。

## 怎么调试

只看某一个应变通道：

```matlab
selectedStrainChannels = 4;
```

只分析某一段时间：

```matlab
analysisTimeSec = [160 200];
```

想重新做宽频候选搜索：

```matlab
resonanceBandHz = [100 1000];
```

## 目前运行结论

按当前程序的高频候选搜索，最强共振主要出现在：

- 应变时间约 `188.5 s`
- 频率约 `631.4 Hz`
- 最强通道主要是 `AI1-04` 和 `AI1-03`

次强的一组高频响应集中在：

- 应变时间约 `171.5-183.3 s`
- 频率约 `629.3 Hz`

所以后续 BTT/OPR 的窗口不应该盲选整段，应该优先围绕这些应变共振窗口，再做应变时间轴和 OPR/BTT 时间轴的对应关系确认。
