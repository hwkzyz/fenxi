# 20241106 Step03 选窗与频谱检查说明

脚本：

```text
Step03_Visualize_BTT_Strain_Window_20241106.m
```

作用：把高速 BTT 相对位移、转速、应变片时域和局部 FFT 放在一起看，用于选择后续辨识窗口。

## 重要假设

脚本中 BTT 时间窗和应变片时间窗是分开的：

```matlab
bttWindowSec = [70 72];
strainWindowSec = [150 210];
```

这是有意的。当前还没有证明 PCI/BTT 时间轴和 AI 应变片时间轴同零点，所以不要直接把同一个时间窗同时套给两者。

## 可调参数

常用：

```matlab
sensorIds = [2 3 5 7];
targetBladeSlot = 1;
bttWindowSec = [70 72];
strainWindowSec = [150 210];
fftBandHz = [0 800];
```

如果要检查 probe 4 或 6：

```matlab
sensorIds = [2 3 4 5 6 7];
```

## 当前默认运行现象

默认 BTT 窗口 `[70,72]` 在高速升速段附近，仅用于流程验证。运行时应变片 `AI1-02/03/04` 在 `[150,210]` 秒会出现约 `629 Hz` 的主峰；BTT 低频峰还没有和该应变片主峰直接对齐。

这说明下一步需要继续做：

```text
1. 更系统地扫描 BTT 时间窗；
2. 或先建立 BTT 与应变片的时间同步关系；
3. 再选稳定段进入后续辨识。
```

因此 Step03 的输出是“选窗诊断”，不是最终振动辨识结果。
