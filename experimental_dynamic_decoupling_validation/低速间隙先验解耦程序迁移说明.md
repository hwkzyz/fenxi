# 低速间隙先验解耦程序迁移说明

本文总结 `20250527_low_speed_gap_prior_decoupling` 和 `20251222_low_speed_gap_prior_decoupling` 两个文件夹的当前程序思路。后续处理新的日期或新的传感器组合时，可按本文复制和修改程序。

## 总体思想

当前程序采用“低速模板 + 间隙库 + 高速动态辨识”的路线。

核心逻辑是：

```text
1. 低速数据先建立每个传感器的静态波形模板。
2. 间隙库描述传感器电压波形随叶尖间隙、测点位置和安装倾斜的变化。
3. 高速数据中同时存在静态间隙偏差和叶片振动。
4. 最终在高速 waveform objective 下联合识别 EO、频率、幅值、相位、整体 x 偏移、间隙增量和小的倾斜增量。
```

当前统一主方法是 `gap_tilt`。主程序默认只计算 `gap_tilt`，其它方法只在单独的对比程序中计算。

## 文件排序原则

每个日期文件夹都按文件名排序组织：

```text
Step00 : 主流程总入口
Step01-Step08J : 当前主程序
Step09 : 额外方法对比程序
Step10-Step13 : 可视化、TRAC、应变片频谱验证
Step90 : 诊断分析程序
```

主流程和对比流程必须分开：

```text
Step07J 主程序      : 默认只输出 gap_tilt 主结果
Step09 方法对比程序 : 单独生成 fixed/gap_only/gap_tilt 对比结果
```

这样可以避免论文主结果和消融对比结果混在一个默认文件里。

## 主流程 Step00-Step08J

### Step00：主流程入口

示例：

```matlab
Step00_Run_Main_LowSpeedGapPrior_20250527
Step00_Run_Main_LowSpeedGapPrior_20251222
```

作用：按顺序运行 Step01 到 Step08J。

如果只想从中间继续，修改顶部：

```matlab
runFromStep = 1;
runToStep = 8;
```

迁移到新数据时，建议保留这个总入口，并把日期后缀改成新日期。

### Step01：提取 OPR 和叶尖定时

作用：

```text
1. 读取原始 OPR 和 BTT 传感器数据。
2. 提取转速参考脉冲。
3. 建立叶片通过时刻、转角和转速基准。
4. 输出后续全时域 BTT 位移计算所需的数据。
```

后续新数据最容易出问题的是：

```text
OPR 通道
BTT 传感器通道
阈值
数据文件路径
叶片数
转速脉冲方向
```

### Step02：计算全时域 BTT 位移

作用：

```text
1. 根据 Step01 的叶片通过时刻计算全时域 BTT 位移。
2. 得到每个传感器、每个叶片在全转速过程中的等效位移曲线。
```

这个 Step 主要检查：

```text
位移是否连续
异常跳点是否过多
转速变化段和匀速段是否能区分
```

### Step03：用应变片和 OPR 定位振动区域

作用：

```text
1. 读取应变片数据。
2. 根据 OPR 时间对齐应变片和 BTT 时间轴。
3. 初步定位高速过程中的振动区域。
```

迁移新数据时重点检查：

```text
应变片文件路径
应变片通道号
应变片时间偏移
OPR 对齐是否正确
```

### Step04：检测共振区域和局部 FFT

作用：

```text
1. 根据 BTT/STE 和应变片信息选取后续辨识窗口。
2. 对选定稳定段做局部 FFT，确认应变片主频。
```

20251222 中当前示例使用：

```matlab
selectedTimeSec = [50, 55];
selectedOrder = 14;
```

迁移新数据时，建议先手动选择一个匀速且振动稳定的时间段。不要随便选全段，因为变转速段会让局部频谱和后续辨识窗口不一致。

### Step05：建立低速响应面

作用：

```text
1. 从低速标定数据中建立原始间隙库响应面。
2. 描述不同间隙和 x 位置下的传感器电压波形。
```

本质上得到：

```text
F_raw(g, x)
```

其中：

```text
g : 叶尖间隙
x : 叶尖相对传感器的等效位置
```

### Step05I：学习共享 offset/tilt 响应面

作用：

```text
1. 进一步学习传感器安装 offset、x 缩放和倾斜等参数。
2. 为 Step06I 的低速模板和间隙库对齐提供基础。
```

这个 Step 的目标不是直接做高速辨识，而是把间隙库坐标系和低速模板坐标系统一。

### Step06：建立高速动态映射

作用：

```text
1. 读取低速旋转标定中的动态模板和直接辨识结果。
2. 形成高速滑动窗口 DynamicMap。
3. 为 Step07J 提供每个窗口的高速采样点、转速、转角和 VP 候选。
```

迁移时重点检查：

```text
Template 文件是否对应同一叶片和同一传感器组合
DynamicMap 文件是否对应同一坐标定义
是否使用 OPRCenterStd / GradientXRange030 等统一坐标版本
```

### Step06I：低速模板和间隙库校准

作用：

把低速模板和间隙库拟合到一起，得到每个传感器的安装几何参数：

```text
x_lib = k_s (x_OPR - tau_s)
g_eff = g0_s + mu_s (x_OPR - tau_s)
```

输出：

```text
CorrectedGapLibrary
```

其中包含：

```text
g0_s      : 每个传感器的基准间隙
mu_s      : 低速标定中已有的倾斜趋势
tau_s     : x 方向安装偏移
k_s       : x 方向缩放
a_s, b_s  : 电压幅值和偏置修正
```

这个 Step 是低速模板和间隙库能否结合的关键。

### Step07J：当前主辨识程序

这是主流程中真正的高速振动/间隙解耦辨识程序。

默认主模式：

```text
STEP07J_RUN_MODE = main
```

默认只计算：

```text
gap_tilt
```

主方法模型：

```text
fixed    : 不在主程序中计算
gap_only : 不在主程序中计算
gap_tilt : dg_s + dmu_s*(x - tau_s)
```

主程序中 `gap_tilt` 同时识别：

```text
EO
频率
幅值
相位
整体 x 偏移 dx
每个传感器的间隙增量 dg_s
每个传感器的小倾斜增量 dmu_s
```

输出文件默认后缀：

```text
_main_gaptilt
```

也就是说，正式主结果应类似：

```text
Step07J_NestedStaticWarp_VPFullWave_日期_B1_Sxxx_main_gaptilt.mat
```

如果手动设置：

```matlab
setenv('STEP07J_RESULT_SUFFIX','xxx')
```

则会保存为对应后缀。

### Step08J：主结果交叉验证

作用：

```text
1. 读取 Step07J 主结果。
2. 检查不同窗口、不同传感器、不同参数的稳定性。
3. 输出验证表和趋势图。
```

后续应保持 Step08J 默认读取主结果，也就是 `gap_tilt` 主输出，而不是读取方法对比结果。

## 方法对比 Step09

Step09 是额外程序，不属于主流程。

作用：

```text
1. 使用 STEP07J_RUN_MODE=comparison 单独运行 Step07J。
2. 生成包含 fixed、gap_only、gap_tilt 的对比结果。
3. 输出方法汇总表、窗口对比表和趋势图。
4. 可自动调用 Step10 生成分方法波形图。
```

对比模式输出默认后缀：

```text
_method_compare
```

正式对比结果应类似：

```text
Step07J_NestedStaticWarp_VPFullWave_日期_B1_Sxxx_method_compare.mat
```

对比方法：

```text
direct_low_template_main : 低速直接模板参考，只作为参考行
fixed                    : 不加高速间隙修正
gap_only                 : 只加每传感器间隙增量 dg_s
gap_tilt                 : 加 dg_s 和小倾斜增量 dmu_s
```

`gap_tilt_shift` 不再进入当前对比，因为它额外引入传感器位置平移自由度，训练误差可能更低，但物理约束更弱。

## 可视化 Step10-Step13

### Step10：分方法波形重构图

默认读取：

```text
_method_compare
```

作用：

```text
分别画 fixed、gap_only、gap_tilt 三种方法。
每种方法单独一张图，不放在同一个窗口。
```

图中主要元素：

```text
low-speed template       : 低速标定模板
static gap library       : 低速模板结合间隙库后的静态拟合波形
high-speed data          : 扣除识别振动位移后的高速数据点
method final             : 当前方法最终连续重构波形
prediction samples       : 当前方法在高速采样点处的预测值
```

### Step11：重构流程图

作用：

```text
展示低速模板、间隙库、高速数据、最终重构波形之间的流程关系。
```

该图更适合理解流程，不一定适合作为最终论文中的定量对比图。

### Step12：TRAC 和应变片频谱验证

目前主要用于 20251222。

作用：

```text
1. 读取主方法 gap_tilt 结果。
2. 读取应变片数据。
3. 把应变片按传递比转换为等效位移 mm。
4. 比较 BTT 识别频率和应变片局部 FFT 主频。
5. 用 TRAC 比较 BTT 单频正弦位移和应变片位移波形。
```

当前应变位移换算：

```text
K = 1 / 1.266 / 1000
```

TRAC 注意事项：

```text
TRAC 使用等效位移 mm，不额外做幅值归一化。
TRAC 公式本身包含能量分母，这是定义的一部分。
```

### Step13：Step07J 与应变片 FFT 频率对比

作用：

```text
偏频率验证，用于快速确认识别频率是否落在应变片主频附近。
```

如果 Step12 已经包含完整 TRAC 和频谱验证，Step13 可作为辅助。

## 为什么主方法统一为 gap_tilt

两个数据集表现不同：

```text
20251222 : gap_only 和 gap_tilt 都能稳定 EO14，gap_only RMSE 甚至略低。
20250527 : gap_only 容易跑到 EO10/EO11，gap_tilt 能稳定回到 EO14。
```

原因判断：

```text
20250527 中存在传感器倾斜安装影响。
gap_only 只有整体间隙增量 dg_s，不能描述波形随 x 的小倾斜变化。
gap_tilt 允许 dmu_s，能吸收这类安装/高速状态下的静态波形斜率差异。
```

为了两个数据集使用同一套物理模型，并避免按数据集切换主方法，当前统一采用：

```text
主方法 : gap_tilt
消融   : fixed / gap_only / gap_tilt
```

## 迁移到新数据文件夹的步骤

### 1. 复制文件夹

复制一个已有日期文件夹，例如：

```text

```

改名为：

```text
新日期_low_speed_gap_prior_decoupling
```

### 2. 批量替换日期和传感器组合

需要替换：

```text
20251222 或 20250527
B1_S123 或 B1_S136
analysisSensors
targetBlade
数据文件路径
低速标定文件夹路径
```

重点文件：

```text
Step01-Step04 : 原始数据路径、OPR/BTT/应变片通道
Step06-Step07J : 低速模板、DynamicMap、direct-template 结果路径
Step12 : 应变片文件、时间段、传递比
```

### 3. 先跑低速标定文件夹

在使用 gap-prior decoupling 文件夹前，需要先确保对应的低速标定文件夹已经有：

```text
Template_LowSpeedRotating_...
DynamicMap_...
Result_Step03_Main_...
```

否则 Step06/Step07J 找不到低速模板和直接模板参考。

### 4. 跑主流程

建议先小窗口 smoke：

```matlab
setenv('STEP07J_MAX_WINDOWS','1')
setenv('STEP07J_RESULT_SUFFIX','main_smoke')

```

确认：

```text
modelFits 只有 gap_tilt
Summary 只有 gap_tilt

RMSE 没有明显异常
```

然后再全量：

```matlab
setenv('STEP07J_MAX_WINDOWS','')
setenv('STEP07J_RESULT_SUFFIX','')

```

正式主结果默认保存为：

```text
_main_gaptilt
```

### 5. 跑方法对比

需要消融结果时运行：

```matlab
Step09_Compare_Step07J_Methods_新日期
```

正式对比结果默认保存为：

```text

```

如果只想快速测试：


如果有应变片数据，先在 Step04 选定稳定时间段，再运行 Step12。

重点确认：

```text

TRAC 是否合理
应变片通道和时间对齐是否正确
```

## 常见错误

### 错误 1：主结果和对比结果混用

主结果：

```text
_main_gaptilt
```

对比结果：

```text
_method_compare
```

不要用 `_method_compare` 作为论文主结果。

### 错误 2：Step10 读取主结果

Step10 是方法对比图，默认应读取 `_method_compare`。如果它报缺少 `fixed` 或 `gap_only`，说明读到了主结果。

### 错误 3：低速模板和 DynamicMap 坐标不一致

必须检查：

```text
Template x center
DynamicMap x center
OPRCenterStd / GradientXRange030 后缀
```

坐标不一致会导致低速模板、间隙库和高速点不在同一 x 坐标下，进而造成 EO 或间隙识别异常。

### 错误 4：应变片时间段不对应辨识窗口

应变片 FFT 和 TRAC 应选后续辨识使用的稳定时间段，而不是随便截一段。

### 错误 5：把 TRAC 误解为幅值归一化

当前 TRAC 使用等效位移 mm，未对波形幅值额外归一化。TRAC 公式的分母是定义本身。

## 一句话总结

后续新数据应按下面原则处理：

```text
Step07J 主程序只算 gap_tilt，作为论文主结果；
Step09 单独跑 fixed/gap_only/gap_tilt，作为消融对比；
Step10-Step13 只做可视化和应变片验证，不改变主结果。
```
