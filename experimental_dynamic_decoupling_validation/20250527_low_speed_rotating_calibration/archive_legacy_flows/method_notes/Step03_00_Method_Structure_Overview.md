# Step03 方法结构与结果总说明

本文档说明 `20250527_low_speed_rotating_calibration` 文件夹中当前 Step03 低速模板波形辨识程序的结构、运行速度和结果。当前范围只针对 `S13` 和 `S136`，不使用间隙库，不使用旧超高斯 EO/频率先验。

## 当前物理口径

当前实验只处理同步主频振动，因此频率不作为独立连续变量优化：

```text
f = EO * rot_freq_mean
```

`Step03_04` 的最终模型为：

```text
V_pred = T_low(x - dx_c - A*sin(EO*theta + phi))
```

其中：

- `EO` 是同步阶次。
- `A` 是振动幅值，单位 `mm`。
- `phi` 是相位，单位 `rad`。
- `dx_c` 是空间对齐/常值位移等效项，主要对应传感器安装位置、转速相位映射、OPR 对齐和低速模板-高速窗口零点差异；不再解释为独立振动偏置。
- 旧表或旧程序里的 `d0` 在当前物理解释中等价为 `dx_c`。

## 当前版本顺序

1. `Step03_01_Run_DirectLowSpeedWaveform_20250527.m`
   当前主程序。无加速；所有整数 EO 候选都进入完整波形优化，最终按 post-refinement `weighted_voltage_rmse` 选 EO。

2. `Step03_02_Run_TemplateInverseSeedTopK_20250527.m`
   实验加速版本。模板电压反查种子后保留 top-K EO，再做完整波形优化。

3. `Step03_03_Run_FirstOrderVPTopK_20250527.m`
   实验加速版本。一阶模板 VP 打分后保留 top-5 EO，再做完整波形优化。

4. `Step03_04_Run_FirstOrderVPAdaptive_20250527.m`
   当前改进加速版本。一阶模板 VP 打分后严格保留 top-3 EO；同步频率由 `EO * rot_freq_mean` 给出；最终优化 `A, phi, dx_c`。不做 EO 邻域扩展，不默认 warmup，不默认歧义回退。

## 运行入口

当前主程序批处理入口：


该入口运行 `Step03_01` 的 `S13` 和 `S136`。`Step03_04` 是加速对照和当前理论口径更清晰的实验版本。

## 结论

1. 四个方法在 `S13` 和 `S136` 的 18 个滑动窗口上都稳定选择 `EO14`。
2. 对同步振动，当前不再优化连续 `f`；连续频率搜索更适合异步振动。
3. `Step03_04` 是当前更推荐的加速实验版本：每窗只优化 3 个 EO 候选，速度快于 `Step03_03`，同时保留相同 EO 和参数结果。
4. `dx_c` 已明确为波形空间对齐项；旧 `d0` 结果按 `dx_c` 解释。
5. 本阶段仍只讨论固定低速模板下的振动参数辨识，不进入间隙库或 Step07。
