# 最新试验程序审计（2026-09-05）

## 结论

当前试验的生产方法是：

`Main01 -> Main02 -> Main03 -> Main04 -> R5_Run_R4_FrontEnd_Only -> Main10 -> Main12`

其中 R5 前端使用与 R4 仿真冻结的 PC1 排序系数流形、gap-law、分段线性定位和低速
anchor；B2 registration 只负责跨域坐标/电压配准；输出以 sidecar 形式交给未修改的
Main10。Main13 仅用于可视化，不改变辨识结果。

## 与仿真端相同的历史问题

审计发现试验根目录原先仍保留 Main05--Main08 的旧共享响应面、offset/tilt、blade-path
和旧动态映射路线；Main09/Main11 还保留固定间隙对照入口。它们的文件名和编号会让人
误以为是当前主链，和仿真目录中旧 `Analyze_*` 仍像主程序的问题相同。

这些文件现已移动到：

`old_program/legacy_pre_pc1_20260905`

`LegacyFixed025_20251222.m` 也已移入该目录。它们按当前冻结方法视为错误入口，仅用于
历史追溯，不得用于生成最新结果。

## 当前有效的 R5 文件

- `R5_Run_R4_FrontEnd_Only_20251222.m`：唯一正式 R5 前端入口。
- `R5_Build_R4_ExperimentalSurfaceFamily.m`：构造 gap-law/PC1 波形面。
- `R5_Calibrate_B2_AnchorRegistration.m`：B2 registration。
- `R5_Localize_R4_Surface_FromLowSpeed.m`：低速 anchor 定位目标叶片面。
- `R5_Export_Main10_CompatibleLibrary.m`：执行传感器一致性、覆盖范围和 Main10 sidecar 契约。

`R45_*`、`R5_*Ablation/Diagnostic/Summarize*` 只用于验证、消融、敏感性和报告，不属于
生产主链。`R5_Run_All_20251222.m` 已归入 `analysis/.../archive_legacy_20260905`，不再
作为正式入口。
