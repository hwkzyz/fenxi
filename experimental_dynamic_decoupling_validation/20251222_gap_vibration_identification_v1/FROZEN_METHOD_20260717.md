# 20251222 V1 正式方法冻结说明

冻结标识：`20251222_V1_FROZEN_20260717`

本文件固定 Main09 Foundation 和 Main10 GapAware 的正式方法边界。后续对
R4 W18等异常窗口进行分析时，应建立独立诊断程序；未经重新完成R1、R7、R4
全窗口回归，不直接改变本文件所列设置。

## 共同数据约定

- 数据集：`20251222/1000_2500_3500`。
- 低速模板：第2–21圈，共20圈，三个传感器采用同一圈段。
- OPR：每圈6个事件，使用实测非等间隔槽角；高速到低速槽序偏移为`-2`。
- 分析传感器：CH1、CH2、CH3。
- 窗口：目标20圈、每窗3圈、步长1圈，共18个独立窗口。
- 区域：R1=B1/50.2 s/EO14，R7=B1/39.2 s/EO15，R4=B5/31.9 s/EO18。
- 搜索频率：`300–1000 Hz`；不加入应变EO先验，不固定目标EO。
- `eta_s=0`，不作为高速辨识变量。
- VP阶段允许灵敏度加权；最终完整电压波形残差不加权。

## Foundation固定间隙方法

正演模型为

`V = T_s,b(x - dx_c - A sin(EO theta + phi))`。

- 每个窗口独立辨识`EO、A、phi、dx_c`。
- 不辨识`dg_s`，也不调用GapAware候选EO。
- 全EO VP扫描后采用`adaptive_full_fit`候选策略。
- 最终候选由普通未加权完整电压残差决定。
- Foundation结果同时保存完整原始波形点束，供两种方法使用同一观测样本。

## GapAware间隙-振动联合方法

- 主模型仅为`gap_only`，不释放`dmu_s`或`dtau_s`。
- 每个窗口独立辨识`EO、A、phi、dx_c、dg_1、dg_2、dg_3`。
- 只使用GapAware自己的全EO加权VP Top-3；不加入NoGap Top-K、相邻EO或
  强制EO。
- 三个候选EO分别完成间隙正演优化，再由普通未加权完整电压残差选EO。
- 每个候选允许`±2 Hz`连续频率细化。
- `dx_c`参考采用当前窗口Top-3种子的`seed_median`，不使用前一窗口状态。
- Foundation在Main10中只提供共同原始波形点束和同一低速模板；严禁继承
  Foundation拟合得到的`EO、A、phi、dx_c`。
- `dg_s`范围为`±0.25 mm`，保留既定投影限制和静态参数正则项。

## 变更规则

任何正式方法改动必须：

1. 在`diagnostics`中建立不覆盖正式结果的消融版本；
2. 同时运行R1、R7、R4的18窗口；
3. 报告EO计数、逐窗口幅值、普通RMSE、`dx_c`和三个`dg_s`；
4. 通过`Check_Program_20251222('all')`；
5. 确认有效后更新冻结标识，不静默修改现有标识下的方法。
