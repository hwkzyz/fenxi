# R5 锚点引导波形面迁移：20251222 试验接入方案

## 1. 接入原则

本方案是 `20251222_gap_vibration_identification_v1` 的旁路分析任务。原目录中的 Main01--Main13、`Config_20251222.m`、既有 `results` 和原始数据均视为只读；R5 只读取其公开结果，并将新文件写入本目录的 `results`。

R5 的闭环不是“先得到一个唯一迁移波形再识别振动”，而是：

```text
现有准备/标定结果
    -> 低速锚点与 donor 选择
    -> 候选状态族 Yhat(x;s_j)
    -> 每个 s_j 的高速 profile fit
    -> 状态-振动联合选择
    -> 选中状态下的 EO/A/phi/dx 细化
```

其中 `s` 的语义分两条：B2 使用物理 `g [mm]`；其他叶片使用 `xi`（effective state）或机械设定档位。非 B2 的 `xi` 不得在结果表中改名为局部物理 gap。

## 2. 现有程序在 R5 中扮演的角色

| 现有程序/结果 | R5 读取对象 | R5 不应做的事 |
|---|---|---|
| Main01 | `jiluOPR.mat`、`omega.mat`、叶尖时刻 | 不重新估计槽角，不假设 60 度等间隔 |
| Main02--04 | BTT 位移和应变共振证据 | 不把应变幅值当作静态 gap 真值 |
| Main05 RefBladeAnchor | `Step05_Response_Surface_20251222_RefBladeAnchor.mat` 或其 `responseSurface` | 不把 `gTrainMm` 直接当作名义物理 gap；不把所有叶片合并成绝对局部 gap 面 |
| Main06 | B2 坐标、偏置/倾斜修正结果 | 不在高速阶段重新开放自由倾角 |
| Main07 | `CorrectedGapLibrary.sensor` 中的 `g0Mm/tauMm/xScale/muGapPerXMm/a` 和低速模板 | 标定后冻结；`mu` 只作低速几何先验 |
| Main08 | `DynamicMap.Window`、低速模板、`x_points/t_points/v_points` | 不另造一套 OPR 到 x 的映射 |
| Main09 | Foundation 结果 | 作为固定 gap 基线和可选初始化，不继承其拟合参数 |
| Main10 | GapAware 结果格式和高速残差语义 | 不直接调用其 `dg_s` 作为其他叶片绝对 gap；不修改其逐窗口独立策略 |
| Main11--13 | 比较、应变验证、图形风格 | 仅复用读取和绘图约定，结果写入 R5 目录 |

## 3. R5 需要建立的标准数据合同

### 3.1 `StaticSurfaceR5`

每个传感器、每个 donor 叶片保存：

```text
blade_id
sensor_id
state_axis_type        % physical_gap_mm | effective_state
state_axis_value       % g or xi
x_b2_opr_mm
waveform_mv
surface_coeff          % optional 1, 1/g, log(g/g0) basis
support_mask
dFdx, dFds
source_file
```

B2 的 `state_axis_value` 才能写入 `gap_mm`；非 B2 另存 `nominal_gap_setting_mm`（如存在）和 `effective_state_id`，两者都不能标为局部真值。

### 3.2 `AnchorQueryR5`

由 Main07/08 结果转成统一结构：

```text
target_blade, sensor_id, x_b2_opr_mm, v_anchor_mv
opr_slot_angle_deg, slot_anchor_deg, high_to_low_offset
template_lap_range = [2 21]
scale_mu_train, scale_sigma_train
support_mask, anchor_source_file
```

锚点距离的尺度参数必须来自训练集；不得对每条波形单独 z-score，因为幅值本身可能携带状态信息。

### 3.3 `HighSpeedWindowR5`

从 Main08 `DynamicMap.Window(iw)` 或其 Foundation bundle 旁路读取：

```text
window_id, blade_id, lap_range, rpm_hz
sensor_id, x_mm, t_s, v_mv, valid_mask
```

`x_mm` 必须与模板/静态面使用同一个 B2 OPR 坐标。动态前向模型只允许在此坐标上加入：

\[
x_{model}=x_{mm}-dx-u_x(t;EO,A,\phi).
\]

弯曲振动已经进入 x 位移，不得在 R5 前处理阶段从电压或 x 中另行扣除。

## 4. 在现有链路中的具体插入位置

### 阶段 A：只读准备和合同检查

R5 首先读取 `Config_20251222` 的路径和 OPR 配置，但在 `R5_Config_20251222.m` 中复制为只读快照。检查：

1. Main05 响应面、Main07 低速模板、Main08 DynamicMap 是否来自同一数据集和目标叶片；
2. `x` 单位、B2 槽角、槽偏移、传感器编号是否一致；
3. 低速模板是否确实为第 2--21 圈；
4. 每个窗口是否有足够支持点，且没有超出静态面支持域。

这一阶段只生成 `R5_InputContract.csv`，不修改任何源 MAT 文件。

### 阶段 B：建立 donor 面和 transition library

1. B2：直接读取 Main05 面，在物理 gap 网格 `g_j` 上计算 `F_B2(g_j,x)` 和 `DeltaF_B2(g_a->g_j,x)`。
2. 非 B2：利用静态库中每个叶片的观测波形或 per-blade surface，在 `xi`/设定档位轴上建立 `F_b(xi_j,x)`；不得使用“B2 名义 gap 轴”这个名称。
3. 对每个 donor 保存 `DeltaY_b(a->t,x)`、支持掩膜、donor 间离散度和来源状态。
4. 目标 gap/状态留出时，先切分数据，再拟合面和增量；留出状态不得参与尺度估计、donor 选择或超参数选择。

现有 `analysis/static_waveform_manifold_20260901` 中的 Step15/per-blade surface 可以作为诊断输入，但 Step03 的 absolute affine gap path 不作为 R5 物理定位器。

### 阶段 C：低速锚点和 donor 选择

对目标叶片的低速模板，在同一 B2 OPR x 轴和支持掩膜上计算 donor 起始状态距离：

\[
D=w_VD_V+w_{dV}D_{dV/dx}+w_pD_{phase}+w_AD_A.
\]

建议先保留 Top-2/Top-3 donor。`D_V` 使用训练集固定传感器尺度；相位项只检查 OPR/x 合同，不允许通过非 B2 独立峰值平移制造“更近”的 donor。

此步骤只确定“从哪个状态出发”和 donor 权重，不能确定高速目标状态。

### 阶段 D：生成候选状态族

对每个候选目标状态 `s_j` 分别生成：

\[
\hat Y(x;s_j)=Y_a(x)+\sum_k w_k C_k\Delta Y_k(a\to s_j,x),
\]

其中 `C_k` 是固定尺度下的幅值修正。候选状态先采用静态库支持范围内的离散网格；只有 profile 曲线单峰且通过可辨识性门禁，才在邻域连续细化。

每个候选必须记录：`state_axis_type/value`、donor 列表、权重、支持比例、幅值修正、`D_manifold` 和不确定度。若加权波形远离训练流形，不输出该候选，而不是继续平滑外推。

### 阶段 E：高速逐状态 profile fit

R5 新建独立的 `R5_ProfileFit_StateVibration_20251222.m`。它读取 `HighSpeedWindowR5` 和候选波形族，对每个 `s_j` 单独求：

\[
J_w(s_j)=\min_{EO,A,\phi,dx}\sum_{i,s}r_{i,s}^2,
\quad
r_{i,s}=v_{i,s}-\hat Y_s[x_{i,s}-dx_s-u_{i,s}(EO,A,\phi)].
\]

实现上可复用 Main10 的参数边界、VP Top-K、频率细化和电压残差定义，但不能直接调用 Main10 的脚本局部函数；R5 应在旁路目录中提供独立 evaluator。`dg_s` 在 R5 中只作为候选状态标签或有效增量，不再作为自由物理 gap 变量。

### 阶段 F：状态—振动联合选择

先保存每个窗口的完整 `J_w(s)` profile，而不是只保存最小值。然后求：

\[
\arg\min_{s_1,\ldots,s_W}
\sum_w J_w(s_w)+\lambda_s\sum_{w>1}(s_w-s_{w-1})^2.
\]

`lambda_s` 必须由训练状态/重复性数据确定。若跨越转速或热状态，优先采用 `s=f(rpm,temperature)` 的先验；不能把窗口编号平滑直接解释为间隙变化。

对每个候选计算：

```text
rho_sx = corr(dY/ds, dY/dx)
cond(J_joint) or sigma_min(J_joint)
profile_margin = J(second) - J(first)
state_jump = |s_w - s_(w-1)|
```

当状态方向和 x 位移方向高度相关、profile 没有唯一极小值或 Jacobian 条件数超过重复性阈值时，输出 `state_unidentifiable`，保留 Top-K 候选，不强行选择物理状态。

### 阶段 G：选中状态后的 Main10 类细化

只有通过阶段 F 的状态门禁后，才对 `s_w*` 做 EO、幅值、相位和 `dx` 的最终细化，并输出与 Main10 对齐的结果表。结果字段至少包括：

```text
window_id, blade_id, sensor_id
state_axis_type, state_axis_value, state_confidence
EO, frequency_hz, amplitude_mm, phase_rad, dx_mm
rmse_mv, waveform_support, rho_sx, jacobian_cond
```

多传感器结果先逐传感器计算，再做稳健融合；单传感器 `state_axis_value` 不自动升级为整机 gap。

## 5. 与现有 Main10 的关系

R5 第一版不替换 Main10，而是建立三种并行结果：

1. `Foundation_baseline`：直接读取 Main09；
2. `Main10_original`：原程序原样运行并读取其结果；
3. `R5_candidate_profile`：R5 生成候选状态族后，在独立 evaluator 中完成状态—振动选择。

若需要验证“R5 迁移是否改善 Main10”，可将 R5 选中的候选波形作为 Main10 等价前向模型的初值进行旁路比较，但不得改写 Main10 的候选集和结果文件。

## 6. 试验验证顺序

### V0 输入合同

验证 Main05/Main07/Main08 坐标、单位、模板圈段和窗口索引一致；不通过则停止后续识别。

### V1/V2 迁移算子

先做同叶片迁移和留一 gap，分别输出：

- `Y_anchor`、真实目标静态波形、`Yhat(s_true)`、残差；
- 候选状态族及其 profile 距离；
- P50/P90 相对 RMSE、峰值电压和峰位置误差。

V1-M/V2-M 只评价迁移本身；V1-C/V2-C 才允许把观测波形通过固定 profile evaluator 用来选择未知状态。

### V3 留一状态

留出一个圈段、运行状态或窗口，检查 OPR 对齐误差是否被错误吸收到状态变化中，并检查状态慢变约束。

### V4 留一叶片

donor 完全排除目标叶片；目标叶片最多提供低状态锚点。结果是跨叶片 effective-state 迁移诊断，不是绝对局部 gap 真值验证。

### V5 低速到高速闭环

在 R1/B1/EO14、R7/B1/EO15、R4/B5/EO18 的 18 个窗口上，依次运行 Foundation、原 Main10 和 R5。每个窗口必须保存 `J_w(s)` 曲线、Top-K 状态、联合拟合波形和残差图。EO、频率、幅值和 RMSE 的既有一致性门槛只能作为工程闭环指标，不能表述为独立动态真值。

## 8. 最终判定边界

- B2：若 profile 唯一、Jacobian 可辨识且 V1/V2/V5 通过，可报告物理 `g` 的估计和误差。
- 非 B2：最多报告 `effective_state`、相对迁移量、候选排序和不确定度；没有独立局部间隙测量时，不报告 `g_B5` 等绝对值。
- 倾角：Main07 的低速 `mu` 可作为冻结先验；高速残余 `dmu/q` 只能作为 tilt-like residual 诊断。不能从单个高速电压窗口推出结构倾角。

因此，真正的第一版实施顺序是：V0 合同检查 → B2/非 B2 双轨 transition library → V1/V2 迁移验证 → 候选状态 profile search → V3/V4 可辨识性 → V5 低速到高速闭环。整个过程均在 `analysis/r5_anchor_guided_experimental_20260903` 旁路目录完成，不覆盖原程序。

## 9. 当前旁路实现与实测状态

已实现的可执行入口为 `R5_Run_All_20251222.m`。它读取 Main05 RefBladeAnchor、Main07 低速模板，并可在显式指定 Main08 DynamicMap 后读取单个高速窗口；所有结果写入 R5 自有 `results` 目录。当前已通过 MATLAB 烟雾测试：

- V0：`801 x 6 x 16` 静态面，电压单位为 mV，公共支撑率约 `0.7241`；
- Main07 锚点：B1/CH1，低速模板圈段 `2--21`；
- 同叶片静态迁移：中位相对 RMSE `0.1161`；
- 真正留出整个状态档的间隙插值：中位相对 RMSE `0.0871`，支撑不足的边界档会单独标记；
- 留一叶片：中位相对 RMSE `0.2079`，只作为跨叶片 effective-state 诊断；
- Main08 窗口 profile：已生成观测/预测图；电压合同修正后示例窗口通过局部可辨识性检查，但仍仅为 `identifiable_window_only`，不能部署或解释为物理倾角。

当前 Main08 自动发现若找到多个 DynamicMap 会主动报歧义，必须由研究者显式选择窗口来源，避免把不同转速/共振区间混入同一闭环。V5 批处理应使用 `R5_V5_LowHigh_Closure.m`，并逐窗口保存状态、EO、振幅、RMSE、支撑率和门控原因。

### 电压合同修正后的 B1/R1 18 窗口闭环

2026-09-03 已对 `Step06_DynamicMap_20251222_B1_S123_R01_T00039p200_L20_W03_S01_PW0p00060.mat` 的 18 个窗口执行 V5。Main07/Main08 原始电压均采用 Main10 同一合同 `(V-baseline)*1000` 转为 mV 后再与 Main05 波形面比较；此前未转换的原型结果一律无效。

- 所有窗口的联合选择为 `effective_state=3`，而不是可报告的物理间隙；
- 振幅范围约 `0.082--0.248 mm`，逐窗 RMSE 为约 `102--127 mV`；
- 全部窗口通过当前的局部 Jacobian/边界检查，因此标记为 `identifiable_window_only`；
- 该标签**不是部署结论**。它没有独立的 B1 局部 gap 动态真值、多传感器融合一致性门槛，且 V1/V2 的现有指标尚未定义预注册阈值。因此该闭环目前是仿真/试验诊断信息，不能升级为“非 B2 局部物理间隙”或“结构倾角”结果。
