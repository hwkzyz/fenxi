# Step03_01 直接低速模板波形优化方法说明

对应程序：

```text
Step03_01_Run_DirectLowSpeedWaveform_20250527.m
```

这是当前主程序，也是当前文件夹中的无先验基线方法。

## 方法定位

`Step03_01` 不使用任何候选加速。它对每个滑动窗口内的所有整数 EO 候选都执行完整低速模板波形优化，然后用优化后的加权波形 RMSE 选择最终 EO。

该方法用于回答一个最基础的问题：

```text
如果不引入 EO 先验、不用 VP 加速、不用间隙库，仅靠低速模板完整波形匹配，能否稳定辨识正确阶次和频率？
```

## 输入数据

程序读取两个文件：

```text
output/templates/Template_LowSpeedRotating_B1_<sensor_tag>_20250527.mat
output/dynamic_maps/DynamicMap_B1_<sensor_tag>_SlidingWindows_20250527.mat
```

其中：

- `Template` 来自 Step01，包含每个传感器的低速模板 `T_s(x)`。
- `DynamicMap` 来自 Step02，包含每个滑动窗口内的动态波形点、时间、转角、局部坐标和权重。

## 核心模型

对每个传感器和每个动态采样点，预测电压为：

```text
u(theta) = A * sin(EO * theta + phi) + d0
V_pred = T_s(x - u(theta))
```

其中：

- `EO` 是整数阶次候选。
- `theta` 是转角。
- `A` 是振动幅值。
- `phi` 是相位。
- `d0` 是平均位移偏置。
- `T_s` 是传感器 `s` 的低速模板。

## 每个窗口的计算步骤

1. 构建当前窗口的模板观测包 `bundle`。
2. 根据 `100-1000 Hz` 和窗口平均转频生成所有整数 EO 候选。
3. 对每个 EO，先用模板反查得到一个初值表 `seed_table`。
4. 对每个 EO 都执行完整波形优化：

```text
min_{A, phi, d0} sum_i w_i * (V_i - T_s(x_i - A sin(EO theta_i + phi) - d0))^2
```

5. 对每个 EO 记录优化后的 RMSE。
6. 按 `weighted_voltage_rmse` 从小到大排序。
7. 选择 RMSE 最小的 EO 作为窗口辨识结果。

## 为什么没有先验

该方法没有使用旧结果中的 EO 或频率。EO14 不是预先指定的，而是在所有 EO 完整优化后由 RMSE 排名选出的。

程序中仅保留以下问题定义参数：

- 频率搜索范围 `100-1000 Hz`。
- 单频同步模型。
- 幅值和偏置边界。

这些属于辨识问题的搜索范围和物理模型设置，不是答案先验。

## 优点

- 结果最容易解释。
- 所有 EO 公平竞争。
- 适合作为其他加速版本的正确性基线。

## 缺点

- 每个窗口都要完整优化所有 EO，速度最慢。
- 当前每个窗口约 `22` 个 EO 候选。

## 当前验证结果

在当前数据上，运行 `S13` 和 `S136`：

```text
S13  : 18 个窗口全部 EO14，平均频率约 580.223499 Hz
S136 : 18 个窗口全部 EO14，平均频率约 580.223365 Hz
```

完整批处理约 `23.209 s`，对应 `36` 个窗口。
