# R5 / V1 方法改进记录

本记录只记录程序合同、可复现实验结果和导致参数变化的原因。应变数据不进入任何辨识目标函数；应变只在盲辨识完成后作为独立后验校核。`referenceEO` 只能作为审计字段，不能锁定最终 EO。

## 基线：V1 `gap_only`

V1 的动态合同由旧 `gap_only` 保留：V1 观测点、传感器 `eta`、低速模板、每传感器 `xScale/tau/mu/gain`、VP 候选、相位公式和完整波形目标。20241106 的 18 个窗口均为 EO12，频率 631.39--632.40 Hz，振幅 0.337--0.386 mm，RMSE 约 36--41 mV。20250527 B1 的 V1 结果均为 EO14，频率 580.20--580.36 Hz，振幅 0.397--0.406 mm，RMSE 56.18--63.93 mV。

## 改进 1：V1 外壳 + R5 间隙增量

混合正向模型定义为

`Vpred = Vlow_V1(x_current) + [F_R5(g0+dg,x_R5)-F_R5(g0,x_R5)]`。

V1 的静态空间注册和冻结基线不得被 R5 模板再次施加。适配层现在保存 V1 模板、传感器标定、响应面和 `g0BySensor`；公共 evaluator 增加冻结 V1 静态项 `F_V1(g0)-F_V1(gref)`。零间隙和模板回放由静态审计门禁检查。

## 改进 2：静态支撑审计

审计查询现在与响应面 x 域和有效间隙域求交，并为有限差分导数保留内部裕度，避免把端点舍入误判为模型错误。该修改不改变优化目标，只防止越界数据进入动态拟合。

## 结果 1：20241106 B4

V1 外壳 + R5 增量运行通过：18 个窗口仍全部 EO12，频率 631.39--632.38 Hz，振幅 0.336--0.386 mm，RMSE 38.5--47.5 mV。说明在该工况，频率合同和振幅尺度能够从 V1 稳定迁移到 R5。

## 结果 2：20250527 B1（尚未通过）

 未加入 V1 冻结静态间隙项时，结果为 EO19、约 788 Hz、振幅上限附近、RMSE 约 2.3 V；加入该项后 RMSE 降至 60--67 mV，但仍选 EO19（约 787.6 Hz），而 V1 为 EO14（约 580.2 Hz）。逐传感器桥接显示 R5 响应系数与 V1 响应面存在明显差异，故该结果暂不能作为正式参数。下一步必须先完成 V1/R5 间隙增量的逐点尺度和符号审计，再决定是否采用该 R5 库。

固定第一窗口 V1 参数（EO14、580.362 Hz、A=0.3981 mm、`dx=0.1349 mm`）进行桥接时，混合模型残差约 401 mV；按传感器分别为约 106、521、443 mV。该测试排除了优化器本身是唯一原因，表明 R5 增量算子仍未与 V1 的传感器增量合同对齐。该固定参数桥接结果已作为后续修正的回归基线。

新增增量审计后发现，20250527 第一窗口 V1 的 `dg` 主要只在 S3 非零；S3 的 R5/V1 增量 RMS 比约 0.71、相关系数约 0.99，说明 S3 主要是增量幅值尺度不一致，而不是波形频率不一致。S1、S6 的 V1 `dg` 为零，但混合桥接仍存在约百 mV 级差异，说明这两个通道的剩余误差来自模板/坐标/静态基线合同，不能通过调 `dg` 解释。该结果进一步支持先修正静态观测合同，再进行 EO 搜索。

## 结果 3：20251222 B1（尚未通过）

当前初始混合运行得到 EO10、416.08--416.12 Hz、振幅 0.114--0.147 mm、RMSE 543--551 mV，明显不满足 V1 频率稳定性门槛。该结果仅为失配诊断，不是正式结果。

## 当前验收门槛

1. V1 自回放逐点一致；
2. `dg=0` 时混合算子与冻结 V1 基线合同一致；
3. 静态审计、支撑域和单位检查通过；
4. 三个工况分别进行全 EO 候选诊断，最终 EO 不得靠应变或预设 EO 强行选择；
5. 频率先满足 V1 同模态稳定性，再讨论振幅及应变传递比；
6. 每次修改都保存 EO、频率、振幅、RMSE 及与 V1 的差异。

截至本记录日期，只有 20241106 达到频率稳定门槛；20250527 和 20251222 仍处于 R5 增量算子接口审计阶段。

## 理论收拢：为什么 V1 能成功、R5 不能直接替换

重新核对旧程序后确认，V1 成功的关键不是“优化器找到了一个较低 RMSE”，而是整个动态辨识始终使用同一个已经通过低速标定的观测算子：

`xEval = X - eta_s - dx - u(t)`，

`V = Vlow_V1(xEval) + gain_s * [F_V1(g0_s+dg_s,xReg)-F_V1(g0_s,xReg)]`。

因此 V1 的 EO/f/A 变化会直接反映在同一组传感器模板和同一组响应面上，频率候选的比较是自洽的。当前 R5 混合版虽然保留了 V1 的外壳，但把整个 `[F(g0+dg)-F(g0)]` 换成了另一套系数、另一套有效间隙和注册路径；这会改变每个 EO 候选的波形残差，故不能把 V1 的频率稳定性自动继承过来。

后续正式方法应采用“V1 动态算子为辨识主链，R5 为静态间隙理论的增量校核/替换实验”两层结构：先用 V1 合同完成 EO、f、A、phi、dx 的盲辨识，再在相同 `xEval`、`g0` 和单位合同下计算 R5 增量并报告替换造成的参数变化。只有当固定 V1 参数下 R5 增量逐点桥接通过，才允许把 R5 增量放入正式优化。这样频率正确性由已验证的 V1 主链保证，新理论则通过可审计的间隙增量逐步引入，而不是一次性改变频率判别基准。

## 与最新仿真逻辑的对照

最新仿真程序的辨识主方程是绝对响应面 `V=F(g_high,x-d-u)`，低速波形只用于建立 `F(g_low,x)` 的静态基准；位移初值由 `-(V-F)/F_x` 得到，再用 VP 搜索 EO，最后用完整电压波形精修。当前实验混合版仍以 V1 的差分结构为外壳，再叠加 R5 差分增量，因此它不是最新仿真的绝对响应面合同。这个差异解释了为什么 20241106 可以迁移，而 20250527/20251222 会改变 EO 排名。

后续改进应按仿真逻辑增加一个独立的绝对响应面诊断链：在不改变 V1 正式结果的前提下，使用同一 `F(g,x)` 和 `F_x(g,x)` 生成位移初值、执行全 EO VP 排序，并与 V1 候选逐窗比较。只有该绝对链在无噪声回放和固定 V1 参数桥接上通过，才考虑替换正式动态算子；否则 R5 仅作为后验间隙增量分析。

## 本轮程序收口：V1/R5 逐窗对比接口

新增 `R5_Compare_V1_R5_Identification_20260912`。该函数只读取两套结果文件，按窗口输出 `EO、f、A、RMSE` 及差值；不读取应变、不锁定 EO，也不参与候选选择。它用于记录每次 R5 改动相对于 V1 的影响，避免只比较总 RMSE 而遗漏频率或振幅漂移。正式判读仍遵循：先检查 V1 自回放和频率稳定，再检查 R5 静态增量桥接，最后才进行应变后验验证。
