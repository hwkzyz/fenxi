# 超高斯模型与间隙解耦模型的对比分析设计

## 1. 对比目标

这个对比不要直接问“哪个方法更接近实验结果”，而要问：

```text
1. clean / noise_only 时，超高斯与间隙路线是否都能无偏恢复 A_true？
2. 加入 CH6 静态 gap 偏移 dg6 后，超高斯是否会把静态误差折算成振动？
3. 加入 CH6 tilt-like 偏移 dmu6 后，gap_fixed_tilt 是否会偏高，而 residual dmu 是否会吃振动？
4. S13 与 S136 的差异是否主要由 CH6 引入？
5. residual dmu 的改善是物理解释，还是仅仅降低电压残差？
```

因此分析应分为两条线：

```text
受控仿真线:
  有 A_true, dg6_true, dmu6_true，用于判别偏差机制。

实验复现线:
  无真值，只比较超高斯 S13/S136 与 gap 路线 S13/S136 的幅值趋势。
```

## 2. 方法命名

建议在仿真表格里统一命名：

```text
superGaussian:
  对应 Step5 超高斯位移拟合；
  在当前仿真中可由 fixed/no-gap superGaussian kernel 表示；
  不允许 dg，不允许 dmu。

gap_fixed_tilt:
  当前 gap_only；
  允许 dg_s；
  固定 mu_s = 低速标定 corr.muGapPerXMm；
  主结果模型。

gap_tilt_residual_raw:
  当前 gap_tilt；
  允许 dg_s + residual dmu_s；
  只作为未保护诊断。

gap_tilt_residual_safe:
  两阶段正交残余 dmu；
  Stage 1 输出 A；
  Stage 2 只诊断 residual dmu，不回改 A。
```

## 3. 仿真工况矩阵

第一组是标定/基线工况：

```text
clean:
  dg6 = 0
  dmu6 = 0
  noise = 0
  目的：验证各方法在理想情况下都能恢复 A_true。

noise_only:
  dg6 = 0
  dmu6 = 0
  noise = 实验量级
  目的：验证噪声不会造成 5%-15% 的幅值差异。
```

第二组是机理工况：

```text
ch6_static_dg:
  dg6 != 0
  dmu6 = 0
  目的：检验超高斯是否把 CH6 静态间隙误差折算成 A；
       检验 gap_fixed_tilt 是否能恢复 A；
       检验 raw residual dmu 是否会错误拉低 A。

ch6_tilt_dmu:
  dg6 = 0
  dmu6 != 0
  目的：检验真实 tilt-like 偏移对各模型的影响；
       评估单窗口高速电压能否无偏区分 A 和 dmu。

ch6_dg_dmu:
  dg6 != 0
  dmu6 != 0
  目的：模拟最接近实验的混合 CH6 静态波形误差。
```

第三组是稳健性工况：

```text
dmu_limit sweep:
  dmu_limit = 0, 0.001, 0.003, 0.005, 0.01, 0.03, 0.08
  目的：检查 A 是否随 dmu 上限漂移。

noise sweep:
  noise_scale = 0, 0.5, 1, 2
  目的：检查偏差是否由噪声驱动。

amplitude sweep:
  A_true = 0.2, 0.3, 0.37, 0.45 mm
  目的：检查耦合是否随振动幅值增强。
```

## 4. 传感器组合必须成对比较

每个工况都至少跑：

```text
S13  = [1,3]
S136 = [1,3,6]
```

判据：

```text
如果 S13 clean/noise 稳定，而 S136 在 CH6 偏移工况下偏差明显，
说明传感器组合是差异源。

如果超高斯 S136 比 S13 高，而 gap_fixed_tilt 能拉回，
说明超高斯把 CH6 静态误差折算进了 A。

如果 raw gap_tilt S136 比 gap_fixed_tilt 低，
说明 residual dmu 有吃振动风险。
```

## 5. 公平比较的关键

超高斯和 gap 路线必须使用同一组：

```text
sensor set
window / lap range
blade id
EO = 14
X / Theta / W 采样骨架
noise realization
```

否则不能解释为方法差异。

实验结果中尤其要避免：

```text
超高斯用 S13；
gap 路线用 S136。
```

这会把传感器组合差异误认为模型差异。

## 6. 指标

有真值的仿真指标：

```text
A_error_percent = 100 * (A_id - A_true) / A_true
dg6_error       = dg6_id - dg6_true
dmu6_error      = dmu6_id - dmu6_true
RMSE            = 电压拟合残差
dmu_bound_ratio = abs(dmu6_id) / dmu_limit
```

无真值的实验指标：

```text
A_mean
A_best_window
S136 - S13 amplitude shift
gap_fixed_tilt - superGaussian
gap_tilt_residual_raw - gap_fixed_tilt
RMSE reduction
dmu stability across windows
```

必须强调：

```text
RMSE 更低不等于 A 更可信。
```

若 `dmu` 降低 RMSE 但 A 大幅改变，这正是耦合风险。

## 9. 预期解释模板

如果仿真结果符合当前趋势，可以这样解释：

```text
clean/noise 工况下，各方法均能恢复注入 A，说明识别框架本身没有系统性低估。

当 CH6 存在静态 gap/tilt-like 偏移时，superGaussian 因不显式建模静态误差，
会把部分静态波形误差折算为振动位移，尤其在 S136 组合中表现为 A 偏高。

gap_fixed_tilt 利用低速标定 tilt 先验并只估计 dg_s，可以去除主要静态间隙偏差，
因此更适合作为主幅值结果。

raw gap_tilt_residual 允许高速自由 dmu_s，虽然能降低电压残差，但 dmu_s 与振动方向
存在投影耦合，可能把一部分振动解释为倾斜残差，导致 A 偏低。

因此 residual dmu_s 应只作为正交化后的诊断项，不应进入主振动幅值定义。
```

## 10. 最终结论应该落在哪里

最终不要写成：

```text
gap_tilt 比超高斯更准确。
```

而应写成：

```text
超高斯模型适合无显著静态波形误差或传感器组合稳定的情形；
当 CH6 引入静态 gap/tilt-like 偏移时，超高斯会产生等效位移偏差；
gap_fixed_tilt 通过低速标定先验显式处理静态 gap 偏移，是本文主结果；
高速 residual dmu 与振动不可完全解耦，仅作为诊断项。
```
