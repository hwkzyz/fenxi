# 间隙方向和倾斜方向的解耦实施方案

## 1. 参数命名

建议把当前方法重命名为：

```text
fixed:
  不估计高速 dg，不估计高速 residual dmu

gap_fixed_tilt:
  估计高速 dg_s
  固定 mu_s = 低速标定 corr.muGapPerXMm
  对应当前 gap_only

gap_tilt_residual:
  估计 dg_s + residual dmu_s
  对应当前 gap_tilt
  只作为诊断，不作为主结果
```

## 2. 静态 gap/tilt 正交支点

在每个传感器、每个窗口中计算：

```text
J_g  = dV/dg
J_mu = dV/dg * (x - tau)
```

用加权内积：

```text
<a,b>_W = sum_i W_i a_i b_i
```

计算：

```text
alpha = <J_g,J_mu>_W / <J_g,J_g>_W
J_mu_gap_perp = J_mu - alpha J_g
tau_star = tau + alpha
```

等价模型：

```text
dg_old + dmu * (x - tau_old)
= dg_star + dmu * (x - tau_star)
```

换算关系：

```text
dg_star = dg_old + dmu * (tau_star - tau_old)
dg_old  = dg_star - dmu * (tau_star - tau_old)
```

实际辨识使用 `dg_star`，因为它与 `dmu` 在当前窗口的一阶电压度量下正交。

## 3. 保护振动幅值

静态正交只能解耦 `dg` 和 `dmu`。还必须保护振动方向：

```text
J_q = [J_A, J_phi, J_dx_or_d0, J_g]
J_mu_safe = (I - P_Jq) J_mu
```

其中 `P_Jq` 是加权投影。实际实现采用两阶段：

```text
Stage 1:
  拟合 q = [A, phi, dx/d0, dg_s]
  dmu_s = 0
  输出 A

Stage 2:
  固定 q
  在残差 r = V_obs - V_pred(q) 上拟合 J_mu_safe dmu_res
  输出 dmu_res 作为诊断
```

## 4. 为什么不能直接让 dmu 进入主优化

因为：

```text
x_eval = X - dx - A sin(EO theta + phi) - eta
J_mu ~ F_g * (x_eval - tau)
```

`J_mu` 中含有与 `A sin(...)` 同频的部分。若在主优化中自由估计 `dmu`，优化器可以用：

```text
减小 A + 改 dmu + 改 dg
```

来降低残差。这样得到的 `A` 不再是独立振动幅值。

## 5. 不能被高速数据单独解决的部分

分解：

```text
J_mu = P_Jq J_mu + J_mu_safe
```

`P_Jq J_mu` 与主参数完全混叠。只靠同一个高速电压窗口无法判断它来自真实 tilt
还是来自振动/间隙变化。能安全估计的只有 `J_mu_safe`。

因此如果真实 residual tilt 很强，且大部分落在 `P_Jq J_mu` 中，就必须依赖外部信息：

```text
低速 tilt 标定；
跨窗口共享 dmu_s；
独立应变/FE 幅值参考；
传感器剔除或降权；
改变传感器几何组合以降低 J_mu 与 J_A 的相关性。
```

## 6. 对当前实验的建议

当前最可信的主结果应来自：

```text
gap_fixed_tilt / 当前 gap_only
```

当前 `gap_tilt` 应报告为：

```text
gap_tilt_residual diagnostic
```

如果后续要改 Step07J，建议先加两个输出：

```text
gap_fixed_tilt_main_A
gap_tilt_residual_diagnostic_dmu_safe
```

不要让 `gap_tilt_residual` 覆盖主幅值。
