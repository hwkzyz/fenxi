# 仿真分析路线与判据

## 1. 仿真的目的

这个仿真不应只用来说明某个方法“结果更接近真值”，而应回答四个可判别问题：

```text
Q1. 无静态误差时，三种方法是否都能恢复注入振动 A_true？
Q2. 只有 CH6 静态间隙偏移 dg6 时，gap_fixed_tilt 是否能恢复 A_true？
Q3. 加入 residual dmu 后，A 变小是物理倾斜，还是 dmu 吃掉振动？
Q4. 如果真实存在 tilt-like 偏移，单靠高速电压能不能无偏恢复 A？
```

对应的结论边界：

```text
能证明:
  当前 gap_tilt 的幅值降低有结构耦合机制；
  gap_fixed_tilt / 当前 gap_only 更适合作为主幅值；
  residual dmu 应作为诊断，不应进入主幅值定义。

不能证明:
  高速自由 dmu 就是真实物理倾斜；
  单窗口高速电压可同时无偏识别 A、dg、dmu。
```

## 2. 第一层：看基准恢复能力

先看 clean / noise_only：

```text
文件:
output/Step02_voltage_bias_detail.csv

判据:
clean 情况 A_error 应接近 0；
noise_only 情况 A_error 应远小于实验差异，例如 < 1%。
```

如果 clean 都恢复不了，说明仿真模型或优化器本身有问题；当前结果 clean 是通过的。

## 3. 第二层：看纯 dg6 情况

关键看：

```text
case = ch6_static_dg 或 dg_clean / dg_noise
```

希望看到：

```text
gap_fixed_tilt / gap_only:
  A 接近 A_true
  dg6 接近注入值

current gap_tilt:
  如果独立优化后 A 变小、dg6 变小、dmu6 非零，
  说明 residual dmu 进入了错误局部盆地或耦合通道。
```

这层回答的问题是：

```text
纯静态间隙误差本来不应导致 A 下降；
A 下降来自 residual dmu 的不良自由度。
```

建议报告 Step04 的三个对比：

```text
independent gap_tilt
gap_only_zero_dmu_start
truth_start
```

如果 `truth_start` 和 `gap_only_zero_dmu_start` 可以恢复真值，而 `independent` 不行，
说明问题主要是不可辨识/局部极小，而不是模型物理上不允许正确解。

## 4. 第三层：看 dmu 与振动方向的耦合

关键看：

```text
output/Step03_jacobian_coupling.csv
output/Step06_gap_tilt_direction_decoupling.csv
```

判据：

```text
proj_dmu_on_vib 或 proj_tilt_on_vib_raw 越大，
dmu 越容易吃掉 A / phi / d0。

proj_tilt_on_protected_vib_gap 越大，
说明 dmu 与 [A, phi, d0, dg] 整体不可分。
```

当前 S136 CH6 的典型结论：

```text
dg 与 dmu 的直接静态相关不大；
dmu 与振动子空间的投影较大。
```

所以论文里应强调：

```text
主要问题不是 dg-dmu 静态互相混；
主要问题是 residual dmu 与振动幅值方向混。
```

## 5. 第四层：看保护式 residual dmu

关键看：

```text
output/Step05_orthogonalized_residual_tilt.csv
output/Step07_protected_two_stage_residual_tilt.csv
```

分析方式：

```text
Stage 1:
  gap_fixed_tilt 报告主 A

Stage 2:
  A locked，拟合 safe residual dmu
```

判据：

```text
纯 dg6:
  safe residual dmu 应接近 0；
  A 不应被拉低。

真实 dmu6:
  safe residual dmu 可以显著非零；
  但 A 仍不回改。
```

这层用于支撑方法选择：

```text
主幅值 = gap_fixed_tilt
residual dmu = 诊断项
```

## 6. 第五层：看传感器组合

必须分开比较：

```text
S13
S136
```

重点看 CH6 引入后的变化：

```text
S13: 不含 CH6，作为参照
S136: 含 CH6，检查是否出现 A 偏高或 gap_tilt A 偏低
```

若只有加入 CH6 后超高斯或 fixed/gap_only 显著变化，说明传感器组合本身就是主要差异源。

这正好解释实验现象：

```text
超高斯 S13 与 gap_tilt 差距小；
超高斯 S136 被 CH6 拉高；
当前 gap_tilt 又被 residual dmu 拉低。
```

## 8. 论文中可用的逻辑链

建议写成：

```text
1. 用实验应变频谱构造 EO14 的真值幅值区间；
2. 用实验 Step5 采样骨架构造受控电压仿真；
3. clean/noise 验证说明识别框架本身能恢复 A；
4. CH6 静态偏移会导致不考虑 gap 的方法幅值偏差；
5. residual dmu 与振动方向存在投影耦合，会把 A 拉低；
6. 因此主方法固定低速 tilt 标定，只估计 dg；
7. residual dmu 只作为正交化后的诊断项。
```

## 9. 结论判据

最后用下面三个判据决定方法是否合理：

```text
主幅值可信:
  gap_fixed_tilt 在 clean/noise/pure dg 中 A_error 小；
  跨传感器组合变化可解释；
  不依赖 residual dmu 自由度。

residual dmu 可信:
  A locked 后仍显著降低残差；
  dmu 不贴边界；
  跨窗口稳定；
  符号与低速标定/几何一致。

current gap_tilt 不适合作主结果:
  A 随 dmu_limit 或初值明显变化；
  纯 dg6 情况也可出现 A 下降；
  dmu 与振动子空间投影较大。
```
