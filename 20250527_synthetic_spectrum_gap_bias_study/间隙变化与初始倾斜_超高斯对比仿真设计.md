# 间隙变化与初始倾斜对不同方法辨识影响的仿真设计

## 1. 重新定义问题

这里不应把重点放在“高速 residual dmu 是否很大”。更合理的问题是：

```text
真实实验中存在：
1. 初始安装/标定时就存在的传感器倾斜 mu0；
2. 高速工况相对低速标定产生的静态间隙变化 dg；
3. 传感器组合差异，尤其 CH6 是否引入更强静态波形误差。
```

因此仿真要研究的是：

```text
初始倾斜 + 间隙变化 会如何投影到不同方法识别的振动幅值 A 上？
```

而不是先假设高速有很大的自由 `dmu`。

## 2. 概念区分

必须区分三类倾斜：

```text
mu0:
  初始就存在的物理倾斜；
  应由低速标定得到；
  是 gap_fixed_tilt 的已知物理先验。

mu_cal_error:
  低速标定误差；
  即方法使用的 mu_cal 与真实 mu0 不一致；
  可作为不确定度敏感性分析。

residual dmu:
  高速额外自由倾斜；
  不是主研究对象；
  只作为诊断项或对照项。
```

所以主仿真应写成：

```text
truth:  V = F(g0 + dg, mu0, x - u)
method: 使用不同模型去识别 A
```

而不是：

```text
truth:  V = F(g0 + dg, mu0 + dmu_free, x - u)
```

## 3. 方法分组

建议对比四类方法：

```text
superGaussian:
  不显式估计 dg；
  不使用 mu0 物理先验；
  静态间隙/倾斜造成的波形变化可能折算进位移 A。

fixed:
  不估计高速 dg；
  若模板已包含低速初始倾斜，则只能处理“标定状态”；
  对高速间隙变化仍敏感。

gap_fixed_tilt:
  当前 gap_only 的论文命名；
  估计高速 dg；
  固定 mu = mu_cal；
  这是主线模型。

gap_tilt_residual:
  估计 dg + residual dmu；
  只作为诊断/对照，不作为主幅值。
```

## 4. 仿真工况矩阵

### A. 基线标定工况

```text
clean:
  dg = 0
  mu0 = 0 或 mu0 = mu_cal
  noise = 0

noise_only:
  dg = 0
  mu0 = mu_cal
  noise = 实验量级
```

目的：

```text
证明在无高速间隙变化、倾斜被正确标定时，各方法不应系统性低估 A。
```

### B. 间隙变化工况

```text
global_gap:
  所有传感器同向 dg

ch6_gap:
  只有 CH6 有 dg6

mixed_sensor_gap:
  CH1/CH3/CH6 有不同 dg_s
```

目的：

```text
研究静态间隙变化是否会被 superGaussian/fixed 折算为 A；
验证 gap_fixed_tilt 估计 dg 后是否能恢复 A。
```

### C. 初始倾斜工况

```text
known_initial_tilt:
  truth mu0 != 0
  method mu_cal = mu0

tilt_calibration_error:
  truth mu0 != 0
  method mu_cal = mu0 + delta_mu_cal
```

目的：

```text
区分“初始倾斜被正确标定”与“倾斜标定误差”。
如果 mu_cal = mu0，gap_fixed_tilt 不应因为初始倾斜而偏；
如果 mu_cal 有误差，误差可按不确定度传播到 A。
```

### D. 间隙变化 + 初始倾斜

```text
dg + known_initial_tilt:
  truth dg != 0, mu0 != 0
  method mu_cal = mu0

dg + tilt_calibration_error:
  truth dg != 0, mu0 != 0
  method mu_cal = mu0 + delta_mu_cal
```

目的：

```text
这是最接近真实实验的主工况：
低速有初始倾斜，高速有间隙变化。
```

## 5. 传感器组合

每个工况必须同时跑：

```text
S13  = [1,3]
S136 = [1,3,6]
```

分析重点：

```text
S136 - S13 的幅值变化是否主要来自 CH6 的 dg 或 mu0/mu_cal_error。
```

这比单独比较某个方法的绝对 A 更重要。

## 6. 最关键的理论分析：静态误差投影

不同方法的幅值偏差可以先用一阶投影解释。对某个方法，其没有建模的静态误差为：

```text
e_static = V_truth_static - V_method_static
```

振动识别的线性化基为：

```text
J_vib = [J_A, J_phi, J_d0]
```

则静态误差折算成振动参数的近似量为：

```text
delta_q = (J_vib' W J_vib)^(-1) J_vib' W e_static
```

其中 `delta_A` 就是静态误差导致的幅值偏差一阶估计。

这个分析比直接看 nonlinear fit 更干净，因为它能回答：

```text
某个静态间隙/倾斜误差为什么会被某个方法看成振动？
```

建议每个工况都输出：

```text
projection_delta_A_mm
projection_delta_A_percent
static_error_norm
static_error_projection_ratio_on_vib
```

## 7. 不同方法的 e_static 定义

### superGaussian

```text
e_static = V(g0 + dg, mu0) - V(g0, 0)
```

或如果超高斯模板已经吸收了某个低速静态状态：

```text
e_static = V(g0 + dg, mu0) - V(g0, mu_template)
```

关键是：超高斯没有显式 `dg` 参数，所以剩余静态差异会投影到 A。

### fixed

```text
e_static = V(g0 + dg, mu0) - V(g0, mu_cal)
```

若 `dg = 0` 且 `mu_cal = mu0`，则 `e_static = 0`。

若 `dg != 0`，fixed 会有间隙变化残差。

### gap_fixed_tilt

先估计最佳 `dg_hat`：

```text
dg_hat = argmin ||V(g0 + dg_true, mu0) - V(g0 + dg_hat, mu_cal)||_W
```

然后：

```text
e_static = V(g0 + dg_true, mu0) - V(g0 + dg_hat, mu_cal)
```

若 `mu_cal = mu0` 且模型正确，则 `e_static` 应接近 0。

### gap_tilt_residual

只作为对照：

```text
e_static = V(g0 + dg_true, mu0) - V(g0 + dg_hat, mu_cal + dmu_hat)
```

但它的 A 不作为主结果，因为 `dmu_hat` 可能吸收振动。

## 9. 论文中的主结论

更合适的结论不是：

```text
gap_tilt 能处理大 dmu。
```

而是：

```text
初始倾斜是低速标定可获得的物理先验；
高速主要需要处理相对低速状态的间隙变化 dg；
不显式建模间隙变化的方法会把静态波形误差折算成振动位移；
gap_fixed_tilt 通过低速倾斜先验和高速 dg 估计，可以降低这种幅值偏差；
自由 residual dmu 只作为诊断，不是主辨识自由度。
```

## 10. 最小可执行仿真集

如果只做最少一组，建议：

```text
Cases:
  1. clean
  2. noise_only
  3. ch6_gap: dg6 = 0.05, mu0 = mu_cal
  4. ch6_initial_tilt: dg6 = 0, mu0 != 0, mu_cal = mu0
  5. ch6_gap_initial_tilt: dg6 = 0.05, mu0 != 0, mu_cal = mu0
  6. ch6_gap_tilt_cal_error: dg6 = 0.05, mu_cal = mu0 + delta_mu_cal

Sensor sets:
  S13
  S136

Methods:
  superGaussian
  fixed
  gap_fixed_tilt
  gap_tilt_residual only as diagnostic
```

这一组就能直接回答：

```text
间隙变化是否导致超高斯偏差？
初始倾斜在正确标定后是否仍导致偏差？
CH6 是否是 S136 与 S13 差异的主要来源？
gap_fixed_tilt 为什么应作为主结果？
```

## 11. 推荐最终分析顺序

更清晰的主线应按物理复杂度逐层增加：

```text
Stage 0: clean / noise_only
  无间隙变化；
  无初始倾斜或初始倾斜已完全包含在模板/标定中；
  目的：证明超高斯、fixed、gap_fixed_tilt 在无静态误差时都不应系统偏。

Stage 1: gap change only
  有高速相对低速的 dg；
  无初始倾斜或 mu0 = 0；
  目的：单独观察间隙变化如何被不同方法折算成 A。

Stage 2: gap change + initial tilt
  有 dg；
  有初始倾斜 mu0；
  方法使用正确的 mu_cal = mu0；
  目的：验证“初始倾斜本身不是问题”，只要低速标定正确，gap_fixed_tilt 应仍能处理 dg。

Stage 3: gap change + initial tilt + tilt calibration error
  有 dg；
  有初始倾斜 mu0；
  方法使用 mu_cal = mu0 + delta_mu_cal；
  目的：评估低速倾斜标定误差会给 A 带来多大偏差。

Stage 4: tilt change / residual tilt
  有高速相对低速的倾斜变化 delta_mu；
  目的：作为边界/诊断工况，说明单靠高速波形对 A 与 delta_mu 的可辨识性有限。
```

其中 Stage 0-3 是论文主线，Stage 4 是补充诊断。这样不会把论文重点带偏到
“真实中是否有很大 dmu”，而是聚焦于：

```text
间隙变化 + 初始倾斜标定先验
```

对不同方法的幅值影响。

## 12. 每一阶段应回答的问题

### Stage 0: clean / noise_only

判据：

```text
A_error_percent 接近 0；
S13 与 S136 不应有系统差异；
RMSE 差异不能换来明显 A 偏差。
```

若此阶段超高斯或 gap_fixed_tilt 已经偏，说明采样骨架、噪声、优化器或真值构造有问题。

### Stage 1: gap change only

建议设置：

```text
global dg: 所有传感器同向间隙变化
ch6 dg: 只有 CH6 有间隙变化
multi-sensor dg: CH1/CH3/CH6 不同间隙变化
```

判据：

```text
superGaussian / fixed 的 A 偏差随 dg 增大；
gap_fixed_tilt 的 A 偏差显著更小；
gap_fixed_tilt 的 dg_hat 接近注入 dg。
```

这一步是证明“显式估计间隙变化”的核心。

### Stage 2: gap change + initial tilt

建议设置：

```text
truth: mu0 使用低速标定量级，例如 CH6 mu0 = -0.0585
method: mu_cal = mu0
dg: 使用 Stage 1 中同样的 dg 设置
```

判据：

```text
gap_fixed_tilt 与 Stage 1 相比不应明显恶化；
superGaussian 可能因未建模初始倾斜和 dg 的组合而发生额外偏差；
S136 与 S13 的差异应能由 CH6 的静态波形变化解释。
```

这一步要支持的结论是：

```text
初始倾斜不是要高速自由辨识的未知量；
它应作为低速标定先验进入模型。
```

### Stage 3: tilt calibration error

建议不要直接设很大的高速 `dmu`，而是设低速标定误差：

```text
delta_mu_cal = 0, ±0.002, ±0.005, ±0.010
```

判据：

```text
A_error 随 delta_mu_cal 的灵敏度；
误差是否主要出现在 CH6；
是否存在一个可接受的 mu 标定不确定度范围。
```

这一步更符合真实实验：低速标定不可能完全准确，但误差应有物理上限。

### Stage 4: tilt change / residual tilt

只作为补充边界：

```text
delta_mu_high = 0.005, 0.010, 0.030
```

判据：

```text
raw gap_tilt 是否通过降低 RMSE 改变 A；
safe residual dmu 在 A locked 时是否仍能解释残差；
J_mu 与 [A,phi,dg] 的投影是否说明不可辨识。
```

这一阶段的结论应谨慎表述为：

```text
若真实存在高速倾斜变化，单窗口高速波形不能完全无偏地区分 A 与 delta_mu；
因此 residual tilt 只适合作诊断项。
```

## 13. 还需要改进的地方

建议补充三类改进：

```text
1. 用静态误差投影作为每个工况的解释量
   不只看 nonlinear fit 的 A_error，还计算 e_static 投影到 J_A/J_phi/J_d0 后的 delta_A。

2. 做 dg 与 mu_cal_error 的二维敏感性图
   x = dg6
   y = delta_mu_cal
   color = A_error_percent
   这能给出方法的鲁棒域。

3. 明确区分“正确标定的初始倾斜”和“倾斜变化/标定误差”
   前者是物理先验；
   后者才是误差源。
```

最终仿真主线应是：

```text
clean/noise 基线
-> 间隙变化影响
-> 间隙变化 + 正确初始倾斜
-> 间隙变化 + 倾斜标定误差
-> 倾斜变化作为边界诊断
```
