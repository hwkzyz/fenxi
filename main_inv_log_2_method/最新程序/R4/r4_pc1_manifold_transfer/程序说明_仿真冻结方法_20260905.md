# 仿真程序说明：R4 冻结方法

## 文件夹职责

本文件夹只负责 R4 仿真数据生成、方法选择和可控条件验证。R4 与 R5 使用同一套 gap-law、PC1 排序系数流形、分段线性插值和 anchor/profile 思路；R4 中不包含试验传感器配准。

## 最新仿真程序与顺序

这里需要区分“冻结方法验证程序”和“历史审计程序”。当前目录中真正直接实现
PC1 系数流形的是下面这条链：

1. `Main_01_BuildSimulationSurface.m`
   汇总不同 gap/倾角条件下的 COMSOL 波形面，生成
   `output/waveform_families/TiltGap_WaveformSurfaceData.mat`。
2. `Main_02_PC1SurfaceValidation.m`
   拟合 gap-law，将系数拼成 `q`，按 PC1 排序并在 `q(z)` 上用单个留出 anchor
   定位连续预测面；保存 blind transfer、PC1 explained ratio 和外推标记。
3. `Main_03_OpenSetTransfer.m`
   做离散 open-set baseline：目标面不进入候选库，比较最近候选面和 anchor-preserving
   incremental transfer，用于说明连续 PC1 manifold 的必要性。
4. `Main_04_BoundaryIdentifiability.m`
   做边界面外推和未知 anchor-gap 联合搜索，是 identifiability/边界诊断，不是部署主链。
5. `Main_05_PC1Figures.m`
   只读取 Main_02/Main_03 保存的 MAT/CSV 结果制图，不重新拟合、SVD 或定位。

推荐运行顺序为 `1 -> 2 -> 3 -> [4 optional] -> 5`。
正常 R4 结果在 Main_03 后完成；Main_04 仅用于边界/未知 anchor-gap 诊断，Main_05 最后制图。

每个 `Main_*` 都是完整独立程序，不调用旧的 `Analyze_*` 文件。仿真侧与试验侧
共享 gap-law、系数拼接、PC1 排序、分段线性 `q(z)` 和 anchor/profile 思路；
仿真中的端点外推仅用于边界诊断，不作为试验部署结论。

旧的 `Analyze_*`、`Plot_*`、`Run_*` 和 `Summarize_*` 文件已移入
`旧程序_20260905`。它们是早期审计、POD 对照或制图程序，不是当前 PC1 系数流形的正式主程序。

## 冻结方法

对每个面建立：

`V(x,g) = B0(x) + B1(x)/g + B2(x)*log(g/gref)`

随后将系数拼成 `q`，按 PC1 排序得到 `q(z)`，使用分段线性插值，并通过 anchor/profile 定位目标状态。仿真验证使用同域恒等 registration。

## 结果位置

生成结果写入本文件夹的 `output` 或既有结果子目录。原始仿真输入不覆盖；图和表从保存的结果重新汇总。

## 对照和制图程序

`Analyze_TiltSurfaceMigration.m` 明确使用严格 POD 截断，是历史 comparator；
`Analyze_TiltGap_ParametricSurfaceTransfer.m` 是旧的倾角参数曲线路线；
`Plot_*.m` 只负责可视化。它们都不应被写成冻结 PC1 主方法。
