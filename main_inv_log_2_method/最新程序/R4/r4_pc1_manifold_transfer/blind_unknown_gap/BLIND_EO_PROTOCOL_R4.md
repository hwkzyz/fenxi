# R4 盲 EO 仿真协议

## 1. 先区分历史程序与正式盲辨识

R2、R3 的原始程序把 EO=10 写入测试协议，原因是它们分别验证间隙 profile 和留出间隙状态下的振动恢复。这些程序可以保留为“已知 EO 基准”，但不能作为未知 EO 的辨识证据。

正式盲辨识使用 `Main_09_BlindGapOnlyVPDynamicValidation.m`。仿真生成器可以读取 `case.eo`，但估计器接口不读取该字段。

## 2. 盲辨识数据边界

波形生成阶段允许使用：

- FE 已知间隙节点；
- 真实 EO、振幅和相位；
- 真实倾角和转速，用于生成时间波形。

估计阶段只允许使用：

- 低速波形；
- 高速波形；
- 传感器空间位置和转速同步时标；
- 校准 FE 响应库和 PC1 流形。

估计阶段禁止使用真实 `gLow`、`gHigh`、`deltaG`、`eo`、`A`、`phi`，也不能用真实值初始化、限定局部搜索窗口或选择 EO 候选。

## 3. 正式估计流程

1. 低速波形在 PC1 流形上联合估计 `z、gLow、dxLow`。
2. 对允许间隙网格逐个建立高速静态响应。
3. 使用响应梯度
   `u_hat = -(V_obs - V_static) / dV_static_dx`
   得到位移初值，并剔除梯度接近零的样本。
4. 在每个候选间隙下用 VP 搜索 EO 组合，线性求振动正余弦系数。
5. 保留 Top-K EO 组合，用完整前向波形联合精修高速间隙、偏移、振幅和相位。
6. 用第一、第二候选差距及跨圈/跨传感器一致性给出 `identified` 或 `ambiguous_joint`，不能只按最小波形残差宣称成功。

## 4. 工况设计

不能只测试 EO=10。正式测试应至少包含不同 EO 组合，例如 `[7 19]`、`[10 26]`、`[13 27]`，并在增加噪声、改变倾角和改变间隙方向后重复。真实 EO 只用于最终误差评价。

## 5. 主方法与 C1/C2 对照的区别

`C1_g0_only` 和 `C2_g0_mu` 是几何迁移消融模型：它们用简化的低速路径描述倾角失配，因此在盲 EO 情况下可能把响应面误差吸收到 EO、振幅或高速间隙中。它们不能代表 R4 主方法。

R4 主方法是 `Main_09_BlindGapOnlyVPDynamicValidation.m` 的 leave-one-tilt-out PC1 coefficient-manifold transfer：低速先估计 `z、gLow、dxLow`，高速在 `q(z)` 重建的响应面上进行盲 EO 候选筛选和完整波形精修。该方法不具有“任何倾角都必然恢复 EO”的保证；当流形迁移误差、振动幅值和间隙灵敏度形成近似共线方向时，仍应输出 `ambiguous_joint`，而不是强制判定成功。
