# R2 分阶段运行

R2 按理论流程分成四步，阶段结果保存在 `r2_profiled_recovery/output/stages`，后续步骤会优先读取已有缓存：

```matlab
cd('...\\最新程序\\R2'); addpath(pwd)
Stage1_BuildGapLibrary(false)       % 构造/缓存间隙响应库
Stage2_GenerateWaveform(1,false)    % 生成第 1 个案例波形
Stage3_IdentifyVibration(1,false)   % 对已有波形执行盲辨识
T = Stage4_AnalyzeResults(1:6)      % 汇总已经完成的案例
```

只有在修改响应面、噪声或仿真参数时才传入 `true` 强制重建。这样可以单独检查波形生成、间隙库构造或辨识算法，不必每次从头运行全部案例。
