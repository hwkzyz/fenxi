# R2 local_func 函数分层

当前 R2 正式分阶段入口只需要少量核心函数。根据 `Stage1~Stage4`、`Run_R2_BlindSingleFrequency` 和统一后端的静态依赖检查，`local_func` 中约 139 个 MATLAB 文件里，约 54 个属于当前正式流程的直接或间接依赖，约 85 个没有被当前正式入口引用。

## 正式流程核心链

### 响应库

`load_inv_log_2_project_context`  
`load_fixed_trust_domain`  
`get_inv_log_2_model_def`  
`make_fixed_trust_template_library`

### 波形生成与校准

`make_inv_log_2_demo_case`  
`eval_gap_template`  
`build_path_template_model`  
`simulate_low_speed_template`  
`calibrate_inv_log_2_low_speed`  
`simulate_highspeed_from_low_increment`  
`map_highspeed_to_space`

### 盲辨识

`eval_gap_derivative`  
`run_unified_blind_dynamic_backend`

后面列出的 `build_*`、`eval_*`、`fit_*`、`run_*` 函数，是上述核心函数内部的数学依赖，不能只因为没有在 Stage 文件中直接出现就删除。

## 当前未被正式 Stage 链引用的函数

这部分主要是历史方法、诊断程序、旧的 VP/正交方法、性能实验和备用模型。它们暂不从磁盘删除，以免影响旧结果复现，但不应再被新的 R2 主程序调用。

后续整理时应将它们移动到：

```text
R2/旧程序_20260916/local_func/
```

移动前必须先对 R3、R4 和旧结果复现实验做一次全文依赖检查。

## 编程约定

Stage 文件中只保留：参数配置、输入加载、核心算法调用、结果保存。不要再增加只转发参数的包装函数。复杂数值运算保留在核心函数中；历史算法不再加入正式路径。
