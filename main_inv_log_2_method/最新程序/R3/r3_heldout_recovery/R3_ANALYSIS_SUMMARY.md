# R3 留出运行间隙分析总结

更新日期：2026-08-27。本文只整理现有 R3 正式结果和已完成的诊断；不改变正式数据、阈值或算法。

## 1. R3 要回答的问题

R3 检验的是：在低速标定冻结后，运行时实际间隙偏离标定间隙时，显式估计运行间隙能否避免把间隙失配错误归因于同步振动。

这不是“所有工况下误报均受控”的完整可靠性声明。振动恢复能力和空载判决（误报率）必须分开报告。

## 2. 冻结协议与分析链

| 项目 | 设置 |
| --- | --- |
| 全部 FE 间隙库 | 0.2--1.5 mm，步长 0.1 mm |
| 低速标定间隙 | 0.2, 0.3, 0.4, 0.6, 0.8, 1.1, 1.3, 1.4, 1.5 mm |
| 留出运行间隙 | 0.5, 0.7, 0.9, 1.0, 1.2 mm |
| 匹配参考对照 | 0.8 mm |
| 主分析振幅 | 0, 0.10, 0.15, 0.20, 0.25, 0.30, 0.37 mm |
| 真值 EO | 10 |
| 参考噪声 | 15 dB，参考振幅等效电压 SNR |
| 冻结低速标定 | 真值 0.8 mm，估计 g0 = 0.811123 mm |
| 自适应搜索区间 | 0.4--1.3 mm（数值测试区间，不应表述为工程极限） |
| 非空载成功判据 | EO=10；振幅误差 <= max(0.020 mm, 真振幅的 10%)；相位误差 <= 20 deg |
| 联合成功附加条件 | 间隙误差 <= 0.020 mm |
| 空载阈值 | 在 0.8 mm、冻结 C0 下，以 500 个空载重复的 95% 分位数标定 |

三种方法共用低速模板、同步振动求解器与噪声条件；唯一的状态处理差异为：

- `fixed`：始终固定在冻结低速估计 g0。
- `adaptive`：在 0.4--1.3 mm 内联合搜索运行间隙与振动参数。
- `state_matched`：直接固定为仿真真值间隙，是“若间隙已知”的控制，而不是可部署方法。

每个正式单元采用 75 个确定性相位点（2.4--357.6 deg，步长 4.8 deg），每一点配一个确定性高转速噪声种子。因此这里的成功率表示该“均匀相位--噪声配对设计”下的覆盖率，并非 75 x 75 的相位和噪声全因子试验，也不应简单称为纯随机噪声重复率。

## 3. 预分析与可行性检查

1. 间隙库审计：相邻响应连续；五个留出间隙由相邻标定模板插值得到的波形相关系数为 0.999942--0.999989，归一化 RMSE 为 0.00788--0.01629。这确认了留出状态在模板族内可平滑表示，但不等同于已经证明高转速判决可靠。
2. 无噪声、真值间隙控制：所有非空载门禁算例均恢复 EO=10 并满足振动成功判据。这说明模型族和基本求解链能表示目标运动。
3. 冻结标定：低速波形先映射至空间坐标，并以自适应 Savitzky--Golay 模板构建静态模型；随后冻结为 C0，主矩阵不再用高转速真值回填该标定。
4. 空载阈值：分别对三种方法标定，数值为 fixed 0.0019925 mm、adaptive 0.0027027 mm、state-matched 0.0312257 mm。

## 5. 主结果

下表将六个非空载振幅合并（每种方法每个间隙 n=450），空载误报率单列（n=75）。在这些结果中，`P_joint` 与 `P_vib` 数值相同，表示只要振动判定成功，间隙误差也均落入 0.020 mm 容差。

| 真值间隙 (mm) | fixed: P_vib / P_FP | adaptive: P_vib / P_FP | state-matched: P_vib / P_FP |
| --- | --- | --- | --- |
| 0.5 | 0% / 100% | 100% / 100% | 98% / 0% |
| 0.7 | 0% / 100% | 100% / 1.3% | 91% / 0% |
| 0.8（匹配） | 100% / 2.7% | 100% / 4.0% | 88% / 2.7% |
| 0.9 | 0% / 100% | 99% / 100% | 85% / 100% |
| 1.0 | 0% / 100% | 99% / 57.3% | 80% / 100% |
| 1.2 | 0% / 100% | 100% / 100% | 100% / 0% |

固定法与自适应法的逐相位--种子配对比较表明：在全部五个留出间隙的所有非空载单元中，自适应法仅有“救回”而没有相对 fixed 的“损失”。0.9 mm、A=0.20/0.25 mm 和 1.0 mm、A=0.20 mm 的救回率分别为 96%、97.3%、96%；其余留出非空载单元均为 100%。0.8 mm 匹配控制下两者完全一致。

### 可以成立的结论

在本冻结标定、15 dB、测试搜索区间和所列振幅下，运行间隙自适应估计使留出状态的同步振动恢复率由 fixed 的 0% 提升至 99--100%，并使间隙误差同时满足 0.020 mm 的联合判据。这支持“显式处理运行间隙可消除固定标定间隙失配导致的同步振动错误归因”。

### 不能成立的结论

不能写成“自适应法普适扩展了可靠域”或“所有工况均可靠”。原因是 adaptive 在 0.5、0.9、1.2 mm 空载时的误报率为 100%，在 1.0 mm 仍为 57.3%。因此，当前结果只证明其非空载参数恢复强，不证明检测判决在留出状态上受控。

`state_matched` 在 0.9 和 1.0 mm 空载时也有 100% 误报，即使其间隙直接取真值。这排除了“误报完全由自适应间隙估计错误造成”的解释，指向更基础的问题：以 0.8 mm 条件标定的全局振幅阈值/残差投影统计量不能转移到所有运行间隙状态。真值间隙控制也不是理论上必然 100% 振动恢复，因为它仍要在有限采样、噪声和非线性模板下选择 EO、振幅、相位。

## 6. 99% 而非 100% 的八次非空载失败

自适应法在 2,700 个非空载正式重复中有 8 次未满足 `P_vib`，均误选 EO=16（真值为 EO=10）：

| 真值间隙 (mm) | 真振幅 (mm) | 失败重复索引 | 相位 (deg) |
| --- | --- | --- | --- |
| 0.9 | 0.20 | 69, 72, 74 | 328.8, 343.2, 352.8 |
| 0.9 | 0.25 | 4, 74 | 16.8, 352.8 |
| 1.0 | 0.20 | 72, 73, 74 | 343.2, 348.0, 352.8 |

这八次的自适应间隙误差均在 0.010--0.018 mm，振幅误差也在容差内；失败由 EO 选择而非振幅或间隙容差触发。

### EO 竞争诊断

对同一八条波形，将 EO 固定为 10 和 16 后分别比较“联合间隙搜索”与“真值间隙固定”两种拟合：

- 真值间隙固定时，EO=10 的 RMSE 总是低于 EO=16，优势为 468--728 uV（均值 552 uV）。
- 联合间隙搜索时，EO=16 的 RMSE 反而总是低于 EO=10，优势为 3--385 uV（均值 181 uV）。

因此这八次属于已证实的 `joint_gap_rank_inversion`：允许间隙与振动联合优化后，EO=16 的局部组合越过了 EO=10，而不是单纯的原始波形在真值间隙下本来就无法区分 EO。

### 相位与噪声分离诊断

对其中三个代表性失败单元，分别固定失败噪声扫 75 个相位，以及固定失败相位扫 75 个噪声种子：

| 代表单元 | 固定失败噪声、扫相位：EO=10 | 固定失败相位、扫噪声：EO=10 |
| --- | --- | --- |
| g=0.9 mm, A=0.20 mm | 96.0% | 0.0% |
| g=0.9 mm, A=0.25 mm | 98.7% | 18.7% |
| g=1.0 mm, A=0.20 mm | 97.3% | 9.3% |

证据表明相位扮演主要触发角色：在大多数相位，固定同一噪声仍选 EO=10；一旦固定在异常相位附近，更换噪声通常仍落入 EO=16 竞争谷。噪声改变边界和个别结果，但不足以单独解释该模式。现有数据支持“相位--有限采样--联合间隙搜索耦合引发 EO 排名翻转”；尚不足以把其归因于某一个唯一物理机理。

## 7. 推荐的论文表述与下一步

建议主文采用如下边界明确的表述：

> 在冻结低速标定和 15 dB 条件下，显式估计运行间隙使五个留出间隙状态的同步振动恢复率达到 99--100%，而固定标定间隙在这些状态下均为 0%。该改进解决了间隙失配向同步振动参数的错误归因；但空载误报在部分留出状态仍然很高，故当前方案尚不能宣称检测判决在全运行间隙域内可靠。

下一步应分成两个独立问题验证，而不是用同一结论覆盖两者：

1. 为空载判决建立运行状态条件化的统计量或阈值，并单独验证跨间隙误报控制；在完成前，不将 `P_FP` 视为已解决。
2. 对 EO=10/16 竞争，比较保留更多候选、间隙正则/先验或剖面目标函数后的排名稳定性，并在异常相位带做相位 x 噪声全因子验证。
