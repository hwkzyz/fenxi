# R3 主程序与子程序边界

正式入口是 `Main_R3.m`，它直接调用 `r3_heldout_recovery/Run_R3_UnifiedBlindBackend.m`。`Run_R3_BlindSingleFrequency.m` 仅作为旧命令的兼容入口，不再作为新的主程序。

R3 后端中直接展开了固定协议、案例循环、观测整理、辨识配置和结果保存。保留的 R3 子程序仅处理三类复杂内容：

1. R3 留出间隙上下文和原始响应读取；
2. 低速参考校准与高速波形生成；
3. 统一盲辨识核心。

`R3_Protocol.m` 仍保留给旧审计和论文复现脚本使用，但正式主流程已经把当前协议常量直接写入后端，避免阅读主流程时来回跳转。
