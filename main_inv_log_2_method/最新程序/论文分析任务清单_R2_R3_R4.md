# 论文分析任务清单：盲EO统一辨识后

## R2：同几何条件下的基准可辨识性

R2回答的问题是：在响应面没有几何迁移误差时，盲EO、盲间隙和单频振动参数能否联合恢复。

必须分析：

1. 多个EO（低、中、高阶）下的恢复率；
2. 间隙误差、振幅误差、频率偏差和波形RMSE；
3. VP候选是否召回真实EO；
4. 15–30 dB噪声下的成功率和歧义率；
5. 传感器数和转数对EO margin的影响。

R2不应加入PC1迁移误差，也不应使用已知EO作为正式结果。

## R3：间隙—振动联合辨识

R3回答的问题是：当高速间隙未知且频率可能偏离整数阶时，完整波形联合优化是否仍能恢复间隙和振动参数。

必须分析：

1. 增大和减小间隙两类工况；
2. 多个EO及正负频率偏差；
3. 间隙与振幅、偏移之间的耦合；
4. `identified` 与 `ambiguous_joint` 的判定；
5. 全EO精修与Top-K筛选的一致性。

R3的核心结果不是单一RMSE，而是证明盲候选搜索没有依赖真实EO或真实间隙。

## R4：响应面跨几何迁移

R4回答的问题是：低速PC1流形和迁移响应面存在误差时，统一盲动态后端的性能如何变化。

必须分析：

1. 低速PC1状态估计误差；
2. 训练几何与留出几何之间的响应面误差；
3. 高速间隙恢复误差；
4. EO召回率和Top-2 margin；
5. 低速状态歧义向高速参数的传播；
6. 与同几何R2/R3结果的差异。

R4不能把响应面迁移误差和动态辨识误差混在一个结论中，应分别报告低速状态误差、静态响应面误差和动态参数误差。

## 不能再作为正式主结果的分析

- 已知EO条件下的动态验证；
- 使用真实间隙作为高速初始化；
- 只比较局部真值附近的优化结果；
- 只报告最小波形RMSE、不报告候选差距；
- 用`absolute`前向模型替代正式`low_increment`模型。
