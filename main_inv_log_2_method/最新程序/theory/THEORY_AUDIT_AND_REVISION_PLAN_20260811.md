## 2. 原理论文件的结构与数学缺口

### 2.1 理论对象已经落后于冻结程序

原稿主线仍是“反比--对数静态响应面 + 通用多频阶次/频偏参数化 + 投影间隙局部窗”。最新程序的正式主线已经变为：完整 DAQ 加噪、OPR 空间映射、support-aware 自适应 SG 低速模板、PCHIP 连续查询、低速模板增量前向模型、四类已知结构和双同步 Funnel V2。原稿没有把这些模块串成同一个信息链。

### 2.2 噪声、映射和窗口的先后关系缺失

原稿直接从时间--空间映射开始，没有定义噪声是在完整 DAQ 记录上加入，还是在最终空间窗口上加入。这样无法解释名义 DAQ SNR、实际窗口 SNR和振动增量 SNR为何不同，也无法复现实验。原稿还没有说明：OPR 映射决定样本坐标；低速/静态共同支撑决定模型可查询域；位移与偏移上界进一步收缩出高速认证辨识窗口。

### 2.3 低速模板构造过于理想化

原稿用泛化的“插值 + 聚合”描述低速模板，没有写明 0.02 mm 物理分箱、完整转次分组交叉验证、自适应 SG 窗宽选择、SG 导数和 PCHIP 查询。更关键的是，没有区分模板函数误差与模板导数误差，也没有说明 PCHIP 不能恢复硬分箱已丢失的信息。

### 2.4 频率模型与当前四类求解器不一致

原稿用 `k_q theta + 2 pi Delta f_q t` 表示所有分量，混淆了同步转角基与异步时间基；还写成“试验采用单频，多频待验证”，与当前单同步、单异步、双同步、同步--异步四类正式仿真相冲突。必须分别给出四个模型族，并明确“结构类别已知”不等于“真实频率已知”。

### 2.5 Funnel V2 职责缺位

原稿只有通用变量投影和局部优化，没有说明双同步的冻结计算层级。因而无法区分：候选召回失败、Top-K 截断失败、完整优化失败、真 EO 已入 Top-3 但最终残差竞争失败。原稿也无法解释为什么 X01 增加 K2 没有意义。

### 2.6 可辨识性概念混层

原稿只有局部间隙分离度 `eta_g,s`，缺少完整连续参数雅可比、离散模型流形分离和有限噪声判据。结构可辨识性、实用可辨识性、给定 EO 后连续参数可恢复性和盲 EO 选择被放在同一“是否可辨识”表述中，容易把 X01/X02 的实用退化误写成结构不可辨识。

### 2.7 缺少确定性偏差触发模型选择翻转的数学解释

原稿的 `T_x` 与 `S_g` 投影只能解释间隙--振动连续参数混淆，不能解释两个 EO 模型之间的竞争。需要增加：去除共享/干扰方向后的 principal angles、canonical correlation、模板偏差在成对 EO 判别方向上的投影、完整连续参数雅可比局部条件数、候选模型流形距离。

### 2.8 成功判据和近竞争诊断混淆

原稿没有形式化的仿真成功事件。程序中的 `ambiguous` 来自一个噪声归一化残差裕量启发式，但最终竞争审计已证明它会把大量正确案例也标为模糊，因此不能作为主要失败判据。理论应以 EO/频率、幅值、相位、间隙误差和数值可行性是否同时过阈值作为成功标准，残差裕量只解释近竞争程度。

### 2.9 仿真章节仍是计划，不是已验证结论

原稿写“多频仍需验证”，没有纳入 42/42 主范围结果、Funnel V2 召回结果、X01/X02 oracle 与机制审计、低速模板正式指标，也没有严格区分“已有证据”和“待验证讨论”。

## 3. 推荐的新理论主线

1. 问题定义：间隙变化、模板偏差和有限传感器信息共同影响完整波形。
2. 数据生成协议：完整 DAQ 加噪，再做 OPR 映射；名义 DAQ SNR 与空间窗口实际 SNR 分开。
3. 支撑域契约：低速观测域、静态响应域、数值裕量、偏移/幅值上界共同确定高速认证区间。
4. 低速模板：空间分箱 → 完整转次分组 CV → 自适应 SG → 导数 → PCHIP 连续查询。
5. 增量前向模型：实测低速模板定义零增量，静态响应面只提供相对间隙变化。
6. 四类结构化振动模型：单同步、单异步、双同步、同步--异步。
7. 候选生成与精修：一阶 VP 只产生候选；双同步单列 Funnel V2 及其召回职责。
8. 可辨识性四层：结构、给定结构连续参数、实用、离散 EO 选择。
9. 失效机理：候选子空间近共线 + 确定性模板偏差判别投影 + 噪声实现。
10. 可检验条件与验收：支撑、导数、幅噪比、独立相位、主角、最小奇异值、收敛、残差裕量和逐参数阈值。
11. 正式证据和适用边界：写清主范围、X01、X02、Funnel、未验证项。

- 逐参数成功事件：EO、频率、幅值、相位、间隙和数值可行性交集。

### 重写

- 摘要：从早期单频方法改为冻结程序、四类结构和可辨识边界。
- 基本假设：增加 DAQ 噪声、结构类别、支撑域，删除暗含“模型成立即唯一”的表述。
- 时间--空间与低速模板章节：改为 support-aware adaptive SG + PCHIP。
- 振动模型章节：同步用实测转角，异步用绝对时间。
- 双同步求解：明确所有 EO 对 joint-GN 后才能删减。
- 仿真章节：由未来计划改为正式证据与边界。
- 讨论与结论：明确 X01/X02 不是统一低 SNR 问题，也不把实用退化称为结构不可辨识。

### 删除或降级

- 删除“试验只用单主导频率、多频尚未验证”的过时结论。
- 删除把通用 `k theta + Delta f t` 作为四类结构统一物理模型的写法。
- 降级 `ambiguous`：只作诊断，不作主要失败判据。
- 降级搜索半宽、Top-K 和局部残差：均为数值策略或诊断量，不是统计置信区间和正确性保证。

## 5. 证据--结论边界

### 已有仿真支持

- 三传感器、8 转、10--20 dB DAQ SNR、分量幅值不低于 0.1 mm 的代表性范围内，四类结构共 42 组参数判据通过；最大频率误差 0.0935 Hz，最大间隙绝对误差约 0.00062 mm。
- 自适应 SG 在正式低速模板指标中显著改善模板与导数误差，导数相关系数接近 0.999。
- Funnel V2 的全 EO 第一次 joint-GN 修复了固定间隙 GN1 后真 EO 排名 45--58 的候选漏检。
- X01 的硬分箱/支持设置会产生足以改变 EO 竞争顺序的确定性偏差；真/竞争 EO 子空间高度近共线。
- X01、X02 在固定真 EO 后的连续参数恢复明显优于盲选择，证明“结构选择”和“连续参数恢复”是两层问题。
- 当前残差裕量启发式不适合作为主要成功/失败判据。

### 只能作为假设、讨论或后续验证

- 对任意 EO 组合、任意传感器布局和任意噪声的唯一辨识保证。
- `D_min > 2||e||` 在真实试验中的直接可验证概率保证；未知确定性模型误差仍需界定。
- OPR 抖动导致 X01 翻转。当前合成审计使用真 OPR 时刻，尚无该证据。
- 五传感器或某一优化布局的全局最优性。
- 四类结构类别未知时的自动跨结构选择。
- 缺少独立间隙真值时的绝对间隙精度。
