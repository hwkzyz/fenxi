# 仿真与试验统一盲辨识思路对照

## 试验端当前正式程序

试验端最新生产入口是 `experimental_dynamic_decoupling_validation/20251222_gap_vibration_identification_v1/latest_programs_20260905/Run_R5_Main_20251222.m`；逐窗口统一后端是 `experimental_dynamic_decoupling_validation/common/R5_Run_SensorConditionedWindowIdentification.m`。20250527 使用同一后端的工况配置，20241106 暂不作为同构主验证，因为 S2 为直接模板通道而 S5/S7 为间隙通道。

试验端流程为：Foundation 无间隙 VP 候选 → 低速模板/传感器条件化 sidecar 冻结 → 完整高速窗口波形 → 每个窗口的 EO 候选和频率细化 → 固定候选 EO 后联合优化振幅、相位、dx 及间隙传感器的 dg_s → 静态重放、支持域、硬闸门及应变/BTT 后验审计。

配置中 `searchHz=[300,1000]`、`candidateTopK=3`，`lockReferenceEO=false`。因此参考 EO（若存在）只用于审计，不是估计先验。20251222 三个分析传感器均声明为间隙传感器；20250527 也明确检查传感器角色和静态支持域。

## 仿真端当前正式程序

仿真端正式入口为 `Run_R2_BlindSingleFrequency.m`、`Run_R3_BlindSingleFrequency.m` 和 `r4_pc1_manifold_transfer/blind_unknown_gap/Main_10_UnifiedBlindBackendValidation.m`，共同后端为 `local_func/run_unified_blind_dynamic_backend.m`。

仿真端流程为：已知真值间隙和振动参数生成波形 → 低速状态冻结 → 间隙库/响应面查询 → 高速梯度 VP 初筛 → EO 候选 `1:30` 全盲搜索 → Top-K 完整电压波形精修 → 残差排序并输出间隙、EO、频率偏移、振幅和相位。

仿真中的真实参数只进入波形生成模块和最终误差评价，不能进入估计器。正式前向模型统一为 `low_increment`。

## 一致之处

1. 都以低速数据建立并冻结运行基准，而不是用高速数据重新训练 PC1。
2. 都保留完整高速波形作为最终目标，VP 仅用于候选生成/筛选。
3. 都允许间隙与振动参数联合解释波形，不能把间隙当作已知先验。
4. 都采用候选 EO → 完整波形精修 → 独立质量/歧义审计的分层流程。
5. 都把真实 EO 或外部应变频率放在评价/后验验证端，而不作为正式估计输入。

## 目前仍存在的理论和接口差异

| 项目 | 仿真 | 试验 | 影响 |
|---|---|---|---|
| EO 参数化 | 同步 EO 直接离散搜索 `1:30`，近同步用 `deltaF` 连续细化 | 频率在 `[300,1000] Hz` 连续搜索，候选 Top-3 后 ±2 Hz 细化 | 需要统一报告为“离散 EO 候选 + 连续频率细化”，不能只比较 EO 整数值 |
| 传感器模型 | 当前 R2/R3 多为共享响应面/单一 gap 参数 | 试验为逐传感器 sensor-conditioned sidecar，间隙传感器各自 `dg_s` | 仿真尚未完全覆盖逐传感器独立间隙增量 |
| Foundation 作用 | 低速模板和响应面直接构造仿真模型 | Foundation 主要提供原始窗口 bundle 和 VP/seed 候选，不继承其 EO/A/phi/dx | 仿真应增加“Foundation 只提供候选、不继承动态参数”的审计字段 |
| 支持域/硬闸门 | 主要检查有限值、梯度和残差 | 另有静态重放、共同支持域、边界命中、独立参考后验审计 | 仿真需补充同样的 support/boundary/replay gate，避免只看 RMSE |
| 频率结构未知性 | R2/R3 已指定 single-sync 或 near-sync 结构 | 试验配置仍有 `structureSelection='known_from_experimental_design'`，未知结构用 BIC 仅列为候选 | 若论文宣称结构盲辨识，试验端还需增加 single-sync/async 结构比较；目前只能称频率/EO 盲、结构类别受限 |
| 噪声与窗口 | 代表性仿真工况较少 | 试验逐窗口真实噪声和窗口一致性审计 | 图2大网格重跑前，仿真应扩展相位、噪声、窗口/转数维度 |

## 结论

两端的主思想已经一致：低速冻结响应关系、间隙库提供物理约束、VP 只做候选、完整波形决定最终结果、真值只用于生成和评价。尚未完全一致的不是核心辨识思想，而是“逐传感器间隙增量、支持域硬闸门、Foundation 角色、频率连续化和结构类别处理”。因此图2/R2--R3仿真可以作为方法机理和盲 EO 能力验证；若要直接对应 R5 试验，还需要在后续仿真批次中加入逐传感器 `dg_s`、窗口化输入和与试验相同的支持域/硬闸门审计。
