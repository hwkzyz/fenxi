# R2–R4统一盲辨识主程序说明

## 主程序入口

```matlab
Run_R2_BlindSingleFrequency
Run_R3_BlindSingleFrequency
r4_pc1_manifold_transfer/blind_unknown_gap/Main_10_UnifiedBlindBackendValidation
```

三个入口现在均调用同一个动态后端（R4 的 `Main_09` 只是兼容包装器）：

```text
run_unified_blind_dynamic_backend.m
```

R2、R3、R4的区别只在响应面适配器：

- R2：同几何直接响应面；
- R3：同一固定几何响应面族内的留出间隙节点/间隙库；
- R4：多个倾角/几何响应面之间的 PC1 流形迁移。

## 统一辨识流程

1. 低速数据估计并冻结低速状态；
2. 由响应适配器提供 `evalF` 和 `evalFx`；
3. 在全局合法间隙范围内生成候选；
4. 对全部EO候选进行梯度位移VP；
5. 用间隙感知的电压种子残差保留Top-K；
6. 对Top-K进行完整电压波形联合精修；
7. 只用full-wave SSE排序最终结果；
8. 根据第二候选差距输出 `identified` 或 `ambiguous_joint`。

真实EO、真实高速间隙、振幅和相位只允许出现在仿真波形生成和最终误差评价中，不进入估计器输入。

## 正式仿真结果

R2结果：

```text
r2_profiled_recovery/output/unified_blind_backend/
```

R3结果：

```text
r3_heldout_recovery/output/unified_blind_backend/
```

R4结果：

```text
r4_pc1_manifold_transfer/blind_unknown_gap/output/unified_backend_full/
```

## 论文中必须报告的分析

- 盲EO恢复率；
- 间隙误差、振幅误差、频率偏差误差；
- 完整波形RMSE；
- 第一/第二候选目标函数差距；
- 噪声水平下的成功率和歧义率；
- 传感器数量和转数对可辨识性的影响；
- R4低速PC1状态的边界和歧义检查。

旧版程序不作为正式主结果，只用于历史结果复核和消融对照。
# 论文图件数据刷新

`Refresh_Paper_Figure_Data_R2_R3_R4.m` 是统一重跑入口。它先运行 R2、R3、R4 的盲 EO/间隙后端，再把结果写入 `paper_figures/updated_source_data`，同时备份历史论文数据。

现有论文绘图脚本所依赖的 R3 正式统计 MAT 和 R4 几何迁移 CSV 保持原格式，不用新的盲辨识汇总表强行覆盖；否则会造成字段结构和物理问题定义不一致。`paper_data_refresh_manifest.csv` 给出每个图件数据的当前来源和兼容性状态。
