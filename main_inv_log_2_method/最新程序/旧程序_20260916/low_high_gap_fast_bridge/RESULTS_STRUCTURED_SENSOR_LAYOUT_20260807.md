# 结构化辨识的传感器布局审计（2026-08-07）

## 动机

当前三传感器角位置约为 `[0.9599, 2.0378, 3.1158] rad`。在5 dB、
8转、双分量振幅达到下限 `0.1 mm` 时，完整电压目标会出现同步阶次
谐波/空间别名竞争。增加优化迭代、扩大候选池和增加到32转均不能对
所有噪声种子保证真值。

## 对照布局

边界程序增加以下隔离仿真布局，不修改默认主程序硬件配置：

- 当前三传感器；
- 三传感器均匀布局；
- 四传感器均匀布局；
- 五传感器均匀布局；
- 三传感器黄金角非均匀布局；
- 五传感器黄金角非均匀布局。

黄金角布局采用：

```matlab
phi = (1 + sqrt(5))/2;
alpha = sort(mod((0:N-1)*2*pi/phi, 2*pi));
```

## 关键结果

针对最困难的双同步 `300+350 Hz, A=[0.1,0.1] mm` 和同步+异步
`300+1493 Hz, A=[0.25,0.1] mm`：

- 当前三传感器在5 dB、8转下存在错误频谷胜出；
- 三传感器黄金角布局仍不能稳定恢复双同步弱相邻阶次；
- 四传感器均匀布局仍可能选择错误同步阶次；
- 五传感器均匀布局改善明显，但对称布局仍保留阶次别名风险；
- 五传感器黄金角布局在三个独立噪声种子的两个困难案例中达到6/6正确。

进一步用固定理论指标在 `EO=6:30` 上最小化同步子空间最大互相关，
随机搜索2000个五传感器布局得到：

```text
alpha = [0, 0.973466, 2.42106, 2.90560, 4.06032] rad
worst subspace coherence = 0.80051
worst pair = EO6/EO12
```

该布局在两个困难案例、三个噪声种子下也达到6/6正确。它比黄金角
五传感器的最坏互相关 `0.98393` 更低，说明“传感器布局先按候选阶次
子空间互相关优化，再做完整电压辨识”比直接采用规则均匀布局更有
理论依据。

用该优化布局运行全部12个边界案例（单同步、单异步、双同步和同步+
异步各3例，5 dB、8转）得到 `12/12` 参数判据通过。结果文件位于
`output/structured_boundary_matrix_12cases_8rev_5db_stress0_optimized5/`。
其中7例达到2 sigma目标间隔；其余5例虽然命中仿真真值，但仍被保守
标记为需要更多观测或候选池未完成验证。

随后用五传感器黄金角布局运行完整12案例边界矩阵，单同步、单异步、
双同步、同步+异步共12/12参数判据通过。所有案例使用全部可信点；
单案例用点数约29704。

## 解释

这说明当前剩余失败不是单纯“算法搜索不够宽”，而是硬件时间/空间
采样没有给弱分量提供足够独立相位信息。非均匀五传感器布局可以打破
部分整数阶次谐波别名，比继续增加同一布局下的优化次数更有效。

该结果仍不是对所有频率和所有噪声实现的数学证明。正式设计应在目标
阶次范围内计算候选阶次字典的最小互相关或最小奇异值，并据此优化角
位置，而不是把黄金角五传感器直接当作唯一最终硬件方案。

运行入口：

```matlab
Run_StructuredBoundaryMatrix(0,false,[],8,5,'golden5')
Run_StructuredBoundaryMatrix([0 1000 2000],false,...
    {'dss_adj_low','dsa_wide'},8,5,'golden5')
```
