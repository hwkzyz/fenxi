# 冻结分析协议

## A. 相位孔径干预

- 使用 Route 31 已冻结的三探针、八转、可信支撑域和低速增量模型。
- 固定所有采样位置、模板导数、间隙导数及 nuisance 列。
- 只将 passage 内相位偏移缩放为 `theta_gamma = theta_center + gamma*(theta-theta_center)`。
- `gamma = 0` 是 frozen-phase 极限，`gamma = 1` 是完整逐点相位。
- 同时报告原始条件信息和迹匹配后的信息；后者排除总灵敏度能量变化。

## B. 条件 CRLB--Monte Carlo

- 固定正确双同步 EO `(10,26)`，不包含离散模型选择。
- 目标参数为绝对高速间隙和四个正余弦系数；公共空间偏移作为 nuisance 条件化。
- 生成器和反演使用同一冻结增量模型，以隔离模型正确条件下的统计方差。
- 噪声先加入完整 DAQ 时间记录，再执行 OPR 映射和可信支撑裁剪。
- 使用真值初始化的两步局部 Gauss--Newton，以隔离局部统计效率，不审计全局优化。
- 预定 SNR 为 `25, 15, 5 dB`，每档 60 个固定种子。

## C. X01 模型距离与偏差投影

- 真 EO 为 `(10,12)`，主要竞争 EO 为 `(10,18)`。
- 参考模型和正式 adaptive-template 模型均对两个 EO 对执行完整固定对非线性重优化。
- 判别方向来自参考模型中两个优化后波形之差。
- 正式模型相对参考模型的真模型波形差投影只作为局部诊断。
- 最终翻转以 `wrong RMSE - true RMSE` 的符号为准。
