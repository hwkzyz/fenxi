# Route 31 首轮理论—仿真闭环结论

## 1. 已完成的检查

1. 冻结依赖检查：8项主链依赖均存在。
2. 相位多样性解析恒等式：数值与解析特征值最大误差 `3.55e-14`。
3. exact/frozen 条件几何：完成3个代表双同步工况。
4. 物理窗口扫描：完成3工况×18窗口×2模式。
5. X01 冻结证据综合：确认模型偏差造成残差裕量翻转。
6. 正式20工况指标—结果关联：已与600次冻结结果对接。

## 2. 核心发现

### 发现 A：passage 内动态相位对当前三探针双频模型具有秩恢复作用

frozen passage 在排除间隙与公共偏移后，四个振动正余弦系数仅保留秩2；exact passage 在3个工况中均恢复为秩4。

这支持：

> 逐采样点完整波形并非只是提高数据量，而是为固定双同步模型提供了三探针中心点观测所缺少的相位方向。

它不支持：

> full waveform 自动保证全局唯一或 EO 选择正确。

### 发现 B：孔径对稳定性的影响远大于“是否数值满秩”

exact 模型在0.24 mm全宽窗口已数值满秩，但 X01 的归一化条件数约为 `9.4e4`；全窗口下降至 `31.5`。所以论文应报告最小条件信息和条件数，不应仅报告 rank。

### 发现 C：局部参数信息与离散模型分离不是同一件事

exact passage 恢复了四维参数信息，但其最小竞争子空间角仍只有约 1.4--3.6°，说明“恢复连续参数方向”不等于“所有离散 EO 候选都容易区分”。由于 frozen 模型的完整振动切空间已降秩，其候选夹角不再具有同等几何含义，因此不作 exact/frozen 夹角增益比较。

### 发现 D：X01 给出了确定性偏差摛毁模型裕量的直接证据

正式 adaptive template 下，错误 `(10,18)` 比真 `(10,12)` 的 oracle RMSE 低 `1.4266e-5 V`；exact direct 模型下，错误模型反而高 `2.7976e-5 V`。条件 canonical correlation 为 `0.99805`。

### 发现 E：单一局部指标只有中等预测力

在5 dB下，最小竞争角与 EO 正确率的 Spearman 相关约 `0.542`，条件信息与全参数成功率约 `0.473`。这足以支持机制解释，但不足以建立单指标成功阈值。

## 3. 对论文是否有用

**有用，而且不是装饰性的数学补充。**

它将论文从“完整波形联合辨识算法在多工况下成功”提升为：

1. 解释逐点完整波形为何能为固定动态模型恢复缺失的参数方向；
2. 解释为何这仍不足以保证离散 EO 选择；
3. 解释为什么 Funnel V2 解决了召回却不能解决 X01；
4. 用模型分离裕量与定向模板偏差解释零噪声翻转。

这四点可以构成高质量专业期刊或 Communications Engineering 方向的核心理论结果。

## 4. 当前停止边界

首轮结果还不支持：

- 已经建立可测量前普适预测的 identifiability law；
- full waveform 对所有 EO 候选都增加分离；
- 当前理论可跨不同物理波形几何泛化；
- 已经达到 Nature Communications 级证据闭环。

下一轮最值得做的不是继续增加理论符号，而是：

1. 总灵敏度能量归一的窗口孔径对照；
2. 正确 EO 条件下的 CRLB–Monte Carlo 定量验证；
3. 预先锁定的多因素预测式与新 blind EO 对；
4. 通过上述三项后，再做 full/TOA/peak 表示压缩对照。
