# R5 传感器条件动态解耦程序说明

版本：`R5_SensorConditioned_Decoupling_20260916`

## 一、整理结果

新的正式程序已经独立放在本目录。正式运行只需要把本目录加入 MATLAB path；不会加入、调用或依赖两个旧的 `latest_programs_*` 目录。

两个工况共用 `core/` 中的动态辨识和审计程序，通过 `adapters/` 中的工况适配器连接各自的模板、间隙响应面、sidecar 和 Foundation 窗口数据。

旧工况目录中的历史 `Main*.m` 和 `Legacy*.m` 已移入各自的 `legacy_programs/`。旧程序仅用于历史复现和对照，不再是正式 R5 入口。

## 四、完整运行流程

### 阶段 A：低速静态状态

```text
低速完整波形
 → 时间同步、传感器/叶片注册
 → 低速模板 T_s(x)
 → 间隙库和静态响应面 F_s(x,g)
 → PC1/anchor/R4 绝对静态定位
 → 得到每个传感器的 g0_s、B_s(x)、注册关系和增益
 → 检查模板域、响应面域、间隙域
 → 冻结 sidecar
```

低速波形不是说明性输入。它实际决定低速模板、静态响应面状态和绝对坐标注册；这些结果被写入 sidecar，并供高速 forward 使用。

### 阶段 B：高速动态辨识

```text
Foundation 高速窗口
 → 读取 X、T、Theta、V、sensor_id
 → 静态合同审计
 → 支持域硬门控
 → 按原有逻辑产生 EO 候选
 → 在 [300,1000] Hz 内搜索 f
 → 优化 [A, phi, dx, delta_g_s]
 → 生成完整非线性预测波形
 → 记录 RMSE、支持率、边界和多解诊断
```

正式动态参数只有：

```text
EO, f, A, phi, dx, delta_g_s
```

### 阶段 C：正式 forward

```matlab
u_t = A .* sin(phase_t);
x_t = X_t - dx - u_t;

gLow  = g0_s;
gHigh = g0_s + delta_g_s;

Vpred_s = T_s(x_t) + ...
    Gain_s .* (F_s(xF_t,gHigh) - F_s(xF_t,gLow));
```

当前动态阶段禁止用 `mu` 重新生成空间间隙倾斜。保留的历史斜率字段仅用于审计或说明，不进入正式动态预测。

支持域是硬门控：域外点不外推，只做 mask，不进入有效拟合。

### 阶段 D：回放和独立后验

```text
完整 Foundation 回放
 → replay_unavailable / replay_fail / replay_pass
 → 质量分类 usable / diagnostic_only / rejected
 → 独立应变片/BTT 后验
 → 输出结果合同和审计信息
```

Foundation replay 是基础方法诊断，不是 R5 最终验收条件。

基础方法与提出方法的正式比较由 `R5_Compare_Foundation_vs_R5` 完成，比较固定间隙基线与包含 `delta_g_s` 的 R5 结果。

应变片和 BTT 只在动态辨识完成后用于独立后验，不参与目标函数、EO 选择或参数调节。由于位移传递比尚未独立验证，振幅是 provisional，不是硬验收条件。

## 六、输入和输出

运行前必须存在每个工况的冻结 sidecar、低速模板和 Foundation 窗口文件。缺失输入必须由安装检查明确报告，不能从旧目录或 MATLAB path 偷找。

输出位于：

```text
results/20250527/
results/20251222/
```

每个结果包含窗口行、动态参数、支持域诊断、EO 审计、静态合同和 replay 字段。

