# 等效响应模型闭环验证结果摘要

## 1. 这一轮验证要回答什么问题

`03_static_template_library_theory` 已经说明：

```text
当前 1/g 线性坐标并不是静态模板库下的最优连续重构坐标；
低指数幂律和低阶修正模型更接近当前静态模板流形。
```

但这还不是最终结论。真正要回答的是：

```text
静态模板库理论上更优的 gap 坐标，
是否真的能提升高速波形下的 gap 与振动识别？
```

`Step05_Run_Equivalent_Response_Model_ClosedLoop.m` 就是为这个问题设计的闭环验证脚本。

它保持以下部分全部不变：

1. 当前双 VP 主方法；
2. 频率候选筛选策略；
3. 最终联合精修流程；
4. 误差评价方式。

只替换一件事：

```text
连续静态模板族 F_g(x) 与导数 F'_g(x) 的重构模型。
```

因此，如果闭环结果改善，就可以更清楚地说明：

```text
提升来自静态模板库重构规则本身，
而不是来自后端优化器调参。
```

## 2. 对比模型

当前闭环对比的代表模型为：

1. `baseline_1_over_g`
   即当前默认 `1/g` 线性基线。

2. `power_law_p075_order1`
   一阶低指数幂律模型。

3. `power_law_p025_order2`
   二阶低指数幂律修正模型。

4. `exponential_lambda030`
   指数型等效响应对照模型。

## 3. smoke 工况结果

默认 `runMode = "smoke"` 为最敏感的边界工况：

```text
g_true = 0.2 mm
snr = 10 dB
```

这一工况下：

1. `power_law_p025_order2`
   平均 gap 误差约 `0.0026 mm`，
   平均频率误差约 `0.18 Hz`，
   平均幅值误差约 `0.0029 mm`。

2. 当前 `1/g` 基线
   平均 gap 误差约 `0.0157 mm`，
   平均频率误差约 `24.9 Hz`。

3. `power_law_p075_order1`
   平均频率误差约 `99.8 Hz`，
   仍表现出明显支路误判。

4. `exponential_lambda030`
   平均频率误差约 `49.9 Hz`，
   也未恢复到正确分支。

这表明：

```text
在最敏感的小间隙边界工况下，
二阶 p = 0.25 幂律模型不仅改进了静态模板逼近，
而且把频率识别从错误支路拉回了正确支路。
```

## 4. quick 工况结果

`runMode = "quick"` 检查了多个代表性间隙。当前结果显示：

1. `power_law_p025_order2`
   综合最优，平均 gap 误差约 `0.0068 mm`，
   平均频率误差约 `0.15 Hz`。

2. 当前 `1/g` 基线
   平均 gap 误差约 `0.0156 mm`，
   平均频率误差约 `41.6 Hz`。

3. 在 `g = 0.2 mm` 和 `g = 0.4 mm` 这两个小间隙边界工况，
   `power_law_p025_order2` 都成功保持正确频率分支；
   而当前 `1/g` 基线在 `g = 0.4 mm` 已出现约 `100 Hz` 的频率误差。

4. 在 `g = 1.4 mm` 工况，
   `power_law_p025_order2` 没有明显副作用，
   频率误差与当前基线同量级，
   但模板 RMSE 仍更小。

5. `power_law_p075_order1` 与 `exponential_lambda030`
   虽然静态库分析里有一定优点，
   但闭环中在部分 gap 上反而触发了支路错误，
   因此不应直接作为首选替换模型。

## 5. 当前结论

当前闭环验证支持如下更严格判断：

```text
新方法的识别瓶颈之一，确实来自静态模板库的连续重构方式；
仅把 1/g 线性替换为更合适的等效响应模型，
就能在不修改双 VP 主方法结构的前提下，
显著改善小间隙边界工况的 gap 与频率识别。
```

更具体地说：

```text
当前最强候选不是一阶 p = 0.75 幂律模型，
而是二阶 p = 0.25 幂律模型；
它在静态模板值、闭环 gap 误差和闭环频率误差上都表现最好。
```

## 6. 下一步建议

1. 用 `runMode = "full"` 继续验证更多 gap 和更多信噪比。
2. 若 full 工况仍保持优势，可将
   `power_law, p = 0.25, basis_order = 2`
   作为主方法新的默认静态模板重构模型候选。
3. 后续仍需继续观察：
   二阶幂律模型在更多边界 gap 上是否会引入导数不稳定问题，
   以及是否需要进一步增加小间隙模板密度来降低外推风险。
