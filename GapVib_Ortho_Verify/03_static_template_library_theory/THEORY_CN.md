# 静态间隙模板库理论分析

## 1. 问题背景

在叶尖间隙与叶片振动解耦问题中，高速传感器采集到的波形同时受到静态间隙和叶片振动的影响。若忽略噪声，高速波形可以表示为

```math
V(t)=F_g(x(t)-u(t))
```

其中，`g` 为叶尖间隙，`F_g(x)` 为间隙为 `g` 时的静态无振动波形，`x(t)` 为叶尖扫过传感器时对应的空间坐标，`u(t)` 为叶片振动位移。

因此，振动解耦算法的一个关键前提是：必须能够获得或重构当前高速工况间隙 `g` 对应的静态无振动波形 `F_g(x)`。如果该静态波形本身重构不准确，则后续 gap 估计、振动频率识别、幅值估计和相位估计都会受到影响。

## 2. 静态模板库的本质

实验中通常只能获得有限个离散间隙下的静态标定曲线：

```math
\{F_{g_1}(x),F_{g_2}(x),\cdots,F_{g_N}(x)\}
```

当高速工况的真实间隙 `g*` 不恰好等于某个标定间隙时，需要由有限模板库构造连续模板族：

```math
\widehat F(g,x)
```

然后再用高速波形估计等效间隙：

```math
\hat g
=
\arg\min_g
\left\|
V(t)-\widehat F(g,x(t)-u(t))
\right\|^2
```

因此，当前方法估计的不是脱离模板库的绝对真实间隙，而是在当前静态模板库及其插值规则下，使模板波形最能解释高速波形的等效间隙。当模板库重构准确时，等效间隙可以逼近真实物理间隙；当模板库存在系统性插值或外推误差时，等效间隙可能偏离真实间隙。

## 3. 静态模板流形

对每一个间隙 `g`，静态波形 `F_g(x)` 是一条函数。当 `g` 连续变化时，所有静态波形构成一个一维函数流形：

```math
\mathcal{M}=\{F_g(x):g\in[g_{\min},g_{\max}]\}
```

静态模板库只是该流形上的有限采样点。间隙方向插值的本质不是普通数值插值，而是在有限样本下重构这个函数流形。

一个好的 gap 方向坐标 `eta(g)` 应使该模板流形尽可能接近线性：

```math
F_g(x)\approx A(x)+B(x)\eta(g)
```

当前程序默认采用 `1/g` 线性插值，等价于假设

```math
F_g(x)\approx A(x)+B(x)\frac{1}{g}
```

这个假设需要物理依据，而不能仅作为经验选择。

## 4. 从传感器距离响应推导 gap 坐标

静态无振动波形可以理解为传感器距离响应的空间扫掠结果。设传感器输出主要由瞬时距离 `d` 决定：

```math
V=H(d)
```

静态无振动时，叶尖扫过传感器，瞬时距离可写为

```math
d(x,g)=g+s(x)
```

其中，`s(x)` 表示由叶尖几何、传感器敏感区和扫掠位置引起的空间距离变化。于是静态模板为

```math
F_g(x)=H(g+s(x))
```

因此，gap 方向插值变量应由距离响应函数 `H(d)` 的形式决定。

### 4.1 线性距离响应

若传感器响应在工作区间内近似为

```math
H(d)\approx c_0+c_1d
```

则

```math
F_g(x)\approx c_0+c_1s(x)+c_1g
```

此时合理的 gap 坐标为

```math
\eta(g)=g
```

### 4.2 反比距离响应

若传感器响应近似为

```math
H(d)\approx c_0+\frac{c_1}{d}
```

则

```math
F_g(x)=c_0+\frac{c_1}{g+s(x)}
```

当 `s(x)/g` 较小时，

```math
\frac{1}{g+s(x)}
=
\frac{1}{g}
-
\frac{s(x)}{g^2}
+
\frac{s^2(x)}{g^3}
-\cdots
```

若只保留主导项，则有

```math
F_g(x)\approx A(x)+B(x)\frac{1}{g}
```

这就是当前 `1/g` 线性插值的理论来源。它隐含的前提是：传感器响应主导项接近反比关系，且空间距离扰动 `s(x)` 相对 `g` 较小。

### 4.3 幂律距离响应

更一般地，若传感器响应近似为幂律形式

```math
H(d)\approx c_0+c_1d^{-p}
```

则

```math
F_g(x)=c_0+c_1(g+s(x))^{-p}
```

对 `s(x)/g` 展开：

```math
(g+s(x))^{-p}
=
g^{-p}
\left(1+\frac{s(x)}{g}\right)^{-p}
```

```math
(g+s(x))^{-p}
\approx
g^{-p}
-
p\,s(x)g^{-(p+1)}
+
\frac{p(p+1)}{2}s^2(x)g^{-(p+2)}
```

若只保留主导项，则

```math
F_g(x)\approx A(x)+B(x)g^{-p}
```

因此，当前 `1/g` 只是 `p=1` 的特殊情况。更合理的方式是由静态标定库估计等效幂律指数 `p`，而不是预先固定为 1。

### 4.4 指数距离响应

若传感器响应近似为指数衰减：

```math
H(d)\approx c_0+c_1\exp(-d/\lambda)
```

则

```math
F_g(x)
=
c_0+c_1\exp(-(g+s(x))/\lambda)
```

```math
F_g(x)
=
c_0+
\left[c_1\exp(-s(x)/\lambda)\right]\exp(-g/\lambda)
```

此时理论上合理的 gap 坐标为

```math
\eta(g)=\exp(-g/\lambda)
```

因此，`g`、`1/g`、`g^{-p}` 和 `exp(-g/lambda)` 并不是随意候选项，而是分别对应不同的传感器距离响应假设。

## 5. 小间隙端为什么更困难

在中间间隙区域，如果目标间隙两侧都有模板，则连续模板构造是插值问题。此时只要模板密度足够，误差通常可控。

但在小间隙边界，例如 `g=0.2 mm` 被留出时，识别库只能使用更大间隙模板去重构小间隙波形。这已经不是插值，而是边界外推。

从幂律展开可以看出，小间隙时高阶项会被放大：

```math
g^{-(p+1)},\quad g^{-(p+2)},\quad \cdots
```

因此，即使 `1/g` 主导项在中间间隙有效，在小间隙端也可能因为高阶项不可忽略而失效。此时 `F_g(x)` 的重构误差会增大，`F'_g(x)` 的导数误差也可能增大。

这会进一步影响振动分离。因为小振动条件下，

```math
F_g(x-u(t))
\approx
F_g(x)-F'_g(x)u(t)
```

新方法中的振动形状基依赖 `F'_g(x)`：

```math
F'_g(x)\sin(2\pi ft),
\quad
F'_g(x)\cos(2\pi ft)
```

如果模板导数由不可靠外推得到，则 gap 修正和频率识别都会受到影响。

## 6. 更严谨的改进思路

为了更准确地利用静态间隙库计算高速波形的等效间隙，应先建立物理响应约束的连续模板重构模型，而不是直接尝试不同插值方式。

一种可行模型为：

```math
F_g(x)\approx A_0(x)+A_1(x)g^{-p}
```

其中，`p` 是由静态标定库识别出的等效距离响应指数。

如果小间隙端一阶模型不足，可以引入二阶展开：

```math
F_g(x)
\approx
A_0(x)
+
A_1(x)g^{-p}
+
A_2(x)g^{-(p+1)}
```

该模型来自 `(g+s(x))^{-p}` 的级数展开，因此比单纯切换插值函数更有物理依据。

但模型阶数不能过高。静态模板数量有限时，高阶模型容易过拟合，尤其在边界外推时会变得不稳定。

## 7. 参数识别与验证指标

对候选参数 `p`，可以使用 leave-one-gap-out 验证。每次留出一个间隙 `g_i`，用剩余模板重构

```math
\widehat F_{g_i}^{(-i)}(x;p)
```

然后计算模板值误差：

```math
E_F(p)
=
\sum_i
\left\|
F_{g_i}(x)
-
\widehat F_{g_i}^{(-i)}(x;p)
\right\|^2
```

由于振动分离依赖导数，还应计算导数误差：

```math
E_{F'}(p)
=
\sum_i
\left\|
F'_{g_i}(x)
-
\widehat F_{g_i}^{\prime(-i)}(x;p)
\right\|^2
```

综合目标可以写为：

```math
p^\ast
=
\arg\min_p
\left[
E_F(p)+\lambda_d E_{F'}(p)
\right]
```

这里 `lambda_d` 用于平衡模板值重构和导数重构。若目标是服务于振动解耦，则不能只优化 `F_g(x)`，还必须约束 `F'_g(x)`。

在当前模块中，`Step01_Analyze_Gap_Coordinate_Models.m` 将上述思想具体化为几类可检验模型：

```text
1. g 线性模型；
2. 1/g 线性模型；
3. 一阶幂律模型 A_0(x)+A_1(x)g^{-p}；
4. 二阶幂律展开 A_0(x)+A_1(x)g^{-p}+A_2(x)g^{-(p+1)}；
5. 指数响应模型 A_0(x)+A_1(x)exp(-g/lambda)。
```

其中，`p` 和 `lambda` 不是直接作为最终识别参数，而是作为静态库重构模型的响应参数。它们通过留一重构误差来选择，目的是判断静态模板族在什么 gap 坐标下更接近线性。

该验证需要分别报告所有留一工况的误差，以及按模型聚合后的平均误差、最大误差和边界外推误差。这样可以区分两类结论：

```text
中间间隙插值是否准确；
小间隙边界外推是否可靠。
```

如果某一模型只降低平均误差，却显著增大边界外推误差，则不适合作为小间隙工况下的模板重构模型。

## 8. 与高速等效 gap 估计的关系

当连续模板族 `\widehat F(g,x)` 构造完成后，高速波形的等效间隙可以通过下式估计：

```math
\hat g
=
\arg\min_g
\left\|
V(t)-\widehat F(g,x(t)-u(t))
\right\|^2
```

在振动未知时，可以使用一阶投影形式：

```math
V(t)-\widehat F(g,x(t))
\approx
-
\widehat F'_g(x(t))u(t)
```

对每个候选 `g`，构造振动形状子空间：

```math
B_g=
\left[
\widehat F'_g(x)\sin(2\pi f_1t),
\widehat F'_g(x)\cos(2\pi f_1t),
\cdots
\right]
```

然后使用投影代价：

```math
J(g)
=
\min_c
\left\|
V(t)-\widehat F(g,x(t))-B_gc
\right\|^2
```

最终选择使投影后残差最小的 gap。这个过程的可靠性直接取决于 `\widehat F(g,x)` 和 `\widehat F'_g(x)` 的重构质量。

## 9. 当前结论

当前 `1/g` 线性插值并非完全没有理论依据。它对应传感器响应近似反比距离响应的主导项假设：

```math
H(d)\approx c_0+c_1/d
```

但该假设只在一定条件下成立。尤其在小间隙端，空间距离扰动项 `s(x)` 相对 `g` 不再足够小，高阶项被放大，单一 `1/g` 线性模型可能无法准确重构真实小间隙静态波形。

因此，`g=0.2 mm` 留一工况下出现的 gap 偏差和频率支路误判，不能简单归因于振动识别算法本身。更合理的解释是：小间隙边界处静态模板流形缺少足够约束，导致 `\widehat F_g(x)` 与 `\widehat F'_g(x)` 重构误差增大，进而影响高速波形的等效 gap 估计和振动参数识别。

如果需要进一步讨论“这一结论是否已经从电容传感器电场理论出发”，应结合 `THEORY_FIELD_RESPONSE_CN.md` 阅读。该文档单独说明了：

```text
电场分布变化
→ 等效电容变化
→ 电路输出电压变化
→ 静态模板 F_g(x)
```

以及为什么当前 `g^{-p}` 与指数响应模型可以被理解为机理一致的低维等效模型，而不是纯经验坐标。

后续改进应优先围绕静态模板库重构展开：

```text
1. 基于传感器距离响应推导 gap 方向坐标；
2. 用静态库识别等效响应参数，例如幂律指数 p；
3. 同时评价 F_g(x) 和 F'_g(x) 的留一重构误差；
4. 单独区分中间间隙插值与小间隙边界外推；
5. 必要时增加小间隙端模板密度。
```
