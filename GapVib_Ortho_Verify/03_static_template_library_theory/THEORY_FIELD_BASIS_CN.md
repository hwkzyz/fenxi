# 场机理启发的静态模板基函数模型

## 1. 为什么需要这一层模型

当前表现最好的模型是：

```math
F_g(x)\approx A_0(x)+A_1(x)g^{-0.25}+A_2(x)g^{-1.25}
```

它在静态库和高速闭环中效果很好，但如果直接把 `0.25` 写成传感器理论指数，物理支撑不足。更严谨的做法是：从电容/电涡流传感器的场效应机理出发，构造一组有来源的低维标定基函数，再用静态库验证。

## 2. 电容传感器的场效应展开

理想平板模型给出主项：

```math
C_{\mathrm{area}}(d)\sim \frac{\varepsilon A}{d}
```

考虑有限尺寸、边缘场、护环和叶尖几何后，更合理的写法是：

```math
C(d,x)=C_{\mathrm{area}}(d,x)+C_{\mathrm{edge}}(d,x)+C_{\mathrm{stray}}(x)
```

其中 `C_edge` 不是通用幂律函数，而是由几何和边界条件决定。有限平板电容的边缘场修正常出现与尺寸比、周长、对数项或高阶距离项有关的修正。因此，在有限工作区间内，可以构造如下低维基函数：

```math
\phi(g)=
\left[
1,\frac{1}{g},\log g,\frac{1}{g^2}
\right]
```

其中：

1. `1/g` 来自主平行场项；
2. `log(g)` 用于表示有限尺寸边缘场的弱非线性修正；
3. `1/g^2` 来自 `1/(g+s(x))` 展开后的一阶空间几何修正；
4. 常数项吸收杂散电容、电路偏置和静态背景。

这比直接写 `g^{-0.25}` 更容易解释，因为每一项都能对应到场机理或电路标定中的一类修正。

## 3. 推荐比较的模型

当前新增以下候选：

```text
cap_edge_1: [1, 1/g, log(g), 1/g^2]
cap_edge_2: [1, 1/g, 1/g^2, log(g)]
cap_edge_3: [1, 1/g, log(g), g log(g)]
inv_poly_3: [1, 1/g, 1/g^2, 1/g^3]
inv_log_2:  [1, 1/g, log(g)]
```

这些模型的定位不是完整电场解析解，而是：

```text
由场效应传感器机理启发的有限区间标定展开。
```

它们需要和当前最强经验模型 `power_law, p=0.25, order=2` 比较。如果场机理基函数能达到相近或更好精度，论文理论会更稳；如果仍然不如二阶幂律，则说明二阶幂律是当前有限模板库下更强的等效压缩近似，但不能宣称其为严格物理公式。

## 4. 评价标准

不能只看模板值误差，还要同时看：

```text
F_g(x) 重构误差；
F'_g(x) 导数误差；
小间隙边界外推误差；
高速闭环 gap 和频率识别误差。
```

最终模型选择应服从：

```text
理论来源清楚；
静态重构稳定；
高速闭环有效；
边界外推不过度失真。
```
