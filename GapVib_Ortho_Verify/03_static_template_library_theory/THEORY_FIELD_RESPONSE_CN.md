# 电容传感器电场响应到静态模板的理论框架

## 1. 这一层理论要解决什么问题

当前 `THEORY_CN.md` 已经建立了一个物理启发的响应模型：

```math
F_g(x)=H(g+s(x))
```

其中，`H(d)` 被视为“传感器对瞬时距离 `d` 的响应函数”。这个写法已经比经验插值更严谨，但它仍然把 `H(d)` 当作一个抽象函数，并没有回答：

```text
为什么电容传感器的输出电压会随叶尖距离变化？
理想 1/d 关系在什么条件下成立？
当实际电场和电路偏离理想条件时，应如何建立可验证的等效响应模型？
```

本文件的目标，就是把这条链条再往前推进一层：

```text
叶片经过传感器
→ 电场分布变化
→ 等效电容变化
→ 电路输出电压变化
→ 静态模板 F_g(x)
```

需要先说明边界：这里给出的是“机理建模框架”和“可用于选择 gap 坐标的理论依据”，并不是已经完成的三维电场严格解析解。

相关文献依据整理见 `LITERATURE_SENSOR_RESPONSE_CN.md`。该文档汇总了电容、感应和电涡流叶尖间隙传感器中常见的表达方式：理想电容公式、调理电路输出关系、标定函数以及电磁场有限元模型。

## 2. 从电场到等效电容

电容传感器的本质是：传感器电极附近的电场会受到邻近导体的影响。叶尖经过时，叶片作为导体边界条件的一部分，会改变电场线分布，从而改变传感器看到的等效电容。

如果用 `d` 表示叶尖与传感器敏感区域之间的等效距离，则可将传感器等效电容记为

```math
C=C(d)
```

更严格地说，`C(d)` 不是单纯由一对理想平板决定，而是由以下因素共同决定：

1. 传感器电极几何形状；
2. 叶尖表面几何；
3. 叶尖在空间中的相对位置；
4. 边缘场和泄漏场分布；
5. 周围介质的介电常数。

因此真实的 `C(d)` 往往不能简单写成理想平板电容公式，但可以把它理解为某个随距离单调变化的等效函数。

更严格地，等效电容应由静电场边值问题定义。设传感器电极与叶片导体之间施加电势差 `U`，电势场 `phi` 满足

```math
\nabla\cdot(\varepsilon\nabla\phi)=0
```

并满足电极、叶片和周围边界条件。电荷量可由电极表面的法向电位移积分得到：

```math
Q=\int_{\Gamma_e}\varepsilon\nabla\phi\cdot n\,dS
```

于是等效电容为

```math
C=\frac{Q}{U}
```

也可以通过电场能量定义：

```math
W=\frac{1}{2}\int_{\Omega}\varepsilon|\nabla\phi|^2\,d\Omega
```

```math
C=\frac{2W}{U^2}
```

因此，真实 `C(d,x)` 的形式原则上由几何和边界条件决定。只有在特殊几何和近似条件下，它才会退化为简单解析式。

## 3. 理想平板只是最简单极限

如果极端理想化地把叶尖和传感器看成局部平行导体，并忽略边缘场，则：

```math
C(d)\approx \frac{\varepsilon A}{d}
```

这里，`A` 是等效作用面积，`epsilon` 是介电常数。

在这个理想极限下，等效电容与距离呈严格反比。若后级电路输出电压与电容近似线性相关，则会得到：

```math
V(d)\propto \frac{1}{d}
```

这也正是当前 `1/g` 模型最朴素的物理来源。

但这只是一个理想极限，而不是实际叶尖-传感器系统的完整理论。

## 4. 为什么实际响应不能简单等同于 1/d

在实际系统中，`C(d)` 是否接近 `1/d` 取决于电极几何、叶尖几何、边缘场、介质条件和后端电路。严格地说，电场理论首先只能说明：理想平板公式成立需要特定假设；一旦这些假设不满足，`C(d)` 必须由实际边值问题决定，而不能直接写成 `epsilon A/d`。

因此，本节的严谨表述应是：

```text
边缘场和空间耦合会破坏理想平板 1/d 模型；
但它们并不必然推出某一种简单解析形式；
幂律或指数形式只能作为有限工作区间内的等效响应模型，
其有效性必须由标定数据验证。
```

实际偏离主要来自以下三类原因。

### 4.1 边缘场主导

当传感器电极尺寸、叶尖局部曲率和间隙量级接近时，电场不再主要表现为平行板之间的均匀场，而会有明显边缘场。此时有效作用面积不再是常数，电容随距离的变化率也会改变。

这会使理想平板公式不再充分：

```math
C(d)\neq \frac{\varepsilon A}{d}
```

但从这一点并不能严格推出 `C(d)` 必然服从某种幂律。更严谨的写法是：在给定传感器结构和有限工作间隙范围内，可以用低维等效模型去近似真实的 `C(d)`。幂律模型只是其中一种候选：

```math
C(d)\approx C_0+C_1 d^{-p}
```

其中 `p` 是由标定数据识别得到的等效指数，而不是由“存在边缘场”这一事实直接推出的理论常数。若该模型在留一验证中同时降低 `F_g(x)` 和 `F'_g(x)` 的误差，才说明它在当前工作区间内比 `1/d` 更适合作为等效响应坐标。

### 4.2 有效面积随位置变化

叶尖经过传感器时，传感器“看到”的不只是法向距离变化，传感区域的空间重叠关系也在变化。也就是说，叶片扫过时不仅 `d` 在变，局部耦合面积和耦合路径也在变。

因此更合理的写法应是

```math
C=C(d,\xi)
```

其中 `xi` 表示沿扫掠方向的位置相关几何状态。若将其压缩成一个空间变量 `x`，则静态模板实际上是

```math
F_g(x)=V(C(d(x,g),x))
```

所以 `F_g(x)` 的形状不只是纯距离曲线，也包含空间耦合结构。

### 4.3 电路输出不一定与 C 线性

传感器最终测到的是电压，而不是电容本身。电容变化还要经过前端电路映射。若把电路输出写成

```math
V=G(C)
```

则整体响应为

```math
V(d)=G(C(d))
```

如果 `G(C)` 近似线性，则

```math
V(d)\approx a_0+a_1 C(d)
```

这时 `V(d)` 的主要形式由 `C(d)` 决定。

但如果前端电路是振荡型、桥式、充放电型或带有非线性增益，则 `G(C)` 本身可能引入额外非线性。于是即使 `C(d)` 接近 `1/d`，最终 `V(d)` 也不一定严格等于 `1/d`。

## 5. 从电容响应到静态模板

静态无振动时，叶尖扫过传感器，空间坐标记为 `x`。可把叶尖相对传感器的局部距离写为

```math
d(x,g)=g+s(x)
```

其中：

1. `g` 表示名义叶尖间隙；
2. `s(x)` 表示扫掠过程中由叶尖外形、相对几何和敏感区投影引起的附加空间距离项。

于是等效电容为

```math
C_g(x)=C(g+s(x),x)
```

最终输出静态波形为

```math
F_g(x)=G(C_g(x))
```

如果把 `G(C(d,x))` 合并记作一个总响应函数 `H(d,x)`，则

```math
F_g(x)=H(g+s(x),x)
```

在进一步近似中，如果位置依赖主要通过 `s(x)` 吸收，而 `H` 的主要非线性由距离控制，则可退化为当前主文档中的表达：

```math
F_g(x)\approx H(g+s(x))
```

这说明 `THEORY_CN.md` 中的 `H(g+s(x))` 并不是拍脑袋的抽象写法，而是由“电场 → 电容 → 电路输出”压缩后的低维表示。

## 6. 为什么可以引入幂律坐标 g^{-p}

幂律坐标的严谨定位不是“由电场理论必然推出”，而是“由理想平板反比模型推广而来的可验证等效响应族”。若真实系统的综合响应在工作区间内可以用下式近似：

```math
V(d)\approx a_0+a_1 d^{-p}
```

则静态模板为

```math
F_g(x)\approx a_0+a_1(g+s(x))^{-p}
```

当 `s(x)/g` 较小时，展开得

```math
(g+s(x))^{-p}
\approx
g^{-p}
-p\,s(x)g^{-(p+1)}
+
\frac{p(p+1)}{2}s^2(x)g^{-(p+2)}
\cdots
```

从这里可以看出三点：

1. `1/g` 只是 `p=1` 的特例；
2. 若标定数据支持综合响应在当前区间内近似为 `d^{-p}`，则 gap 方向更合理的等效坐标可取为 `g^{-p}`；
3. 小间隙端高阶项会迅速放大，因此边界外推天然更困难。

这正是为什么当前 `Step01_Analyze_Gap_Coordinate_Models.m` 会把 `g^{-p}` 看成“由机理启发、由标定验证”的响应坐标，而不是直接把它当成电场理论的解析结论。

## 7. 为什么还不能宣称已经“从电场理论严格推导完成”

虽然上面的链条已经把问题推进到了电容传感器机理层，但它还没有达到严格电场解析推导的程度，主要因为还缺以下内容：

1. 传感器电极和叶尖的精确三维几何模型；
2. 边界条件下的电势场或电荷分布求解；
3. 从电场能量或电荷积分直接得到 `C(d,x)`；
4. 传感器前端电路 `G(C)` 的具体工作方程；
5. 理论参数与实际硬件结构参数的一一对应关系。

也就是说，当前我们建立的是：

```text
机理一致的低维响应模型
```

而不是：

```text
一阶原理严格闭式解
```

但在工程上，这一层已经足以回答一个重要问题：

```text
当前为什么不应把 1/g 线性坐标视为唯一正确选择？
```

答案是：只有在理想平板近似和近线性电路映射都成立时，`1/g` 才会自然出现；真实系统中边缘场、空间耦合和电路非线性会使这一关系偏离理想形式。偏离后的函数形式不能仅凭定性电场分析直接指定，必须结合标定数据建立等效模型。

## 8. 对当前静态模板库分析的意义

把这套电场-电容-电压框架和当前静态库分析结合起来，可以得到一个更严谨的论证链条：

1. 电容传感器输出来自电场分布变化；
2. 电场分布变化先体现为等效电容 `C(d,x)` 的变化；
3. 电路把 `C(d,x)` 映射为电压波形 `F_g(x)`；
4. 因此静态模板族本质上反映的是综合响应 `V(d)` 的形状；
5. gap 方向坐标应由这个综合响应在工作区间内的主导非线性决定；
6. `Step01` 的留一验证并不是盲目比较插值，而是在静态库层面检验候选等效响应坐标是否成立。

因此，当前 `03_static_template_library_theory` 的理论定位可以更准确地表述为：

```text
我们尚未建立电容传感器的严格三维电场解析模型，
但已经建立了从电场响应机理到静态模板坐标选择之间的理论框架，
并且这个框架可以被现有静态标定库直接验证。
```

## 9. 下一步若要继续严格化

如果要再往“电场理论严格推导”推进，建议顺序是：

1. 先明确传感器类型和前端测量电路形式；
2. 建立叶尖与电极的简化几何模型；
3. 推导或数值求解 `C(d,x)`；
4. 写出 `V=G(C)` 的电路映射；
5. 比较理论 `V(d)` 与静态标定库的拟合形式；
6. 再决定最终 gap 坐标应采用 `1/g`、`g^{-p}`，还是其他形式。

这一步做完之后，`g^{-p}` 中的 `p` 才不只是“静态库拟合参数”，而有机会被解释为具体几何与电路共同作用下的等效响应指数。

## 10. 当前理论结论的等级

为了避免把假设写成结论，当前理论中不同说法应按以下等级使用。

| 说法 | 理论等级 | 是否可直接写成结论 |
|---|---|---|
| 叶尖经过传感器会改变电场边界条件，并引起等效电容变化 | 电场机理结论 | 可以 |
| 等效电容可由电荷积分 `C=Q/U` 或能量关系 `C=2W/U^2` 定义 | 静电场理论定义 | 可以 |
| 理想平板且忽略边缘场时，`C(d)=epsilon A/d` | 特殊几何下的解析近似 | 可以，但必须说明条件 |
| 实际叶尖-传感器结构中，`C(d,x)` 一般不能直接等同于 `epsilon A/d` | 由边值问题复杂性推出的判断 | 可以 |
| 边缘场会使响应更接近 `C_0+C_1d^{-p}` | 过强表述 | 不应这样写 |
| `C_0+C_1d^{-p}` 可作为有限工作区间内的等效候选模型 | 等效建模假设 | 可以，但要说明需标定验证 |
| `p` 是具体传感器结构直接决定的理论常数 | 当前证据不足 | 暂不应写 |
| `p` 是由静态标定库识别的等效响应指数 | 数据驱动的等效参数 | 可以 |
| 若 `g^{-p}` 留一误差优于 `1/g`，说明当前工作区间内该坐标更适合模板重构 | 标定验证结论 | 可以 |

因此，当前最严谨的表述是：

```text
电场理论说明理想 1/d 关系只在特定几何和电路条件下成立；
实际传感器响应应由电场边值问题和电路映射共同决定；
在缺少完整三维电场解析或数值模型时，
可以用幂律或指数族作为等效响应模型，
并通过静态模板库留一验证判断其是否优于 1/g 基线。
```

文献层面的进一步支持是：已有叶尖间隙测量研究通常不会直接把最终输出电压固定为某个简单的 `1/g` 或 `g^{-p}` 解析式，而是通过传感器机理解释基本非线性，再依靠标定曲线、插值、拟合模型或有限元模型建立输出与间隙之间的映射。因此，本文使用静态模板库定义 `F_g(x)`，再用物理启发的低维响应展开提高连续间隙重构精度，是比直接假定解析电压公式更稳妥的表述。
