# `F_g(x)=H(g+s(x))` 响应-几何联合模型的第一轮结果

## 1. 这一轮想验证什么

当前 `1/g`、`g^{-p}` 和指数模型都属于：

```text
先选一个 gap 坐标，
再在该坐标下重构连续模板族。
```

为了更靠近物理本体，新增了一条独立理论分支：

```math
F_g(x)=H(g+s(x))
```

它的目标不是直接替换现有主程序，而是检验：

```text
当前最优幂律模型，
是不是只是一个更一般响应-几何结构的低阶近似。
```

## 2. 当前实现方式

第一轮程序 `Step03_Analyze_Response_Geometry_Model.m` 做的是一个轻量近似版本：

1. 通过不同空间列之间的 gap 轴平移对齐，估计 `s(x)`；
2. 把全部静态模板点投影到 `d = g + s(x)` 上；
3. 用单调非参数响应拟合 `H(d)`；
4. 再用该 `H(d)` 与 `s(x)` 重构被留出的静态曲线。

这一步的意义是先判断：

```text
在不修改现有主方法的前提下，
这条更本体的理论路线是否有继续深挖的价值。
```

## 3. 第一轮代表性结果

在轻量测试工况：

```text
g_holdout = [0.2, 0.4, 1.4] mm
```

得到的平均误差排序为：

1. `power_law_p025_order2`
   平均模板 RMSE 约 `0.0026`
   平均导数 RMSE 约 `0.0093`

2. `baseline_1_over_g`
   平均模板 RMSE 约 `0.0111`
   平均导数 RMSE 约 `0.0086`

3. `response_geometry_joint`
   平均模板 RMSE 约 `0.1447`
   平均导数 RMSE 约 `0.1737`

这说明：

```text
当前这个直接的 H(d)+s(x) 轻量实现，
在现有模板数量和现有近似求解方式下，
远没有达到可以替代二阶幂律模型的程度。
```

## 4. 这说明什么

这并不意味着：

```text
F_g(x)=H(g+s(x))
这条理论是错的。
```

更合理的解释是：

1. 这条理论更本体，但它的未知量更多；
2. 现有静态模板数量只有有限几个 gap 点；
3. 仅靠列间平移对齐 + 单调拟合的轻量实现，约束还不够；
4. 在这种数据量和这种求解精度下，自由模型反而更容易失稳。

因此当前第一轮结果支持这样一个判断：

```text
响应-几何联合模型在理论上值得研究，
但以当前数据规模和当前轻量求解器，
它还不如低维幂律展开稳定。
```

## 5. 对当前最优方法判断的影响

这轮结果反而进一步强化了一个现实判断：

```text
在现有静态模板库规模下，
低维、受约束、物理启发的二阶幂律模型
比更自由的响应函数联合识别模型更稳。
```

也就是说：

1. `power_law, p = 0.25, basis_order = 2`
   仍然是当前最可信的工程最优候选；
2. `F_g(x)=H(g+s(x))`
   目前更适合作为理论检验框架，
   而不是马上推进为主识别模型。

## 6. 如果要继续推进这条路线，真正需要什么

如果后续仍要深挖 `H(d)+s(x)`，最需要的不是继续微调当前轻量脚本，而是：

1. 增加静态模板数量，尤其小间隙端模板；
2. 对 `s(x)` 加更强的平滑和几何先验；
3. 对 `H(d)` 加更强的单调、曲率或响应族约束；
4. 用联合优化而不是简单两步对齐近似；
5. 最后再与当前 `p=0.25` 二阶幂律做完整 leave-one-out 和高速闭环比较。

因此，这条路线当前的定位应是：

```text
理论上值得保留，
但在现阶段不能替代二阶幂律模型作为主间隙计算方法。
```
