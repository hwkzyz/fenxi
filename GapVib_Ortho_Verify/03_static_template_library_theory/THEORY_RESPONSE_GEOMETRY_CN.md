# 基于 `F_g(x)=H(g+s(x))` 的响应-几何联合模型

## 1. 为什么还要往前走一步

当前已经证明：

```text
`1/g` 线性并不是当前静态模板库下的最优坐标；
`power_law, p = 0.25, basis_order = 2`
在现有候选模型里表现最好。
```

但这类方法仍然属于：

```text
先选一个 gap 坐标 eta(g)，
再在该坐标下做低阶重构。
```

这并不是最贴近物理本体的表述。更本体的静态模型应写成：

```math
F_g(x)=H(g+s(x))
```

其中：

1. `H(d)` 是传感器对等效距离 `d` 的综合响应；
2. `s(x)` 是叶尖扫掠过程中由几何形状、敏感区投影和空间耦合共同形成的等效距离附加项。

因此，已有的 `1/g`、`g^{-p}`、`exp(-g/lambda)` 本质上都只是对 `H(d)` 的低维近似，而不是问题本身。

## 2. 这个模型比固定 gap 坐标更强在哪里

若采用

```math
F_g(x)=H(g+s(x))
```

则所有静态曲线不再被理解为“不同 gap 下的独立波形”，而被理解为：

```text
同一个响应函数 H(d)
在不同距离基线 g 下的平移采样。
```

这带来两个直接好处。

第一，它不必预先假设：

```math
H(d)\propto \frac{1}{d}
```

或

```math
H(d)\propto d^{-p}
```

而是允许 `H(d)` 由静态库本身去识别。

第二，模板值与导数会被统一约束。因为：

```math
F'_g(x)=H'(g+s(x))\,s'(x)
```

所以只要 `H` 和 `s` 识别得更合理，`F_g(x)` 与 `F'_g(x)` 的一致性会比“模板值一套、导数再单独插值一套”的方式更强。

## 3. 从静态模板库如何识别 `H` 和 `s`

设离散模板库为：

```math
\{F_{g_i}(x_j)\},\quad i=1,\dots,N_g,\ j=1,\dots,N_x
```

目标是识别：

```math
H(d),\quad s(x_j)
```

使得

```math
F_{g_i}(x_j)\approx H(g_i+s(x_j))
```

一个自然的目标函数是：

```math
\min_{H,s}
\sum_{i,j}
\left[
F_{g_i}(x_j)-H(g_i+s(x_j))
\right]^2
+
\lambda_s \|D_x^2 s\|^2
+
\lambda_H \mathcal{R}(H)
```

其中：

1. `D_x^2 s` 用于约束 `s(x)` 平滑；
2. `\mathcal{R}(H)` 用于约束 `H(d)` 平滑或单调。

由于存在平移不唯一性：

```math
H(g+s(x)) = \widetilde H(g+(s(x)-c))
```

因此还需要一个规范条件，例如：

```math
\frac{1}{N_x}\sum_j s(x_j)=0
```

## 4. 当前可执行的近似识别方法

为了避免直接求解高维非线性函数优化，可以使用一个更稳的两步交替近似：

### 4.1 先估计 `s(x)` 的相对形状

固定某个参考空间位置 `x_ref`，则：

```math
F_g(x)=H(g+s(x)),\quad
F_g(x_{ref})=H(g+s(x_{ref}))
```

因此对于每个固定的 `x`，`F_g(x)` 作为 `g` 的函数，应当只是同一个 `H` 的水平平移版本。也就是说：

```text
不同 x 位置对应的 “gap-响应曲线”
应当在 gap 轴上可以相互对齐。
```

因此可以通过列间对齐来估计：

```math
s(x)-s(x_{ref})
```

### 4.2 再用对齐后的样本识别 `H(d)`

当 `s(x)` 近似已知后，所有观测点都对应一组：

```math
d_{ij}=g_i+s(x_j),\quad F_{g_i}(x_j)
```

于是可把全部静态模板点重新投影到单一距离轴 `d` 上，拟合：

```math
H(d)
```

若再施加单调约束，则得到的是一个：

```text
由静态模板库直接识别的非参数单调响应函数。
```

## 5. 这种方法相对幂律模型的意义

这条路线的意义不是马上替代现有 `p=0.25` 二阶幂律，而是回答更深一层的问题：

```text
当前最优幂律模型之所以有效，
到底是因为它真的接近固定幂律响应，
还是因为它在有限 gap 区间里恰好近似了某个更一般的 H(d)？
```

如果 `H(d)+s(x)` 联合模型在留一验证中继续优于二阶幂律模型，那么就说明：

```text
问题的更优描述不是“选一个更好的 gap 坐标”，
而是“直接识别响应函数 H 与空间项 s”。
```

反之，如果它并没有明显优于二阶幂律，则说明当前有限模板库还不足以支撑更自由的模型，二阶幂律反而是更稳的低维近似。

## 6. 当前理论上的预期

从理论上看，这个模型最可能在以下方面优于固定幂律：

1. 中间 gap 区域的整体一致性；
2. 模板值与导数的一致约束；
3. 对 “为什么某些 gap 坐标更好” 的解释力。

但它也可能在以下方面吃亏：

1. 模板数量太少时，自由度更高，容易不稳；
2. 小间隙边界外推仍然受训练数据覆盖限制；
3. 若 `H(d)` 与 `s(x)` 没有足够正则化，可能比二阶幂律更容易过拟合。

## 7. 因此它现在的定位是什么

当前最合理的定位不是：

```text
它一定会直接替代现有最优模型。
```

而是：

```text
它是一个更贴近物理本体的理论检验模型；
用于判断当前最优幂律模型是否只是更一般响应-几何结构的低阶近似。
```

如果它在 leave-one-gap-out 和边界外推中也能稳定优于现有 `p=0.25` 二阶幂律，那么后续再考虑把它推进到高速 gap 识别主链条中才更稳妥。
