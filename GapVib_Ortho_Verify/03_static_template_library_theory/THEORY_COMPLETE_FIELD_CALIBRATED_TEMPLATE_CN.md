# 场机理约束的静态模板库重构完整理论

## 1. 问题重新定义

叶尖经过场效应传感器时，传感器输出电压不是单纯由间隙 `g` 决定，也不是单纯由空间位置 `x` 决定，而是由传感器场分布、叶尖几何、安装状态、调理电路和叶尖相对运动共同决定。

高速无振动基准波形可写成：

```math
V(t)=F_g(x(t))
```

有振动时：

```math
V(t)=F_g(x(t)-u(t))+\varepsilon(t)
```

因此，间隙-振动解耦的关键前提不是先假定一个简单的电压-间隙解析式，而是利用有限静态标定库重构连续静态模板族：

```math
\widehat F(g,x)
```

随后在该模板族中估计高速波形对应的等效间隙。

## 2. 高速无振动间隙波形的理论构造

静态标定库由若干离散间隙下的无振动波形组成：

```math
\mathcal{D}_s=
\left\{
F_{g_i}(x),\quad i=1,\dots,N
\right\}
```

其中 `F_{g_i}(x)` 表示间隙为 `g_i` 时，叶尖无振动扫过传感器形成的完整静态电压波形。

高速工况的真实间隙记为 `g^\ast`。通常 `g^\ast` 不一定正好等于某个静态标定间隙 `g_i`，因此不能直接从静态库中取一条已有曲线作为高速无振动基准。需要由有限静态模板库构造连续静态模板族：

```math
\widehat F(g,x)
```

式中，`\widehat F(g,x)` 表示间隙为 `g`、叶尖位于空间坐标 `x` 处时的无振动静态电压模板。将高速扫掠坐标 `x(t)` 代入后，即可得到候选间隙 `g` 下对应的无振动时间波形。

于是，对于任意候选间隙 `g`，高速工况下“若无振动时应观测到的波形”定义为：

```math
V_0(t;g)=\widehat F(g,x(t))
```

其中，`x(t)` 表示高速采样时刻对应的叶尖扫掠空间坐标。因此，`V_0(t;g)` 表示在给定候选间隙 `g` 且不考虑叶尖振动时，传感器沿同一扫掠轨迹应输出的基准电压波形。

实际高速波形与该基准波形的差为：

```math
r_g(t)=V(t)-V_0(t;g)
```

当 `\widehat F(g,x)` 准确且候选 `g` 接近真实间隙时，`r_g(t)` 主要由振动扰动、噪声和小的模型误差组成；当 `\widehat F(g,x)` 构造不准确时，`r_g(t)` 会混入静态模板重构误差，从而影响后续间隙与振动参数辨识。

因此，本方法的核心不是直接从高速波形中孤立反算间隙，而是先由静态标定库建立连续无振动模板族 `\widehat F(g,x)`，再在该模板族中寻找能最好解释高速波形的等效间隙和振动参数。

## 3. 为什么不能直接使用理想平板公式

对电容式传感器，在极端理想平板条件下：

```math
C_{\mathrm{pp}}(d)=\frac{\varepsilon A}{d}
```

若调理电路输出近似与电容线性相关，则可得到 `1/d` 型响应。这是当前 `1/g` 插值的物理来源。

但该公式成立需要很强假设：

1. 电极和叶尖局部可视为平行导体；
2. 有效面积 `A` 不随位置变化；
3. 边缘场和泄漏场可以忽略；
4. 周围介质均匀；
5. 电路输出与电容近似线性。

真实叶尖-探头系统中，这些条件通常不能完全满足。因此，真实电容更合理地表示为：

```math
C(d,x;\Omega)
```

其中 `\Omega` 表示探头尺寸、护环、叶尖形状、安装状态、介质和边界条件等。

更严格地，电容应由静电场边值问题定义：

```math
\nabla\cdot(\varepsilon\nabla\phi)=0
```

并通过电荷或场能量得到：

```math
C=\frac{Q}{U}
```

或

```math
C=\frac{2W}{U^2}
```

因此，`C=epsilon A/d` 只是一个理想极限，而不是完整叶尖传感器模型。

## 4. 边缘场之后应该怎样写

考虑边缘场、有限尺寸和杂散电容后，可写成：

```math
C(d,x;\Omega)
=
C_{\mathrm{area}}(d,x)
+C_{\mathrm{edge}}(d,x;\Omega)
+C_{\mathrm{stray}}(x;\Omega)
```

其中主面积项仍保留理想平行场的来源：

```math
C_{\mathrm{area}}(d,x)\sim \frac{\varepsilon A_{\mathrm{eff}}(x)}{d}
```

边缘场项 `C_edge` 由有限几何边界决定，通常与电极周长、尺寸比、屏蔽结构、间距比和对数型修正有关。它不能被简单、普适地写成某个固定 `d^{-p}`。

这里需要特别说明：引入对数项并不是认为真实电容严格等于 `a+b/g+c log(g)`。更严谨的依据是，有限尺寸电极的边缘场修正往往不能由理想平板主项完全描述，在经典有限平板电容问题中，边缘场修正可通过渐近展开、保角映射或数值边值问题处理，其中会出现与尺寸比和间隙比相关的弱非线性项。Yariv 对有限平板电容边缘修正的分析表明，理想 textbook formula 之外需要 leading-order edge correction，而该修正由几何边界和间距共同决定，并非简单普适幂律。Yu 等关于叶尖间隙测量技术的综述也指出，实际传感器通常需要通过传感器特性曲线、查表、插值或拟合完成间隙反算，而不是直接使用单一解析公式。

叶尖扫掠时还存在：

1. 有效耦合面积变化；
2. 横向重叠变化；
3. 边缘场路径变化；
4. 叶尖倾角和曲率影响；
5. 电路映射非线性。

因此最终电压应写成：

```math
F_g(x)=G(C(g,x;\Omega))
```

而不是直接写成：

```math
F_g(x)\propto \frac{1}{g}
```

## 5. 从场机理到可验证标定展开

虽然完整 `C(g,x;\Omega)` 需要三维电场或电磁场求解，但实际工程中通常通过静态标定曲线建立输出与间隙之间的映射。因此，本文采用“场机理启发的标定展开”：

```math
F_g(x)
\approx
B_0(x)+B_1(x)\phi_1(g)+B_2(x)\phi_2(g)+\cdots
```

这里的 `\phi_k(g)` 不是任意选取，而应来自场机理和电路映射的低阶近似。

对电容式传感器，候选基函数应从以下四类来源构造，而不是任意试函数：

```math
1,\quad \frac{1}{g},\quad \log g,\quad \frac{1}{g^2},\quad \frac{1}{g^3}
```

各项来源如下。

第一，常数项：

```math
1
```

用于吸收与当前间隙弱相关或在工作区间内近似缓慢变化的成分，包括杂散电容、调理电路偏置、背景耦合和静态模板的基线分量。文献中的实际电容式叶尖间隙系统通常需要先标定传感器特性曲线，说明输出中包含不能仅由理想 `1/g` 主项解释的系统响应。

第二，理想平行场主项：

```math
\frac{1}{g}
```

来自理想平板电容：

```math
C_{\mathrm{pp}}=\frac{\varepsilon A}{g}
```

如果电路在局部工作区间内近似线性，则输出电压包含随 `1/g` 变化的主导成分。因此，`1/g` 是必须保留的物理主项，而不是纯经验插值变量。Yu 等综述中也以平板电容公式解释电容法叶尖间隙测量的基本原理。

第三，边缘场弱修正项：

```math
\log g
```

该项用于表示有限尺寸电极和叶尖边缘场引起的弱非线性变化。对于有限电极，当间隙与电极特征尺寸不再满足理想无限平板条件时，边缘场线向外扩散，有效耦合面积和边缘电荷分布会随间隙改变。有限平板电容的边缘修正常依赖间隙与几何尺寸之比，并可能表现为对数型或近似对数型弱变化。因此，在有限工作区间内，`\log g` 可作为边缘场修正的低维代理项。

需要强调，`\log g` 不是严格闭式解，而是“边缘场修正的可验证低维代理”。是否采用它，必须由静态模板库的留一验证和高速闭环验证共同决定。

第四，空间几何展开项：

```math
\frac{1}{g^2},\quad \frac{1}{g^3}
```

叶尖扫过传感器时，等效距离不只是名义间隙，还包含空间位置相关项：

```math
d(x,g)=g+s(x)
```

若主响应含有反比成分，则：

```math
\frac{1}{g+s(x)}
=
\frac{1}{g}
-
\frac{s(x)}{g^2}
+
\frac{s^2(x)}{g^3}
-\cdots
```

因此 `1/g^2` 和 `1/g^3` 可解释为空间几何项 `s(x)` 对理想反比响应的高阶修正。它们有物理来源，但也更容易在模板数量有限时放大边界外推误差，所以不能盲目增加阶数。

这里的“高阶修正”需要严格理解。若传感器响应的主导项近似为理想反比关系，并且局部等效距离可写成 `d(x,g)=g+s(x)`，则：

```math
\frac{1}{d(x,g)}
=
\frac{1}{g+s(x)}
```

当满足

```math
\left|\frac{s(x)}{g}\right|<1
```

时，可以作几何级数展开：

```math
\frac{1}{g+s(x)}
=
\frac{1}{g}
\left(1+\frac{s(x)}{g}\right)^{-1}
```

更准确地写为：

```math
\frac{1}{g+s(x)}
=
\frac{1}{g}
\sum_{k=0}^{\infty}
\left(-\frac{s(x)}{g}\right)^k
```

即：

```math
\frac{1}{g+s(x)}
=
\frac{1}{g}
-
\frac{s(x)}{g^2}
+
\frac{s^2(x)}{g^3}
-
\frac{s^3(x)}{g^4}
\cdots
```

因此，`1/g^2` 和 `1/g^3` 并不是独立假设出来的经验项，而是当理想反比主项受到空间几何扰动 `s(x)` 调制时自然出现的高阶项。由于 `s(x)` 随空间位置变化，展开中的系数也随 `x` 变化：

```math
B_1(x)\frac{1}{g}
+
B_2(x)\frac{1}{g^2}
+
B_3(x)\frac{1}{g^3}
```

其中 `B_2(x)`、`B_3(x)` 实际吸收了 `s(x)`、`s^2(x)` 以及有效面积、电路增益等空间相关因素。

但这个展开同时给出一个重要限制：它只有在 `|s(x)/g|` 足够小、且目标间隙位于标定区间内或附近时才稳定。小间隙端 `g` 较小时，`1/g^2`、`1/g^3` 增长速度远快于 `1/g`。如果目标间隙位于边界外推区间，例如最小间隙模板被留出，则这些高阶项会显著放大少量系数误差和测量噪声，导致外推曲线和导数曲线发散。

因此，高阶反比项具有明确的物理来源，但其适用性受收敛条件、标定间隙覆盖范围和噪声水平共同限制。对于有限数量的静态模板库，主模型不宜盲目提高阶数，而应优先采用来源清楚、阶数较低且在边界处更稳定的标定展开。

上述四类基函数分别对应：

1. 背景或偏置项；
2. 理想平行场主项；
3. 边缘场弱修正；
4. 空间几何高阶修正。

因此，一个具有物理来源且结构简单的主理论模型为：

```math
F_g(x)
\approx
B_0(x)
+B_1(x)\frac{1}{g}
+B_2(x)\log g
```

即：

```math
\phi(g)=\left[1,\frac{1}{g},\log g\right]
```

从模型来源看，`[1,1/g,\log g]` 分别对应背景或偏置响应、理想平行场主项和边缘场弱修正。该模型不假定真实传感器输出严格服从某个闭式幂律，而是把静态模板库视为标定得到的响应族，并用低维、可解释的间隙基函数对其进行连续化表示。

从模型复杂度看，`[1,1/g,\log g]` 比加入 `1/g^2`、`1/g^3` 的高阶反比模型更保守。它保留了理想平行场主项和边缘场弱修正，同时避免在小间隙外推时过度放大高阶反比项。因此，它适合作为有限静态模板库下的主理论模型。

基于该模型，连续无振动模板族可写成：

```math
\widehat F(g,x)
=
B_0(x)
+
B_1(x)\frac{1}{g}
+
B_2(x)\log g
```

为后续书写方便，定义该模板对空间坐标的偏导数为：

```math
\widehat F_x'(g,x)
=
\frac{\partial \widehat F(g,x)}{\partial x}
```

该导数描述的是在间隙 `g` 固定时，叶尖空间位置发生微小变化引起的电压变化率。

其中 `B_0(x)`、`B_1(x)` 和 `B_2(x)` 由静态标定模板族确定。为了说明这些系数的来源，设静态标定库包含 `N` 个已知间隙：

```math
g_1,g_2,\cdots,g_N
```

在统一空间采样点 `x_j` 上，静态模板库给出对应的无振动电压值：

```math
F_{g_1}(x_j),F_{g_2}(x_j),\cdots,F_{g_N}(x_j)
```

根据间隙基函数

```math
\phi(g)=
\left[
1,\frac{1}{g},\log g
\right]
```

构造标定矩阵：

```math
\Phi=
\begin{bmatrix}
1 & 1/g_1 & \log g_1\\
1 & 1/g_2 & \log g_2\\
\cdots & \cdots & \cdots\\
1 & 1/g_N & \log g_N
\end{bmatrix}
```

对每一个空间位置 `x_j`，将该位置处的静态模板值组成向量：

```math
y_j=
\begin{bmatrix}
F_{g_1}(x_j)\\
F_{g_2}(x_j)\\
\cdots\\
F_{g_N}(x_j)
\end{bmatrix}
```

然后通过最小二乘确定该空间位置处的展开系数：

```math
\begin{bmatrix}
B_0(x_j)\\
B_1(x_j)\\
B_2(x_j)
\end{bmatrix}
=
\arg\min_b
\left\|
\Phi b-y_j
\right\|^2
```

如果 `\Phi^T\Phi` 条件良好，也可写成等价的正规方程形式：

```math
b_j^\ast=
(\Phi^T\Phi)^{-1}\Phi^T y_j
```

其中 `b_j^\ast=[B_0(x_j),B_1(x_j),B_2(x_j)]^T`。上述过程对每个空间采样点独立进行，因此得到的不是三个常数，而是三条随空间位置变化的系数函数：

```math
B_0(x),\quad B_1(x),\quad B_2(x)
```

它们共同定义了连续静态模板族 `\widehat F(g,x)`。对任意候选间隙 `g`，高速无振动基准波形为：

```math
V_0(t;g)
=
\widehat F(g,x(t))
=
B_0(x(t))
+
B_1(x(t))\frac{1}{g}
+
B_2(x(t))\log g
```

这一定义把静态模板库、候选间隙和高速扫掠坐标统一起来，使得后续间隙估计和振动解耦都以同一个连续无振动模板族为基础。

## 6. 静态库验证标准

给定离散静态模板库：

```math
\{F_{g_i}(x)\}_{i=1}^{N}
```

对每一个候选模型，采用留一间隙验证：

```math
\widehat F_{g_i}^{(-i)}(x)
```

并计算：

```math
E_F=
\left\|
F_{g_i}(x)-\widehat F_{g_i}^{(-i)}(x)
\right\|
```

以及导数误差：

```math
E_{F'}=
\left\|
F'_{g_i}(x)-\widehat F_{g_i}^{\prime(-i)}(x)
\right\|
```

这里必须同时评估 `F_g(x)` 和 `F'_g(x)`。原因在于，振动位移首先改变叶尖相对传感器的空间位置，而电压变化的一阶响应由静态模板的空间导数决定。

在无振动时，叶尖扫过探头形成静态波形：

```math
V_0(t)=F_g(x(t))
```

当叶片发生微小振动位移 `u(t)` 时，叶尖相对探头的空间位置发生扰动。若取振动位移使叶尖扫掠坐标变为 `x(t)-u(t)`，则：

```math
V(t)=F_g(x(t)-u(t))
```

对 `u(t)` 在 `x(t)` 处做一阶 Taylor 展开：

```math
F_g(x(t)-u(t))
\approx
F_g(x(t))-F'_g(x(t))u(t)
```

这里的 `F'_g(x(t))` 是静态模板在当前扫掠位置处对空间坐标的导数，表示：

它表征叶尖在当前扫掠位置发生单位空间位移时，传感器输出电压的一阶变化率。

因此，振动并不是简单地给电压叠加一个独立信号，而是通过“沿静态波形斜率方向的空间扰动”进入测量波形。静态波形哪里斜率大，同样的位移会产生更大的电压变化；静态波形哪里斜率接近零，同样的位移对电压影响就弱。

若振动可写成：

```math
u(t)=A\sin(2\pi f t+\phi)
```

则一阶振动项为：

```math
-F'_g(x(t))A\sin(2\pi f t+\phi)
```

进一步展开为正弦和余弦基：

```math
-F'_g(x(t))A\cos\phi\sin(2\pi f t)
-F'_g(x(t))A\sin\phi\cos(2\pi f t)
```

所以在固定候选频率 `f` 下，振动造成的波形变化位于由以下基函数张成的子空间：

```math
F'_g(x(t))\sin(2\pi f t),
\quad
F'_g(x(t))\cos(2\pi f t)
```

这就是“振动基投影”的理论来源。换句话说，`F'_g(x(t))` 决定了振动位移如何映射成电压波形变化，是间隙修正和频率候选筛选的关键物理量。进入实际辨识时，真实导数 `F'_g(x(t))` 由重构模板的空间偏导数 `\widehat F_x'(g,x(t))` 代替。

因此，如果只重构 `F_g(x)` 而不保证 `F'_g(x)` 稳定，会出现两类问题：

1. 间隙估计可能看起来不错，但振动项的投影子空间偏离真实方向；
2. 残差中属于振动的一阶成分无法被正确解释，进而可能导致频率支路误判或幅值偏差。

所以静态模板库重构必须同时验证：

1. 模板值 `F_g(x)`；
2. 空间导数 `F'_g(x)`。

因此，模板值和空间导数都必须作为理论评价对象。若只保证 `F_g(x)` 的幅值拟合，而 `F'_g(x)` 不稳定，则后续振动子空间将偏离真实物理扰动方向。

## 7. 高速波形辨识准则

静态库误差只能说明模板重构能力，不能直接说明高速波形中的间隙-振动解耦能力。最终辨识应回到完整高速波形模型：

```math
V(t)=
\widehat F
\left(
g,\,
x(t)-u(t)
\right)
+\varepsilon(t)
```

因此，候选静态模板模型是否合理，最终应由其在完整高速波形中的解释能力决定。若某一模板模型虽然在静态库重构中误差较小，但在完整波形辨识中导致频率支路错误或振动参数偏差，则说明该模板模型并未真正服务于间隙-振动解耦。

## 8. 与完整振动参数辨识方法的关系

上述静态模板重构不是独立目标，而是完整间隙-振动联合辨识的前置基础。完整理论链条如下。

### 8.1 完整观测模型

高速波形模型为：

```math
V(t)=F_g(x(t)-u(t))+\varepsilon(t)
```

在后续辨识中，真实静态模板 `F_g(x)` 由重构模板 `\widehat F(g,x)` 代替，因此完整观测模型写为：

```math
V(t)=
\widehat F(g,x(t)-u(t))
+\varepsilon(t)
```

其中：

1. `\widehat F(g,x)` 是由静态模板库重构得到的连续无振动模板族；
2. `g` 是待估计间隙；
3. `x(t)` 是高速采样时刻对应的叶尖无振动扫掠坐标；
4. `u(t)` 是叶尖振动位移；
5. `\varepsilon(t)` 是噪声和未建模误差。

若考虑两阶振动成分，可写为：

```math
u(t)=
\sum_{k=1}^{2}
A_k\sin(2\pi f_k t+\phi_k)
```

辨识目标是同时获得：

```math
g,\quad f_k,\quad A_k,\quad \phi_k
```

### 8.2 快速静态间隙初值

第一步先忽略振动，使用静态模板族估计初始等效间隙：

```math
g_0
=
\arg\min_g
\left\|
V(t)-\widehat F(g,x(t))
\right\|^2
```

这一步不是最终结果，而是给后续频率识别和间隙修正提供初始位置。如果静态模板族 `\widehat F(g,x)` 在小间隙端外推不准，`g_0` 会被系统性带偏，并进一步影响后续频率候选。

### 8.3 第一次变量投影频率候选识别

在初始等效间隙 `g_0` 下，先把静态模板固定，近似写成：

```math
r_0(t)
=
V(t)-\widehat F(g_0,x(t))
```

小振动一阶展开为：

```math
r_0(t)
\approx
-
\widehat F_x'(g_0,x(t))u(t)
```

对于候选频率 `f`，构造线性振动基：

```math
\widehat F_x'(g_0,x(t))\sin(2\pi f t),
\quad
\widehat F_x'(g_0,x(t))\cos(2\pi f t)
```

在固定频率 `f` 时，振动位移可等价写成正弦项和余弦项的线性组合：

```math
u(t)=a\sin(2\pi f t)+b\cos(2\pi f t)
```

其中 `a` 和 `b` 是与振动幅值、相位等价的线性系数。于是，对给定的候选频率，残差中由一阶振动造成的部分可写成：

```math
B_f c_f
```

其中 `B_f` 是由上述两列振动基组成的矩阵，`c_f=[c_1,c_2]^T` 是待估计的线性系数。频率 `f` 是非线性参数，而系数 `c_f` 在固定 `f` 后可由最小二乘解析求得：

```math
c_f^\ast
=
\arg\min_{c_f}
\left\|
r_0-B_f c_f
\right\|^2
```

变量投影法的核心思想是：不把频率、幅值和相位全部放入同一个非线性搜索，而是在每个候选频率下先把线性系数投影求解掉，再只比较频率对应的投影残差。令

```math
P_{B_f}
=
B_f(B_f^TB_f)^{-1}B_f^T
```

表示到振动基子空间的正交投影算子，则频率搜索可写为：

```math
f^\ast
=
\arg\min_f
\left\|
\left(I-P_{B_f}\right)r_0
\right\|^2
```

其中 `I` 为单位算子。该步骤的目的不是最终确认振动参数，而是在初始等效间隙下获得合理的频率候选，为后续间隙修正构造振动子空间。

从优化理论上看，该问题属于可分离非线性最小二乘问题：频率是非线性变量，而正弦和余弦系数是线性变量。变量投影法正是针对这类“线性变量和非线性变量可分离”的最小二乘问题提出的，其优点是降低非线性搜索维数，并改善直接联合搜索时的病态性。

对于两阶振动，频率候选可扩展为 `f_1,f_2` 的组合，矩阵 `B_f` 相应包含每个频率对应的正弦和余弦振动基。变量投影法仍然只对频率进行非线性搜索，而将每个频率下的线性系数通过最小二乘消去。

### 8.4 振动基间隙修正

仅用静态残差估计间隙会受到振动污染。为避免把振动造成的波形变化误认为间隙偏差，对每个候选间隙构造投影代价。

对候选 `g`：

```math
r_g(t)
=
V(t)-\widehat F(g,x(t))
```

根据第一次变量投影频率候选识别得到的候选频率集合，构造振动解释子空间：

```math
B_g=
\left[
\widehat F_x'(g,x(t))\sin(2\pi f_1t),
\widehat F_x'(g,x(t))\cos(2\pi f_1t),
\cdots
\right]
```

然后计算投影后残差：

```math
J(g)
=
\min_c
\left\|
r_g(t)-B_gc
\right\|^2
```

最终选择：

```math
\widehat g_{\mathrm{corr}}
=
\arg\min_g J(g)
```

该步骤的含义是：在比较不同候选间隙时，先允许残差中可由一阶振动解释的部分被线性投影消除，然后再判断哪个间隙对应的静态模板更合理。这样可以减少振动对间隙初值的污染。

### 8.5 第二次变量投影频率候选识别

在修正后的间隙 `\widehat g_{\mathrm{corr}}` 下重新执行变量投影频率搜索：

```math
r_{\mathrm{corr}}(t)
=
V(t)-\widehat F(\widehat g_{\mathrm{corr}},x(t))
```

再对候选频率进行变量投影搜索。与第一次变量投影搜索不同，第二次搜索使用更准确的间隙和导数模板，因此残差中的静态模板偏差更小，频率候选更可靠。

在噪声、弱模态或模板外推误差存在时，单个投影残差最小的频率分支可能并不对应真实振动。因此，理论上可保留若干投影残差较小的候选分支，并将它们交给后续局部波形精修和完整非线性联合优化判断。

### 8.6 候选局部波形精修

对第二次变量投影搜索得到的若干候选，在固定间隙附近进行局部波形精修。该步骤使用完整静态模板：

```math
\widehat F(g,x(t)-u(t))
```

而不是只依赖一阶线性残差。其目的是在进入完整联合优化前剔除明显不合理的频率分支，降低最终优化的搜索负担。

### 8.7 最终完整非线性联合优化

最终对少数候选执行完整非线性联合精修：

```math
\min_{g,\{A_k,f_k,\phi_k\}}
\left\|
V(t)-
\widehat F
\left(
g,\,
x(t)-
\sum_k A_k\sin(2\pi f_k t+\phi_k)
\right)
\right\|^2
```

这里将静态模板族显式写成 `\widehat F(g,x)`，而不是写成下标形式 `\widehat F_g(x)`，是为了强调：最终阶段的间隙 `g` 是真正参与非线性优化的变量。优化过程中，`g` 的变化会改变整条静态模板波形：

```math
x\mapsto \widehat F(g,x)
```

同时，振动参数 `A_k,f_k,\phi_k` 会改变模板的空间采样位置：

```math
x(t)-\sum_k A_k\sin(2\pi f_k t+\phi_k)
```

因此最终优化不是“固定间隙后只优化振动”，也不是“先定振动再估计间隙”，而是在完整波形模型中同时调整：

1. 间隙 `g`；
2. 频率 `f_k`；
3. 幅值 `A_k`；
4. 相位 `\phi_k`。

该目标回到原始非线性观测模型，不再只使用一阶线性近似。不同候选分支经过联合优化后，按完整波形 RMSE 选择最终结果。

因此，空间导数 `\widehat F_x'(g,x(t))` 并不是最终模型中“替代”完整模板的近似，而是在间隙修正和变量投影候选筛选中用于构造振动子空间；最终判断仍回到完整非线性模板模型。

### 8.8 静态模板模型为什么会影响振动参数

静态模板重构误差会通过三条路径影响振动参数：

1. 影响静态间隙初值 `g_0`，使第一次变量投影搜索的残差带有系统偏差；
2. 影响导数模板 `\widehat F_x'(g,x(t))`，使振动子空间方向偏离真实振动影响；
3. 影响最终非线性模板 `\widehat F(g,x(t)-u(t))`，使优化器可能通过错误频率、幅值或间隙去补偿模板误差。

因此，模板模型的优劣不能只看间隙估计，还必须看频率支路是否正确、幅值相位是否稳定、完整波形 RMSE 是否降低。

## 9. 理论依据与参考文献

上述理论主要依赖以下几类文献依据：

1. 理想平板电容公式是电容式间隙测量的基本起点，但只在忽略边缘场、有效面积变化和电路非线性时成立。叶尖间隙测量综述通常也将实际传感器建模为需要特性曲线标定、查表、插值或拟合的工程测量系统，而不是单一闭式公式。
2. 有限平板电容的边缘场修正已有经典电场理论基础。Kirchhoff 对圆形平行板电容小间距情形给出过含边缘效应的渐近结果；后续 Love 方程、保角映射、奇异摄动和数值边值问题研究均表明，有限尺寸电极的电容偏离理想平板公式，并且修正项由几何尺寸比和间隙比共同决定。
3. 变量投影法由 Golub 和 Pereyra 针对可分离非线性最小二乘问题提出，适用于模型对一部分参数线性、对另一部分参数非线性的情形。本文频率候选识别中，正弦和余弦系数为线性变量，频率为非线性变量，因此可采用变量投影法降低非线性搜索维数。

可在论文中引用的代表性文献包括：

1. Yu, B., Ke, H., Shen, E., & Zhang, T. A review of blade tip clearance-measuring technologies for gas turbine engines. Measurement and Control, 2020.
2. Yariv, E. Edge corrections for parallel-plate capacitors. European Journal of Applied Mathematics, 2020.
3. Reichert, B., & Ristivojevic, Z. Analytical results for the capacitance of a circular plate capacitor. Physical Review Research, 2020.
4. Golub, G. H., & Pereyra, V. The differentiation of pseudo-inverses and nonlinear least squares problems whose variables separate. SIAM Journal on Numerical Analysis, 1973.
5. Golub, G. H., & Pereyra, V. Separable nonlinear least squares: the variable projection method and its applications. Inverse Problems, 2003.

## 10. 理论表述建议

可表述为：理想平板电容模型给出了 `1/g` 主导项，但实际叶尖-探头系统中存在有限尺寸边缘场、有效耦合面积变化、杂散电容和电路映射非线性，导致输出电压不再满足简单 `1/g` 关系。为避免预设不可靠的闭式电压-间隙公式，本文将静态波形族视为由标定模板定义的响应族，并构造场机理启发的低维标定展开。具体而言，采用 `[1,1/g,\log g]` 表示背景或偏置响应、理想平行场主项和边缘场弱修正。对任意候选间隙 `g`，该展开给出连续无振动模板 `\widehat F(g,x)`，并由 `V_0(t;g)=\widehat F(g,x(t))` 构造高速工况下的无振动基准波形。随后，基于 `F'_g(x(t))` 的一阶线性化建立振动位移到电压扰动的映射，采用变量投影法筛选频率候选，并最终在完整非线性模型中联合优化间隙、频率、幅值和相位。
