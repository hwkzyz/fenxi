# 静态模板库坐标模型第一轮结果摘要

## 1. 分析目的

`Step01_Analyze_Gap_Coordinate_Models.m` 的目标不是直接优化高速识别结果，而是先回答一个更基础的问题：

```text
在有限静态模板库下，哪一种 gap 方向坐标更适合重构连续模板 F_g(x) 及其导数 F'_g(x)？
```

当前比较的模型包括：

1. `g` 线性模型；
2. `1/g` 线性模型；
3. 一阶幂律模型 `A_0(x)+A_1(x)g^{-p}`；
4. 二阶幂律模型 `A_0(x)+A_1(x)g^{-p}+A_2(x)g^{-(p+1)}`；
5. 指数模型 `A_0(x)+A_1(x)exp(-g/lambda)`。

误差指标同时考虑：

```text
模板值重构误差 F_g(x)；
模板导数重构误差 F'_g(x)；
边界小间隙外推误差。
```

## 2. 当前总体排序

基于 `gap_coordinate_model_summary.csv` 的综合得分，当前前几名为：

1. `power_law, p = 0.25, basis_order = 2`
2. `power_law, p = 0.50, basis_order = 2`
3. `power_law, p = 0.75, basis_order = 1`
4. `power_law, p = 0.50, basis_order = 1`
5. `exponential, lambda = 0.30, basis_order = 1`

其中当前程序默认使用的 `1/g` 线性模型等价于 `power_law, p = 1, basis_order = 1`，其综合得分明显落后于上述几种模型。

这说明：

```text
当前 1/g 线性插值并不是静态库意义下的最优 gap 坐标；
更柔和的幂律坐标（p < 1）更接近当前静态模板流形；
适度的二阶幂律展开可以进一步降低模板值重构误差。
```

## 3. 对 1/g 线性模型的直接结论

`1/g` 线性模型不是完全没有物理依据。它对应反比距离响应的主导项假设，因此比直接 `g` 线性要合理得多。

但从留一结果看，它不是最优模型：

```text
g 线性：小间隙边界外推误差很大；
1/g 线性：明显优于 g 线性；
低指数幂律 / 低阶指数模型：进一步优于 1/g 线性。
```

因此当前更准确的表述应为：

```text
1/g 线性不是错误方向，
但它更像是一个一阶近似，
而不是当前静态模板库下最合适的连续重构坐标。
```

## 4. 小间隙边界 g = 0.2 mm 的信息

边界留一 `g = 0.2 mm` 最能反映模型是否适合小间隙外推。当前对比表明：

```text
g 线性边界误差最大；
1/g 线性显著改善；
部分低指数幂律和指数模型还能继续降低边界模板误差；
但某些高阶或高指数模型在边界处会迅速失稳。
```

尤其值得注意的是：

1. `power_law, p = 0.25, basis_order = 2` 的边界模板 RMSE 最小，但导数误差并不占优。
2. `power_law, p = 0.75, basis_order = 1` 的导数误差较好，整体更均衡。
3. `exponential, lambda = 0.30` 在边界模板和导数误差上也表现较稳。

这说明：

```text
最小模板值误差的模型，不一定就是最适合振动解耦的模型；
因为振动分离还依赖 F'_g(x)，所以必须同时看导数误差。
```

## 5. 当前最重要的理解

这轮结果支持这样一个判断：

```text
静态模板族在 gap 方向上的变化，
并不严格服从 1/g 单一线性关系；
更合理的描述是：
它更接近某种低指数幂律坐标下的近线性变化，
必要时还需要加入一项低阶高阶修正。
```

也就是说，当前模板流形更像：

```math
F_g(x)\approx A_0(x)+A_1(x)g^{-p}
```

或者

```math
F_g(x)\approx A_0(x)+A_1(x)g^{-p}+A_2(x)g^{-(p+1)}
```

而不是简单固定为：

```math
F_g(x)\approx A(x)+B(x)/g
```

## 6. 现阶段不应过早下的结论

虽然 `power_law, p = 0.25, basis_order = 2` 当前综合排序第一，但还不能立刻说“最终就应该改成这个模型”。原因有三点：

1. 当前排序只基于静态库 leave-one-gap-out 重构，还没有进入高速振动识别闭环。
2. 二阶模型自由度更高，可能在模板值上更占优势，但进入高速识别后未必最稳。
3. 对振动解耦而言，`F'_g(x)` 的导数稳定性和边界外推稳定性同样重要。

因此下一步更稳妥的路径是：

```text
先从 Step01 结果中选出 2~3 个候选坐标模型；
再放入 02_gap_library_sensitivity，
比较高速等效 gap、频率、幅值和 RMSE；
最后决定是否替换当前 1/g 线性模型。
```

## 7. 建议的候选模型

基于当前第一轮结果，建议优先推进这三类候选模型：

1. `power_law, p = 0.75, basis_order = 1`
   比 1/g 更柔和，导数误差较优，模型仍然简单。

2. `power_law, p = 0.25, basis_order = 2`
   模板值重构最好，可作为“增强型幂律模型”候选。

3. `exponential, lambda = 0.30, basis_order = 1`
   作为不同物理响应形式的代表，用于对比幂律模型是否只是经验拟合。

当前默认模型：

4. `power_law, p = 1.00, basis_order = 1`
   作为现有 `1/g` 线性基线，必须保留用于比较。

## 8. 当前结论

这轮分析最重要的结论不是“已经找到最终最优模型”，而是：

```text
静态模板库的理论分析已经给出明确证据：
当前 1/g 线性坐标并非最优；
静态模板流形更接近低指数幂律或低阶修正模型；
小间隙边界外推问题不能仅靠后端优化器修补，
必须优先改进静态模板族 F_g(x) 和 F'_g(x) 的重构方式。
```

## 9. 等效响应假设验证

`Step02_Verify_Equivalent_Response_Assumptions.m` 进一步把候选模型与当前 `1/g` 基线做配对验证。它不是重新搜索所有模型，而是选出代表模型，并在每个留一间隙上直接比较：

```text
候选模型误差相对 1/g 基线的改善率；
边界小间隙外推改善率；
完整静态库中 F_g(x) 和 F'_g(x) 的线性解释度 R^2。
```

当前验证结果显示：

1. `power_law, p = 0.25, basis_order = 2`
   模板值平均改善约 `89.3%`，完整静态库模板 `R^2` 约 `0.9988`。但它的边界导数改善为负，说明二阶模型虽然非常擅长拟合模板值，却可能牺牲小间隙端导数稳定性。

2. `power_law, p = 0.75, basis_order = 1`
   模板值平均改善约 `55.3%`，导数平均改善约 `12.2%`，边界模板和边界导数也同时改善。这个模型虽然模板值拟合不如二阶 `p=0.25`，但更均衡，更适合优先进入高速识别闭环验证。

3. `exponential, lambda = 0.30, basis_order = 1`
   边界外推有改善，但总体导数改善为负，说明指数模型可以作为对照，但目前不应作为首选替换模型。

因此，`Step02` 对理论假设给出的更严格结论是：

```text
低指数幂律模型确实比当前 1/g 基线更符合静态模板库；
但“模板值最优”的模型不一定“振动解耦最优”；
因此必须进入高速识别闭环再做最终判断，
不能仅凭静态模板值或静态导数误差直接决定替换模型。
```

## 10. 高速闭环验证后的修正结论

`02_gap_library_sensitivity/Step05_Run_Equivalent_Response_Model_ClosedLoop.m`
进一步把这些候选模型接入当前双 VP 主方法闭环测试。这里保持优化器、
频率候选筛选和最终联合精修全部不变，只替换连续静态模板族
`F_g(x)` 与 `F'_g(x)` 的重构规则。

这一步验证的意义是：

```text
如果闭环结果显著改善，
则提升来自静态模板重构模型，
而不是来自对后端识别器额外加经验规则。
```

### 10.1 smoke 工况：g = 0.2 mm, 10 dB

在最敏感的小间隙边界工况下：

1. `field_basis_inv_log_2`
   由 `[1, 1/g, log(g)]` 构成，平均 gap 误差约 `0.00256 mm`，
   平均频率误差约 `0.166 Hz`，平均幅值误差约 `0.00087 mm`。

2. `power_law, p = 0.25, basis_order = 2`
   将平均 gap 误差从约 `0.0157 mm` 降到 `0.0026 mm`，
   将平均频率误差从约 `24.9 Hz` 降到 `0.18 Hz`，
   说明它不仅改善了静态模板拟合，而且把原本容易跳错的频率支路拉回了正确分支。

3. `power_law, p = 0.75, basis_order = 1`
   虽然静态导数误差更均衡，但闭环平均频率误差约 `99.8 Hz`，
   仍然表现出明显支路误判。

4. `exponential, lambda = 0.30`
   闭环频率误差也仍然较大，说明它不适合作为当前主替换模型。

这说明：

```text
静态导数更平衡，并不自动意味着闭环识别更好；
对当前双 VP 方法而言，
模板族对真实小间隙静态波形的逼近能力，
比“导数单项更稳”更关键。
```

### 10.2 quick 工况：跨 gap 的结果

`runMode = "quick"` 进一步检查了代表性 gap 工况。结果显示：

1. `power_law, p = 0.25, basis_order = 2`
   仍然是综合最优模型，平均 gap 误差约 `0.0068 mm`，
   平均频率误差约 `0.15 Hz`。

2. `field_basis_inv_log_2`
   平均 gap 误差约 `0.0082 mm`，
   平均频率误差约 `0.137 Hz`，
   平均幅值误差约 `0.00215 mm`，
   平均模板 RMSE 约 `0.00208`。

3. 在 `g = 0.2 mm` 和 `g = 0.4 mm` 这两个小间隙边界工况下，
   `field_basis_inv_log_2` 和二阶 `p = 0.25` 幂律模型都把频率支路恢复到了正确分支；
   当前 `1/g` 基线在 `g = 0.4 mm` 已经出现约 `100 Hz` 量级的支路误差。

4. 在较大间隙 `g = 1.4 mm` 工况下，
   `field_basis_inv_log_2` 没有引入明显副作用，
   频率误差与当前 `1/g` 基线同量级，
   但模板 RMSE 仍更小。

### 10.3 当前应修正后的结论

结合静态库分析与高速闭环验证，当前更严格的结论应为：

```text
1/g 线性坐标不是当前最优静态模板重构模型；
场机理启发的 [1, 1/g, log(g)] 标定展开
与二阶低指数幂律模型都显著优于 1/g 基线；
其中 [1, 1/g, log(g)] 具有更清楚的物理来源，
可作为论文中的主理论模型；
二阶幂律模型作为强经验对照，
用于证明低维非线性模板重构确实能改善小间隙外推和高速识别。
```

因此，现阶段最合理的推进顺序应改为：

1. 优先把 `field_basis_inv_log_2` 作为当前 `1/g` 基线的主替换候选。
2. 保留 `power_law, p = 0.25, basis_order = 2`
   作为“理论可解释性较弱但数值上很强”的对照模型。
3. 后续继续在更多 gap 和更多信噪比下验证，
   判断这一结论是否在完整工况集上仍成立。

1. `power_law, p = 0.25, basis_order = 2`

3. `exponential, lambda = 0.30`

这说明：


### 10.3 当前应修正后的结论

结合静态库分析与高速闭环验证，当前更严格的结论应为：

```text
1/g 线性坐标不是当前最优静态模板重构模型；
低指数幂律模型确实更符合静态模板流形；
但真正对当前双 VP 闭环识别最有效的，
不是一阶 p = 0.75 幂律模型，
而是二阶 p = 0.25 幂律模型。
```

因此，现阶段最合理的推进顺序应改为：

1. 优先把 `power_law, p = 0.25, basis_order = 2`
   作为当前 `1/g` 基线的主替换候选。
2. 保留 `power_law, p = 0.75, basis_order = 1`
   作为“更简单但闭环未必最优”的对照模型。
3. 后续继续在更多 gap 和更多信噪比下验证，
   判断这一结论是否在完整工况集上仍成立。
