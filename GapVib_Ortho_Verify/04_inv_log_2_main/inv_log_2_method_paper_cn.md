# `inv_log_2` 间隙-振动解耦方法论文版

## 1. 问题定义

叶尖定时观测中，传感器输出同时受到间隙、叶尖振动、空间采样位置和测量噪声影响。若直接在高速波形上反推间隙，振动引起的空间坐标扰动容易被误解释为间隙变化；若仅按静态模板整段拟合，又会将低信息边缘区与振动主导区混入同一目标函数，削弱辨识稳定性。因此，本文将问题重写为一个带结构约束的响应面匹配问题。

记静态间隙为 `g`，空间坐标为 `x`，静态波形为 `V(x;g)`。这里的 `V(x;g)` 不是任意经验函数，而是表示“在间隙为 `g`、叶尖位于空间坐标 `x` 时，传感器应输出的无振动电压”。在高速观测中，叶尖的实际空间位置会被振动扰动，因此高速波形可写成

```math
V_{\mathrm{hs}}(t)=V\!\left(x_0(t)-u(t);g\right)+\eta(t).
```

这一定义的来源是：高速观测并不是在固定空间点采样，而是在叶尖扫掠轨迹上采样；若叶尖发生振动，采样点会从名义位置 `x_0(t)` 偏移到 `x_0(t)-u(t)`。式中，`x_0(t)` 表示名义空间坐标，`u(t)` 表示叶尖径向振动位移，`\eta(t)` 表示测量噪声。后续方法都建立在这一结构化观测模型上。

## 2. 从离散静态库到连续响应面

静态标定只能获得有限个间隙点 `{g_i}_{i=1}^N` 及其对应波形 `V_i(x)`。这意味着可用数据是离散静态库，而高速辨识需要的是可对任意 `g` 评价的连续模板族 `V(x;g)`。二者之间的连接，本质上是对间隙变量上的响应面做低维展开。

对固定 `x`，静态波形可视为间隙变量的平滑函数 `v_x(g)=V(x;g)`。在研究区间内，若该函数关于 `g` 的变化平滑且可验证，则可用少量基函数逼近：

```math
V(x;g)\approx \sum_{k=1}^{K} a_k(x)\,\phi_k(g).
```

这里的 `a_k(x)` 表示第 `k` 个间隙基函数在空间位置 `x` 处的系数，`\phi_k(g)` 表示间隙维度上的基函数。该式的作用不是替代物理模型，而是把有限静态库变成一个可插值、可求导、可用于高速辨识的连续响应面。`inv_log_2` 方法采用的基函数组为

```math
\Phi(g)=\bigl[1,\;1/g,\;\log(g)\bigr].
```

对应写成

```math
V(x;g)\approx a_0(x)+a_1(x)\frac{1}{g}+a_2(x)\log(g).
```

常数项描述基线与偏置，`1/g` 描述主导反比变化趋势，`\log(g)` 描述缓变非线性和边界修正。这里没有把它写成固定的传感器定律，而是把它当作静态库上的可验证参数化形式。

## 3. 可信空间的确定

并非整条波形都适合用于间隙辨识。叶尖通过波形两端通常接近基线，局部斜率和曲率较小，间隙差异在这些区间内不够敏感；将这类低信息区域纳入拟合，会放大噪声并削弱参数可辨识性。因此，需要先从静态库中确定可信空间 `\Omega_x=[x_L,x_R]`。

可信空间的选取遵循三个条件：

1. 区间内响应活动足够强，波形不是近似平坦的；
2. 不同间隙在该区间内具有足够区分度；
3. 留一间隙验证中的模板重构误差和导数误差都较小。

这里的逻辑是：先在静态库上扫描候选窗口，再用留一间隙验证、导数一致性和间隙敏感度共同筛选。换言之，可信空间不是由高速波形阈值直接截取得到，而是由静态库的可验证稳定性决定。形式上，可定义综合评分函数

```math
S(\Omega_x)=E_{\mathrm{temp}}(\Omega_x)+\lambda_d E_{\mathrm{deriv}}(\Omega_x)+\lambda_s R_{\mathrm{sens}}(\Omega_x),
```

其中 `E_{\mathrm{temp}}` 表示模板重构误差，`E_{\mathrm{deriv}}` 表示导数误差，`R_{\mathrm{sens}}` 表示间隙敏感度不足的惩罚，`\lambda_d` 和 `\lambda_s` 是权重系数。最终选择的是在误差可接受前提下尽可能宽的窗口，因为窗口过窄会损失信息，过宽又会引入低信息边缘并降低稳定性。

## 4. 可信模板库的重构

在固定可信空间后，静态模板库可被裁剪为可信模板库，并在该空间内重构连续模板族。设 `x_j` 为可信空间内的采样点，对每个 `x_j`，取静态标定库在不同间隙下的波形值，就能构造一个关于间隙基函数的线性回归问题。

先定义标定矩阵：

```math
\Phi=
\begin{bmatrix}
1 & 1/g_1 & \log g_1\\
1 & 1/g_2 & \log g_2\\
\cdots & \cdots & \cdots\\
1 & 1/g_N & \log g_N
\end{bmatrix}.
```

这个矩阵的每一行对应一个已知间隙 `g_i`，每一列对应一个间隙基函数。它的作用是把“间隙维度上的低维展开”写成线性代数形式。再定义第 `j` 个空间采样点上的静态响应向量：

```math
y_j=
\begin{bmatrix}
F_{g_1}(x_j)\\
F_{g_2}(x_j)\\
\cdots\\
F_{g_N}(x_j)
\end{bmatrix}.
```

这里的 `F_{g_i}(x_j)` 表示在间隙 `g_i`、空间位置 `x_j` 处的静态电压值。把它们按间隙顺序堆叠，就得到该空间点上关于间隙变化的观测向量。对应的展开系数通过最小二乘给出：

```math
\begin{bmatrix}
B_0(x_j)\\
B_1(x_j)\\
B_2(x_j)
\end{bmatrix}
=
\arg\min_b
\left\|
\Phi b-y_j
\right\|^2.
```

这一步的含义是：在每个固定空间点 `x_j` 上，用 `1`, `1/g`, `\log(g)` 三个间隙基函数去拟合该点随间隙变化的响应曲线。若 `\Phi^T\Phi` 条件良好，则可写成正规方程形式：

```math
b_j^\ast=(\Phi^T\Phi)^{-1}\Phi^T y_j.
```

这里的 `b_j^\ast=[B_0(x_j),B_1(x_j),B_2(x_j)]^T`。对每个空间采样点独立求解后，就得到三条随空间位置变化的系数函数 `B_0(x)`, `B_1(x)`, `B_2(x)`，从而形成连续静态模板族

```math
\widehat F(g,x)=B_0(x)+B_1(x)\frac{1}{g}+B_2(x)\log g.
```

这个式子不是直接写出来的经验回归式，而是“离散静态库 + 间隙基函数 + 逐点最小二乘”共同得到的连续模板面。为了后续振动分离，再定义其空间偏导数：

```math
\widehat F_x'(g,x)=\frac{\partial \widehat F(g,x)}{\partial x}.
```

它表示在间隙 `g` 固定时，叶尖位置沿空间坐标发生微小变化时电压的变化率。

由此，候选间隙 `g` 下的无振动基准波形定义为

```math
V_0(t;g)=\widehat F(g,x(t)).
```

这里 `x(t)` 是高速采样时刻对应的叶尖扫掠坐标。把它代入 `\widehat F(g,x)`，就把静态模板面转成了时间波形。

## 5. 高速观测模型

对高速旋转工况，叶尖的名义空间坐标可写为

```math
x_0(t)=R\Omega\,(t-T_{m,k}),
```

其中 `R` 为转子半径，`\Omega` 为角速度，`T_{m,k}` 为第 `m` 圈第 `k` 个叶片的叶尖通过时刻。这个式子的意义是：在无振动条件下，叶尖沿探头敏感方向的扫掠位置可以由转速和通过时刻计算出来。若叶尖存在径向振动位移 `u(t)`，则实际采样位置变为

```math
x(t)=x_0(t)-u(t).
```

这里的减号表示：若叶尖沿传感器敏感方向向探头靠近，则观测坐标相应减小。于是高速观测可写成

```math
V_{\mathrm{hs}}(t)=\widehat F(g,x_0(t)-u(t))+\eta(t).
```

这一定义表明，振动首先表现为空间坐标的重采样，其次才表现为波形形状改变。因此，后续修正应优先处理坐标扰动，而不是把整条残差当作无结构噪声。

## 6. 静态间隙初值估计

在可信空间内，先忽略振动项，仅用静态模板匹配高速波形主轮廓。引入空间平移参数 `d_x` 的原因是：高速波形和静态模板之间通常存在整体对齐偏差，如果不先允许一个小的坐标平移，间隙搜索就会把对齐误差误当作间隙误差。于是构造静态目标函数

```math
J_{\mathrm{static}}(g,d_x)=\frac{1}{M}\sum_{j=1}^{M}\Bigl[V_{\mathrm{hs}}(x_j)-\widehat F(g,x_j-d_x)\Bigr]^2,\quad x_j\in \Omega_x.
```

这里 `M` 是可信空间内的采样点数。式子的含义是：在可信空间中逐点比较高速观测和候选静态模板，寻找同时使间隙 `g` 和空间平移 `d_x` 误差最小的组合。先对 `d_x` 最小化，再对 `g` 搜索，可以避免把对齐误差错误解释为间隙变化。得到的 `\hat g_0` 只是静态初值，不表示间隙已经辨识完成。

## 7. 振动投影修正

静态初值只能解释波形主轮廓，不能解释由振动引起的细节偏移。若振动幅值相对于波形空间尺度较小，则可对模板作一阶展开。先从 `\widehat F(g,x_0(t)-u(t))` 出发，对 `u(t)` 作泰勒展开：

```math
\widehat F(g,x_0(t)-u(t))
\approx
\widehat F(g,x_0(t))-\widehat F_x'(g,x_0(t))u(t).
```

这个式子的来源是：对固定 `g` 和固定采样时刻 `t`，`u(t)` 只是一个小的空间扰动量，因此电压对该扰动的一阶变化可由模板对空间坐标的偏导数给出。若位移可由少量谐波表示，

```math
u(t)=\sum_{q=1}^{Q}A_q\sin(\omega_q t+\varphi_q),
```

则一阶扰动项属于有限维子空间。这里的 `A_q`、`\omega_q`、`\varphi_q` 分别表示第 `q` 个振动分量的幅值、角频率和初相位。将其代入一阶展开后，能够由振动模型解释的残差就落在由 `\widehat F_x'(g,x_0(t))` 及其谐波调制项张成的空间中。

因此，可以定义投影残差

```math
r_\perp(t;g)=\bigl(I-\mathcal P_{\mathcal B}\bigr)\bigl[V_{\mathrm{hs}}(t)-\widehat F(g,x_0(t))\bigr],
```

其中 `\mathcal B` 是上述有限维振动子空间，`\mathcal P_{\mathcal B}` 是到该子空间的最小二乘投影。这个式子的意义不是简单去噪，而是把能够由振动模型解释的残差部分，从静态间隙误差中分离出来。对每一个候选 `g` 都执行一次投影评价，然后再进入频率识别和联合精修阶段。

## 8. 联合辨识的变量投影思想

在得到静态初值和投影修正后，进一步联合求解间隙参数与振动参数。设振动参数记为 `\theta_u`，则联合模型可写为

```math
V_{\mathrm{hs}}(t)\approx \widehat F(g,x_0(t)-u(t;\theta_u)).
```

这里的 `u(t;\theta_u)` 表示由振动参数 `\theta_u` 参数化的位移时程。若直接同时搜索 `g` 与 `\theta_u`，问题维数较高且耦合显著，因此更稳妥的处理方式是采用变量投影思想：外层搜索间隙，内层对振动引入的线性或准线性子问题做最小二乘消元。这样，非线性部分主要保留在间隙维度上，而幅值、相位和频率等振动参数则在每个候选间隙下进行解析或半解析求解。

该策略的意义在于：

1. 它把频率离散搜索、线性参数求解和局部非线性精修拆成可控层次；
2. 它避免将间隙参数、振动参数和对齐参数混入同一个高维黑箱优化，从而提高数值稳定性。

在实现逻辑上，频率列表可先由固定间隙下的变量投影识别得到，也可由静态残差频谱初筛得到，再带入间隙修正模型中继续精化。这里变量投影的作用是：把“频率是离散非线性变量、幅值和相位是线性或准线性变量”这一结构利用起来，减少直接联合搜索的维数。

## 9. 位移重构与结果解释

当最终获得 `\hat g` 与 `\hat\theta_u` 后，便可重构叶尖径向位移时程

```math
\hat u(t)=u(t;\hat\theta_u).
```

这里的 `\hat u(t)` 是最终的位移识别结果，它有两层含义：

1. 在时间域上，它给出叶尖振动的幅值、相位和频率信息；
2. 在空间域上，它可回代到 `\widehat F(\hat g,x_0(t)-\hat u(t))`，检验重构波形是否能够重新解释高速 BTT 观测。

因此，位移重构不是独立于间隙辨识之外的附加步骤，而是整个间隙-振动联合模型的最终输出。若重构后波形在可信空间内与观测数据保持一致，则说明当前模型下估计的间隙与振动参数具有内部一致性。

## 10. `inv_log_2` 基函数的来源与边界

`inv_log_2` 的核心不在于函数数量，而在于它把间隙维度上的连续响应面写成了一个低阶、可验证的参数化模型。与高阶多项式相比，`1/g` 与 `\log(g)` 更适合描述小间隙段的快速变化和大间隙段的缓变过渡；与纯样条插值相比，这种形式更便于在高速辨识中做快速搜索和导数分析。

但这种形式没有普适性。它成立的前提是：所研究的间隙区间内，静态库的响应面足够平滑，且该基函数组能够通过留一间隙验证、模板误差和导数误差检验。`inv_log_2` 的合理性来自验证结果，而不是先验物理定律。

## 11. 方法边界

该方法适用于以下情形：

1. BTT 信号能够稳定获取，且同一测点下的静态库已经建立；
2. 间隙响应在研究区间内近似单调、平滑，模板族可以连续化；
3. 振动幅值相对静态模板空间变化不过大，小扰动一阶近似仍可接受；
4. 主要振动可由少量谐波或少数频率成分描述。

当振动幅值过大、模态过多、波形失真严重或间隙响应出现强非线性拐点时，单一的 `inv_log_2` 模板可能不足以覆盖全部情形，需要扩展间隙基函数、引入分段模板或增加振动子空间维数。
