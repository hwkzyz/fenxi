# 程序框架版：静态模板库与双层识别

## 1. 目标重写

当前目录下程序已经具备两块基础能力：

- 用多间隙无振动波形构造 `F(x,g)` 或 `S(g,x)` 响应面
- 在给定模板上，对 `(dx,g)` 做联合匹配

下一步不是推翻现有后半段，而是把整体结构明确拆成：

1. 静态模板库构造
2. 高速静态状态估计
3. 固定静态模板下的振动参数搜索
4. 最终整波形非线性精修

也就是从“单层联合拟合”改成“分层解耦识别”。

---

## 2. 状态与符号在程序里的落地

建议在代码变量层统一采用下面这组含义：

- `alpha_k`：传感器相对 OPR 的几何安装相位，必须保留
- `a_k`：传感器增益，第一版仿真固定为 `1`
- `b_k`：传感器基线项，第一版仿真固定为 `0`
- `zeta`：静态状态参数
- `zetaGrid`：低速标定状态离散网格
- `zetaHat`：高速窗估计得到的静态状态
- `F_lib{k}`：第 `k` 个传感器的模板库对象
- `Fx_lib{k}`：第 `k` 个传感器的模板一阶导数库
- `x_ref{k}`：由 OPR 与 `alpha_k` 映射得到的无振动空间坐标
- `u(t;p)`：振动位移模型

第一版单等效传感器仿真可退化为：

```matlab
k = 1;
alpha_k = alpha_0;
a_k = 1;
b_k = 0;
```

这里 `alpha_k` 不是设成 `1`，而是退化成固定常数 `alpha_0`。

## 3. 推荐的总流程

建议把主流程明确整理成下面 5 个阶段：

### Phase A. 低速模板库构造

输入：

- 多个低速无振动波形
- 每条波形对应的静态状态标签 `zeta_m`，可是真实 gap，也可是单调状态量

输出：

- `F_lib{k}`：模板插值对象 `F_k(x,zeta)`
- `Fx_lib{k}`：导数插值对象 `F_{k,x}(x,zeta)`
- `templateMeta`：坐标范围、参考网格、参考状态等元数据

对应当前代码基础：

- [Clearance_Vibration_Decoupling.m](E:/0小论文+程序/0博士期间小论文+程序/间隙和振动解耦/Clearance_Vibration_Decoupling.m)
- [Experimental_Clearance_Decoupling.m](E:/0小论文+程序/0博士期间小论文+程序/间隙和振动解耦/Experimental_Clearance_Decoupling.m)
- [NoVibration_ReferenceGap_Reconstruction.m](E:/0小论文+程序/0博士期间小论文+程序/间隙和振动解耦/间隙的影响/NoVibration_ReferenceGap_Reconstruction.m)

说明：

- 顶层两个脚本已经在做 `S(g,x)` 的构造，这一步本质上已经很接近模板库
- 缺的不是数学对象，而是把它正式封装成后续高速识别可调用的“库”

建议新增模块：

```matlab
templateLib = build_static_template_library(lowSpeedData, options)
```

输出字段建议：

```matlab
templateLib.zetaGrid
templateLib.xGrid
templateLib.F_handle
templateLib.Fx_handle
templateLib.referenceZeta
templateLib.sensorMeta
```

---

### Phase B. 几何映射

输入：

- OPR 时刻 `T_OPR(m)`
- 转速 `Omega(m)`
- 传感器几何安装相位 `alpha_k`
- 叶尖半径 `R_tip`
- 高速采样时刻 `t_i`

输出：

- `T_e(k,m)`：理论无振动到达时刻
- `x_ref{k}`：无振动参考空间坐标

建议独立成模块：

```matlab
geom = build_space_mapping(highSpeedData, sensorConfig)
```

输出字段建议：

```matlab
geom.T_expected
geom.x_ref
geom.revIndex
geom.sensorIndex
geom.time
```

说明：

- 这一层对应你强调的 `alpha_k`
- 该层只负责时空映射，不参与拟合，不应混入静态状态估计

---

### Phase C. 高速静态状态估计

输入：

- 高速波形 `V_H`
- `x_ref{k}`
- 模板库 `F_k(x,zeta)`

输出：

- `zetaHat`
- `staticFit`：静态匹配代价、置信度、候选状态排序

目标函数建议写成：

```matlab
zetaHat = argmin_zeta J_static(zeta)
```

第一版建议的 `J_static(zeta)` 形式：

1. 零振动近似粗估

```matlab
J_static(zeta) = sum_{k,i} [V_H(k,i) - F_k(x_ref(k,i), zeta)]^2
```

2. 或加入低维刚体平移补偿后粗估

```matlab
J_static(zeta) = min_dx sum_{k,i} [V_H(k,i) - F_k(x_ref(k,i)-dx, zeta)]^2
```

第二种更稳，因为它不至于把小幅真实振动全部压到静态失配里。

建议新增模块：

```matlab
staticState = estimate_static_state(highSpeedWave, geom, templateLib, options)
```

输出字段建议：

```matlab
staticState.zetaHat
staticState.dx0
staticState.costCurve
staticState.zetaCandidates
staticState.bestTemplate
```

---

### Phase D. 线性化频率候选搜索

输入：

- `zetaHat`
- `F_k(x,zetaHat)`
- `F_{k,x}(x,zetaHat)`
- 高速波形 `V_H`

输出：

- 候选频率
- 线性化初值参数 `p0`

线性化残差：

```matlab
DeltaV(k,i) = V_H(k,i) - F_k(x_ref(k,i), zetaHat)
```

近似模型：

```matlab
DeltaV(k,i) ≈ -F_{k,x}(x_ref(k,i), zetaHat) * u(t_i; p)
```

这一层与原有 VARPRO 思想兼容，只需要把原来固定模板中的：

- `V_fp{k}`
- `K1_fp{k}`

改成：

- `V_fp{k, zetaHat}` 或插值后的 `V_fp_hat{k}`
- `K1_fp{k, zetaHat}` 或插值后的 `K1_fp_hat{k}`

建议新增模块：

```matlab
initGuess = search_vibration_candidates(highSpeedWave, geom, templateLib, staticState, options)
```

输出字段建议：

```matlab
initGuess.freqCandidates
initGuess.linearCoeffs
initGuess.p0
initGuess.scanMap
```

---

### Phase E. 整波形非线性精修

输入：

- `zetaHat`
- 初值 `p0`
- 高速波形 `V_H`
- 模板库 `F_k`

输出：

- 最终振动参数 `pHat`
- 波形拟合结果
- 残差诊断

目标函数：

```matlab
pHat = argmin_p sum_{k,i} [V_H(k,i) - F_k(x_ref(k,i) - u(t_i;p), zetaHat)]^2
```

建议新增模块：

```matlab
fitResult = refine_vibration_nonlinear(highSpeedWave, geom, templateLib, staticState, initGuess, options)
```

输出字段建议：

```matlab
fitResult.pHat
fitResult.uHat
fitResult.vHat
fitResult.residual
fitResult.rmse
fitResult.exitflag
```

## 6. 最合适的首改脚本

第一优先建议先改：

[Clearance_Vibration_Decoupling.m](E:/0小论文+程序/0博士期间小论文+程序/间隙和振动解耦/Clearance_Vibration_Decoupling.m)

原因：

- 它数据干净，变量少，最适合先把“双层识别”的骨架跑通
- 现在它已经有 `F(g,x)`、`dx`、`g` 联合拟合示例，只差把联合拟合改成分层流程
- 一旦在仿真脚本里跑通，再迁移到实验脚本，调试成本最低

不建议一上来先改实验脚本的原因：

- 实验波形里有基线漂移、对齐误差、边界裁剪等现实问题
- 如果先在实验脚本里改，很容易把“理论问题”和“数据脏问题”缠在一起

## 7. 第一轮最小改动方案

建议先不要大拆文件，而是在 `Clearance_Vibration_Decoupling.m` 里完成一次最小闭环改造：

### Step 1. 把 `F(g,x)` 解释为模板库

保留现有：

```matlab
F = griddedInterpolant({gapList, xGrid}, S, 'linear', 'nearest');
```

但在逻辑上改名为：

```matlab
templateLib.F_handle = F;
templateLib.zetaGrid = gapList;
templateLib.xGrid = xGrid;
```

### Step 2. 显式增加静态状态粗估

对合成高速波形 `yMeas`，先做：

```matlab
for each zeta in zetaGrid
    dx0(zeta) = argmin_dx || yMeas - F(zeta, x-dx) ||^2
end
zetaHat = argmin_zeta J_static(zeta)
```

此处 `dx0` 只是静态粗匹配辅助量，不代表最终振动。

### Step 3. 固定 `zetaHat` 后再做振动精修

把现在的联合优化：

```matlab
min_{dx,g} || yMeas - F(g, x-dx) ||^2
```

改成两段：

```matlab
zetaHat = estimate_static_state(...)
dxHat = argmin_dx || yMeas - F(zetaHat, x-dx) ||^2
```

如果后面扩到真实振动模型，再把 `dxHat` 替换成 `u(t;p)`。

### Step 4. 增加结果对比

同一组数据至少输出三种结果：

- 固定低速参考模板拟合
- 联合 `(dx,g)` 拟合
- 双层 `zetaHat -> dxHat` 拟合

这样能直接验证“双层结构是否比原固定模板更符合你现在的理论表述”。

## 10. 最终建议

现阶段最稳妥的推进顺序是：

1. 先在 `Clearance_Vibration_Decoupling.m` 里把“固定模板 vs 联合拟合”扩成“固定模板 vs 联合拟合 vs 双层识别”
2. 证明 `zetaHat` 先估计后，位移识别更稳定
3. 再把这套骨架迁移到实验脚本
4. 最后再接入真实的 `u(t;p)` 多频振动模型与 VARPRO 初值搜索

一句话概括：

不是先去改后半段振动识别器，而是先把前半段补成“模板库 + 静态状态估计器”，这样后半段原有识别逻辑才能继续成立，而且物理含义也不会混掉。
